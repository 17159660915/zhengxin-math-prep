# 24.3 正多边形和圆

## 📖 知识点

### 一、正多边形的定义

各边**相等**、各角也**相等**的多边形叫做**正多边形**。

> 正三角形、正方形、正五边形、正六边形等都是正多边形。

### 二、正多边形与圆的关系

把一个圆分成 n 等份，顺次连接各分点，就得到一个**正 n 边形**。

- 正多边形的**外接圆**：经过正多边形各顶点的圆
- 正多边形的**中心**：外接圆的圆心
- 正多边形的**半径**：外接圆的半径 R
- 正多边形的**边心距**：中心到正多边形一边的距离 r

### 三、正多边形的计算

| 公式 | 说明 |
|------|------|
| 中心角 = 360°/n | 正 n 边形相邻两条半径之间的夹角 |
| 内角 = (n-2)×180°/n | 正 n 边形每个内角的度数 |
| 边长 a = 2R×sin(180°/n) | R 为外接圆半径 |
| 边心距 r = R×cos(180°/n) | 中心到边的距离 |
| 面积 S = 1/2 × n × a × r | 正 n 边形面积 |

---

## ⭐ 重点

1. 正 n 边形的中心角 = 360°/n，内角 = (n-2)×180°/n。
2. 正六边形的边长等于外接圆的半径——这是最特殊的性质。
3. 正多边形既是轴对称又是中心对称图形（偶数边正多边形为中心对称）。

---

## ⚠️ 易错点

> ❌ **错误**：正多边形既是轴对称又是中心对称图形
> ✅ **正确**：正多边形都是轴对称图形，但偶数边数的正多边形才是中心对称图形
>
> ❌ **错误**：正六边形的半径等于边长，那边心距也等于边长
> ✅ **正确**：正六边形的边长 = 半径，但边心距 = R×cos30° = R√3/2，不等于边长

---

## 📝 典型例题

**例 1**：正六边形的中心角是多少度？

> 解：中心角 = 360°/6 = 60°

**例 2**：正五边形的每个内角是多少度？

> 解：内角 = (5-2)×180°/5 = 540°/5 = 108°
