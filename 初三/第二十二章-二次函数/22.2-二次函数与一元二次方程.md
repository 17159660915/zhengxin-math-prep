# 22.2 二次函数与一元二次方程

## 📖 知识点

### 一、二次函数与 x 轴的交点

二次函数 y = ax² + bx + c 的图象与 x 轴的交点**横坐标**，就是方程 ax² + bx + c = 0 的根。

| 判别式 Δ | 与 x 轴交点个数 | 方程根的情况 | 图象特征 |
|---------|--------------|------------|---------|
| Δ > 0 | 2 个交点 | 两个不相等的实数根 | 抛物线穿过 x 轴两次 |
| Δ = 0 | 1 个交点 | 两个相等的实数根 | 顶点在 x 轴上 |
| Δ < 0 | 无交点 | 无实数根 | 抛物线完全在 x 轴上方或下方 |

### 二、二次函数与不等式

ax² + bx + c > 0 的解集（a > 0）：图象在 x 轴上方的部分对应的 x 取值范围。
ax² + bx + c < 0 的解集（a > 0）：图象在 x 轴下方的部分对应的 x 取值范围。

> 注意：当 a < 0 时，开口向下，不等号方向要反过来。

---

## ⭐ 重点

1. 函数图象与 x 轴的交点个数完全由判别式 Δ = b² - 4ac 决定。
2. 二次函数与一元二次方程的关系：求交点就是解方程，方程的解就是交点的横坐标。
3. 不等式解集看图象在 x 轴的上方还是下方——注意 a 的符号决定开口方向。

---

## ⚠️ 易错点

> ❌ **错误**：二次函数图象与 x 轴的交点就是方程的解
> ✅ **正确**：交点的**横坐标**是方程的解，交点本身是点不是数
>
> ❌ **错误**：Δ < 0 时，二次函数与 x 轴没有交点，但方程一定有根
> ✅ **正确**：Δ < 0 时，方程无实数根，函数与 x 轴无交点
>
> ❌ **错误**：ax² + bx + c > 0 的解集一定是"小于小根或大于大根"
> ✅ **正确**：当 a > 0 时，解集是"小于小根或大于大根"；当 a < 0 时，解集是"两根之间"

---

## 📝 典型例题

**例 1**：二次函数 y = x² - 2x - 3 与 x 轴有几个交点？求交点坐标。

> 解：Δ = (-2)² - 4×1×(-3) = 4 + 12 = 16 > 0，有 2 个交点
> x² - 2x - 3 = 0 → (x - 3)(x + 1) = 0
> x₁ = 3，x₂ = -1，交点 (3, 0) 和 (-1, 0)

**例 2**：二次函数 y = x² - 4x + 4 与 x 轴有几个交点？

> 解：Δ = (-4)² - 4×1×4 = 16 - 16 = 0，有 1 个交点 (2, 0)

**例 3**：利用二次函数解不等式 x² - x - 2 > 0

> 解：y = x² - x - 2，与 x 轴交于 (-1, 0) 和 (2, 0)，开口向上
> 图象在 x 轴上方的部分：x < -1 或 x > 2
