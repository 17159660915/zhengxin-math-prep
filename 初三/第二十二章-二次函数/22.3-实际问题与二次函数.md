# 22.3 实际问题与二次函数

## 📖 知识点

### 一、二次函数的最值应用

二次函数 y = ax² + bx + c（a ≠ 0）在顶点处取得最值：
- 当 a > 0 时，开口向上，顶点处有**最小值**
- 当 a < 0 时，开口向下，顶点处有**最大值**

> 顶点 x = -b/(2a)，最值 y = (4ac - b²)/(4a)

### 二、常见类型

| 类型 | 解题思路 |
|------|---------|
| 最大利润 | 总利润 = 单件利润 × 数量，化为二次函数求顶点 |
| 最大面积 | 利用面积公式列二次函数，求顶点 |
| 抛物线形桥/洞 | 建立坐标系，设抛物线解析式，代入已知点求解 |

### 三、解题步骤

1. 设未知数，找出等量关系
2. 列二次函数解析式
3. 确定自变量取值范围
4. 求顶点坐标（最值）
5. 检验是否符合实际意义

---

## ⭐ 重点

1. 最值问题：a > 0 求最小值，a < 0 求最大值。
2. 自变量取值范围**必须符合实际意义**（如数量不能为负）。
3. 抛物线形问题通常需要建立合适的坐标系。

---

## ⚠️ 易错点

> ❌ **错误**：最值直接取顶点而不考虑自变量取值范围
> ✅ **正确**：先求顶点，再判断顶点是否在自变量取值范围内，不在则取区间端点值

> ❌ **错误**：抛物线形问题中，坐标系建得不合适，解析式复杂
> ✅ **正确**：将坐标原点建在抛物线的顶点或对称轴上，解析式最简

---

## 📝 典型例题

**例 1**（最大利润）：某商品进价 50 元，售价 80 元时可卖 200 件。每降价 1 元多卖 10 件，求最大利润时的售价。

> 解：设降价 x 元，利润为 y 元
> y = (80 - 50 - x)(200 + 10x)
> y = (30 - x)(200 + 10x) = -10x² + 100x + 6000
> x = -100/(-20) = 5，y = 6000 + 250 = 6250
> 售价 = 80 - 5 = 75 元，最大利润 6250 元

**例 2**（最大面积）：用 40m 的篱笆靠墙围一个矩形菜地，求最大面积和此时的长宽。

> 解：设垂直于墙的边长为 x m，则平行于墙的边长为 (40 - 2x) m
> 面积 S = x(40 - 2x) = -2x² + 40x
> x = -40/(-4) = 10，S = 200
> 宽 10m，长 20m，最大面积 200m²
