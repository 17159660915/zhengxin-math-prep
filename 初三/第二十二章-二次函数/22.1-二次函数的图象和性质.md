# 22.1 二次函数的图象和性质

## 📖 知识点

### 一、二次函数的定义

一般地，形如 y = ax² + bx + c（a、b、c 是常数，a ≠ 0）的函数，叫做**二次函数**。

> 例：y = x²、y = 2x² + 3x - 1、y = -x² + 4 都是二次函数。
> y = 1/x²、y = x³ 不是二次函数。

### 二、二次函数 y = ax² 的图象

图象是**抛物线**，顶点在原点 (0, 0)，对称轴是 y 轴（即直线 x = 0）。

| a 的符号 | 开口方向 | 顶点 | 最值 | 增减性 |
|---------|---------|------|------|--------|
| a > 0 | 向上 | 最低点 | y = 0（最小值） | 左减右增 |
| a < 0 | 向下 | 最高点 | y = 0（最大值） | 左增右减 |

> |a| 越大，开口越小（越陡）；|a| 越小，开口越大（越平缓）。

### 三、二次函数 y = a(x - h)² + k 的图象

顶点在 (h, k)，对称轴为直线 x = h，由 y = ax² 平移得到。

> **平移规律**：左加右减（x 的平移），上加下减（k 的平移）。
> 例：y = x² → 向右平移 2 个单位 → y = (x - 2)² → 再向上平移 3 个单位 → y = (x - 2)² + 3

### 四、一般式 y = ax² + bx + c 的顶点

**顶点坐标公式**：
- 横坐标：x = -b/(2a)
- 纵坐标：y = (4ac - b²)/(4a)

**对称轴**：直线 x = -b/(2a)



### 五、三种解析式形式

| 形式 | 表达式 | 适用场景 |
|------|--------|---------|
| 一般式 | y = ax² + bx + c | 已知三个点 |
| 顶点式 | y = a(x - h)² + k | 已知顶点和另一点 |
| 交点式 | y = a(x - x₁)(x - x₂) | 已知与 x 轴两个交点 |

---

## ⭐ 重点

1. 开口方向由 a 决定：a > 0 开口向上，a < 0 开口向下，|a| 越大开口越小。
2. 顶点坐标公式：x = -b/(2a)，y = (4ac - b²)/(4a) —— 必须熟记。
3. 平移规律：左加右减，上加下减——注意是给 x 本身加减，不是给整体。
4. 三种解析式形式可以互相转化，根据已知条件选择最合适的形式。

---

## ⚠️ 易错点

> ❌ **错误**：y = -x² 的开口向上
> ✅ **正确**：a = -1 < 0，开口向下
>
> ❌ **错误**：y = (x - 2)² + 3 的顶点是 (-2, 3)
> ✅ **正确**：顶点是 (2, 3)——左加右减，x - 2 表示向右平移 2
>
> ❌ **错误**：y = ax² + bx + c 的对称轴是 x = -b/a
> ✅ **正确**：对称轴是 x = -b/(2a)，分母是 2a 不是 a
>
> ❌ **错误**：平移时 y = x² 向左平移 2 得 y = (x + 2)²，再加 3 得 y = (x + 2)² + 3（正确，但混淆了左右）
> ✅ **正确**：左加右减——向左平移 2 是 x + 2，向右平移 2 是 x - 2

## 📝 典型例题

**例 1**：求二次函数 y = x² - 4x + 3 的顶点坐标和对称轴。

> 解：a = 1，b = -4，c = 3
> x = -(-4)/(2×1) = 2
> y = (4×1×3 - (-4)²)/(4×1) = (12 - 16)/4 = -1
> 顶点 (2, -1)，对称轴 x = 2

**例 2**：二次函数 y = 2(x + 1)² - 3 的顶点和开口方向。

> 解：顶点 (-1, -3)，a = 2 > 0，开口向上

**例 3**：抛物线 y = x² 向左平移 2 个单位，再向下平移 3 个单位，求解析式。

> 解：y = x² → 左移 2 → y = (x + 2)² → 下移 3 → y = (x + 2)² - 3


**例 5**：已知二次函数的顶点为 (2, -1)，且图象过点 (0, 3)，求解析式。

> 解：设顶点式 y = a(x - 2)² - 1
> 代入 (0, 3)：3 = a(0 - 2)² - 1
> 3 = 4a - 1，4a = 4，a = 1
> 解析式为 y = (x - 2)² - 1 = x² - 4x + 3

**例 6**：比较 y = 2x²、y = 0.5x²、y = -x² 三个抛物线的开口大小和方向。

> 解：
> y = 2x²：a = 2 > 0，开口向上，最小
> y = 0.5x²：a = 0.5 > 0，开口向上，最大
> y = -x²：a = -1 < 0，开口向下
> 开口大小排序：y = 0.5x² > y = -x² > y = 2x²（|a|越大开口越小）

**例 4**：已知二次函数过点 (0, 3)、(1, 0)、(2, 3)，求解析式。

> 解：设 y = ax² + bx + c，代入三点：
> c = 3，a + b + 3 = 0，4a + 2b + 3 = 3
> 解得 a = 1，b = -4，c = 3
> 解析式为 y = x² - 4x + 3
