# 22.1 二次函数的图象和性质

## 📖 知识点

### 一、二次函数的定义

一般地，形如 y = ax² + bx + c（a、b、c 是常数，a ≠ 0）的函数，叫做**二次函数**。

> 例：y = x²、y = 2x² + 3x - 1 是二次函数。y = 1/x² 不是。

### 二、二次函数 y = ax² 的图象和性质

图象是**抛物线**，顶点在原点 (0, 0)，对称轴是 y 轴。

| a 的符号 | 开口方向 | 顶点 | 最值 |
|---------|---------|------|------|
| a > 0 | 向上 | 最低点 | y = 0（最小值） |
| a < 0 | 向下 | 最高点 | y = 0（最大值） |

### 三、二次函数 y = a(x - h)² + k 的图象

顶点在 (h, k)，对称轴为直线 x = h，由 y = ax² 平移得到。

> 口诀：左加右减（x 的平移），上加下减（k 的平移）。

### 四、一般式 y = ax² + bx + c 的顶点

顶点坐标：(-b/(2a), (4ac - b²)/(4a))
对称轴：x = -b/(2a)

## ⭐ 重点

1. 开口方向由 a 决定：a > 0 开口向上，a < 0 开口向下，|a| 越大开口越小。
2. 顶点坐标的公式：x = -b/(2a)，y = (4ac - b²)/(4a)。
3. 平移规律：左加右减，上加下减。

---

## ⚠️ 易错点

> ❌ **错误**：y = -x² 的开口向上
> ✅ **正确**：a = -1 < 0，开口向下

> ❌ **错误**：y = (x - 2)² + 3 的顶点是 (-2, 3)
> ✅ **正确**：y = (x - 2)² + 3 的顶点是 (2, 3)（左加右减，x - 2 表示向右平移 2）

> ❌ **错误**：y = ax² + bx + c 的对称轴是 x = -b/a
> ✅ **正确**：对称轴是 x = -b/(2a)

---

## 📝 典型例题

**例 1**：求二次函数 y = x² - 4x + 3 的顶点坐标和对称轴。

> 解：a = 1，b = -4，c = 3
> x = -(-4)/(2×1) = 2
> y = [4×1×3 - (-4)²]/(4×1) = (12 - 16)/4 = -1
> 顶点 (2, -1)，对称轴 x = 2

**例 2**：二次函数 y = 2(x + 1)² - 3 的顶点和开口方向。

> 解：顶点 (-1, -3)，a = 2 > 0，开口向上

**例 3**：抛物线 y = x² 向左平移 2 个单位，再向下平移 3 个单位，求解析式。

> 解：y = x² → 左移 2 → y = (x + 2)² → 下移 3 → y = (x + 2)² - 3
