# 28.1 锐角三角函数

## 📖 知识点

### 一、锐角三角函数的定义

在 Rt△ABC 中，∠C = 90°，设 ∠A 的对边为 a，邻边为 b，斜边为 c：

| 函数 | 定义 | 记法 | 意义 |
|------|------|------|------|
| 正弦 | 对边/斜边 | sinA = a/c | 对边与斜边的比 |
| 余弦 | 邻边/斜边 | cosA = b/c | 邻边与斜边的比 |
| 正切 | 对边/邻边 | tanA = a/b | 对边与邻边的比 |

> 锐角三角函数的值只与角度大小有关，与三角形的大小无关。

### 二、特殊角的三角函数值

| 角度 | 30° | 45° | 60° |
|------|-----|-----|-----|
| sin | 1/2 | √2/2 | √3/2 |
| cos | √3/2 | √2/2 | 1/2 |
| tan | √3/3 | 1 | √3 |


### 三、三角函数的关系

- sin²A + cos²A = 1（同角三角函数平方关系）
- tanA = sinA/cosA（正切与正余弦的关系）

---

## ⭐ 重点

1. 锐角三角函数的值只与角度有关，与三角形的大小无关——任意直角三角形中，同一锐角的三角函数值固定。
2. 特殊角的三角函数值必须熟记——30°、45°、60° 的 sin、cos、tan。
3. 正弦和余弦的取值范围：0 < sinA < 1，0 < cosA < 1（A 为锐角时）。

---

## ⚠️ 易错点

> ❌ **错误**：sin30° = √3/2（混淆 sin 和 cos 的特殊值）
> ✅ **正确**：sin30° = 1/2，cos30° = √3/2
>
> ❌ **错误**：tan45° = 0
> ✅ **正确**：tan45° = 1
>
> ❌ **错误**：sinA = 对边/斜边，但不知道哪个角是 A 就乱用
> ✅ **正确**：一定要先确定 ∠A 的位置，再找它的对边和邻边
>
> ❌ **错误**：sin²A 写作 sinA²
> ✅ **正确**：sin²A 表示 (sinA)²，sinA² 表示 sin(A²)，两者不同

---

## 📝 典型例题

**例 1**：Rt△ABC 中，∠C = 90°，a = 3，c = 5，求 sinA、cosA。

> 解：b = √(5² - 3²) = 4
> sinA = 3/5，cosA = 4/5


**例 3**：在 Rt△ABC 中，∠C = 90°，sinA = 3/5，c = 10，求 a、b、cosA、tanA。

> 解：sinA = a/c = 3/5，a = 10 × 3/5 = 6
> b = √(c² - a²) = √(100 - 36) = √64 = 8
> cosA = b/c = 8/10 = 4/5
> tanA = a/b = 6/8 = 3/4

**例 4**：计算 sin²30° + cos²45° + tan²60°

> 解：sin30° = 1/2，cos45° = √2/2，tan60° = √3
> (1/2)² + (√2/2)² + (√3)²
> = 1/4 + 2/4 + 3 = 1/4 + 1/2 + 3 = 3.75 = 15/4

**例 2**：计算 sin30° + cos60° - tan45°。

> 解：1/2 + 1/2 - 1 = 0

**例 3**：Rt△ABC 中，∠C = 90°，∠A = 30°，BC = 2，求 AB 和 AC。

> 解：sin30° = BC/AB = 2/AB → AB = 2/(1/2) = 4
> AC = √(4² - 2²) = √12 = 2√3
