# 21.2 解一元二次方程

## 📖 知识点

### 一、直接开平方法

利用平方根的定义直接开平方求解。

> 形如 x² = p（p ≥ 0）→ x = ±√p
> 形如 (x + n)² = p（p ≥ 0）→ x + n = ±√p

### 二、配方法

**步骤**：
1. 移项：把常数项移到右边
2. 系数化 1：二次项系数为 1
3. 配方：两边加上一次项系数一半的平方
4. 开方：用直接开平方法求解

> 例：x² + 6x + 2 = 0 → x² + 6x = -2 → x² + 6x + 9 = 7 → (x + 3)² = 7 → x = -3 ± √7

### 三、公式法

**求根公式**：x = [-b ± √(b² - 4ac)] / (2a)（a ≠ 0）

**判别式**：Δ = b² - 4ac
- Δ > 0 → 方程有两个不相等的实数根
- Δ = 0 → 方程有两个相等的实数根
- Δ < 0 → 方程无实数根（有虚数根，初中不要求）

### 四、因式分解法

把方程化为两个一次因式乘积等于 0 的形式，再令每个因式为 0。

> 例：x² - 5x + 6 = 0 → (x - 2)(x - 3) = 0 → x₁ = 2，x₂ = 3

---

## ⭐ 重点

1. 四种解法中，**公式法**是通用解法（适用于所有一元二次方程）。
2. 判别式 Δ = b² - 4ac 决定根的情况——先算 Δ 再求解。
3. 因式分解法最简便，但不是所有方程都能分解。

---

## ⚠️ 易错点

> ❌ **错误**：x² = 4 的解是 x = 2（漏了负根）
> ✅ **正确**：x² = 4 → x = ±2（两个根）

> ❌ **错误**：公式法求根公式中，分母忘了除以 2a
> ✅ **正确**：x = [-b ± √(b² - 4ac)] / (2a)，分母是 2a

> ❌ **错误**：配方法中，两边加的数不是一次项系数一半的平方
> ✅ **正确**：x² + 6x 加 9，一次项系数 6 的一半是 3，平方是 9

---

## 📝 典型例题

**例 1**（公式法）：解方程 x² - 3x - 4 = 0

> 解：a = 1，b = -3，c = -4
> Δ = (-3)² - 4×1×(-4) = 9 + 16 = 25
> x = [3 ± √25] / 2 = [3 ± 5] / 2
> x₁ = 4，x₂ = -1

**例 2**（配方法）：解方程 x² + 4x - 5 = 0

> 解：x² + 4x = 5
> x² + 4x + 4 = 9
> (x + 2)² = 9 → x + 2 = ±3
> x₁ = 1，x₂ = -5

**例 3**（因式分解）：解方程 x² - 5x = 0

> 解：x(x - 5) = 0
> x₁ = 0，x₂ = 5
