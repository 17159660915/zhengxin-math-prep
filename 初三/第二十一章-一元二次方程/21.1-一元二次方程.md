# 21.1 一元二次方程

## 📖 知识点

### 一、一元二次方程的定义

等号两边都是**整式**，只含有一个**未知数**，并且未知数的**最高次数是 2** 的方程，叫做**一元二次方程**。

> 标准形式：ax² + bx + c = 0（a ≠ 0）
> a 是二次项系数，b 是一次项系数，c 是常数项。

### 二、一元二次方程的解

使方程左右两边相等的未知数的值，叫做一元二次方程的**解**（也叫**根**）。

> 例：x = 2 是方程 x² - 4 = 0 的一个根。

### 三、一元二次方程的一般形式

ax² + bx + c = 0（a ≠ 0）
- 当 a = 0 时，变成一元一次方程
- 当 b = 0 时，为 ax² + c = 0（缺一次项）
- 当 c = 0 时，为 ax² + bx = 0（缺常数项）

---

## ⭐ 重点

1. 一元二次方程三要素：① 整式方程 ② 一个未知数 ③ 最高次数为 2。
2. 二次项系数 a ≠ 0 是必要条件——a = 0 就不是一元二次方程了。
3. 方程的根代入后必须使等式成立。

---

## ⚠️ 易错点

> ❌ **错误**：ax² + bx + c = 0 一定是一元二次方程
> ✅ **正确**：当 a = 0 时，它是一元一次方程。必须满足 a ≠ 0

> ❌ **错误**：x² - 2x + 1 = 0 的二次项系数是 0
> ✅ **正确**：二次项系数是 1（x² 的系数），一次项系数是 -2，常数项是 1

> ❌ **错误**：x² - 1/x = 0 是一元二次方程
> ✅ **正确**：1/x 不是整式，所以不是整式方程，不是一元二次方程

---

## 📝 典型例题

**例 1**：将方程 3x(x - 1) = 5(x + 2) 化为一元二次方程的一般形式，并指出各项系数。

> 解：3x² - 3x = 5x + 10
> 3x² - 8x - 10 = 0
> 二次项系数 a = 3，一次项系数 b = -8，常数项 c = -10

**例 2**：x = 3 是方程 x² - 5x + 6 = 0 的根吗？

> 解：代入得 3² - 5×3 + 6 = 9 - 15 + 6 = 0
> 等式成立，x = 3 是方程的根
