# 21.3 实际问题与一元二次方程

## 📖 知识点

### 一、列方程解应用题的步骤

1. **审**：审清题意，找出等量关系
2. **设**：设未知数
3. **列**：列出方程
4. **解**：解方程
5. **验**：检验是否符合实际意义（舍去不合题意的根）
6. **答**：写出答案

### 二、常见类型

| 类型 | 等量关系 |
|------|---------|
| 增长率问题 | 增长后 = 增长前 × (1 + 增长率)ⁿ |
| 面积问题 | 利用面积公式列方程 |
| 利润问题 | 总利润 = 单件利润 × 数量 |
| 数字问题 | 两位数 = 10a + b |

> 增长率公式：a(1 + x)ⁿ = b，其中 a 为初始量，x 为增长率，n 为年数，b 为最后量。

---

## ⭐ 重点

1. 解一元二次方程后，**必须检验根是否符合实际意义**（如长度不能为负）。
2. 增长率问题注意：下降率用负号，n 次增长后为 a(1 + x)ⁿ。
3. 面积问题常用**平移法**将道路移到一边。

---

## ⚠️ 易错点

> ❌ **错误**：求出的根全部保留，不检验
> ✅ **正确**：一元二次方程通常有两个根，必须结合实际意义舍去一个

> ❌ **错误**：增长率问题的公式用错，a(1 + x)ⁿ 写成 a(1 + nx)
> ✅ **正确**：a(1 + x)ⁿ 是 n 次增长后的量，不是 a(1 + nx)

---

## 📝 典型例题

**例 1**（增长率）：某工厂两年内产值从 100 万增长到 121 万，求平均年增长率。

> 解：设平均年增长率为 x
> 100(1 + x)² = 121
> (1 + x)² = 1.21 → 1 + x = ±1.1
> x₁ = 0.1 = 10%，x₂ = -2.1（舍去）
> 答：平均年增长率为 10%

**例 2**（面积）：一块矩形空地长 20m，宽 16m，四周修等宽道路，中间矩形面积为 192m²，求路宽。

> 解：设路宽为 x m
> (20 - 2x)(16 - 2x) = 192
> 320 - 72x + 4x² = 192 → 4x² - 72x + 128 = 0
> x² - 18x + 32 = 0 → (x - 2)(x - 16) = 0
> x₁ = 2，x₂ = 16（舍去，16 > 16/2）
> 答：路宽 2m

**例 3**：两个连续正整数的积为 56，求这两个数。

> 解：设较小的数为 x，则较大的数为 x + 1
> x(x + 1) = 56 → x² + x - 56 = 0 → (x + 8)(x - 7) = 0
> x₁ = 7，x₂ = -8（舍去）
> 答：这两个数为 7 和 8
