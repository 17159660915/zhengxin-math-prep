# 26.1 反比例函数

## 📖 知识点

### 一、反比例函数的定义

一般地，形如 y = k/x（k 为常数，k ≠ 0）的函数叫做**反比例函数**。

> 自变量 x 的取值范围是 x ≠ 0 的一切实数。
> 等价形式：y = kx⁻¹ 或 xy = k（k ≠ 0）

### 二、反比例函数的图象和性质

图象是**双曲线**，由两支曲线组成，关于原点中心对称。

![反比例函数图象](diagrams/03-inverse-proportion.png)

| k 的符号 | 图象位置 | 增减性 | 对称性 |
|---------|---------|--------|--------|
| k > 0 | 第一、三象限 | 每个象限内，y 随 x 增大而**减小** | 关于原点中心对称 |
| k < 0 | 第二、四象限 | 每个象限内，y 随 x 增大而**增大** | 关于原点中心对称 |

### 三、k 的几何意义

过双曲线上任意一点 P(x, y) 作 x 轴、y 轴的垂线，与坐标轴围成的矩形面积 = |k|。

> 即：矩形 PMON 的面积 = |x| × |y| = |xy| = |k|
> 例：若 P 在 y = 6/x 上，则过 P 作两坐标轴的垂线，围成的矩形面积为 6。

---

## ⭐ 重点

1. 反比例函数 y = k/x 中，k ≠ 0 且 x ≠ 0，y ≠ 0。
2. 增减性要强调"**在每个象限内**"——跨象限不能直接比较大小。
3. k 的几何意义：|k| = 过双曲线上任意一点作坐标轴垂线围成的矩形面积。
4. 双曲线无限接近坐标轴，但**不相交**。

---

## ⚠️ 易错点

> ❌ **错误**：反比例函数 y = k/x 中，y 随 x 增大而减小（只说 k > 0 的情况）
> ✅ **正确**：k > 0 时，在每个象限内 y 随 x 增大而减小；k < 0 时，在每个象限内 y 随 x 增大而增大
>
> ❌ **错误**：双曲线与坐标轴相交
> ✅ **正确**：双曲线无限接近坐标轴，但不相交
>
> ❌ **错误**：y = k/x 中 k 可以等于 0
> ✅ **正确**：k = 0 时 y = 0，是常数函数，不是反比例函数
>
> ❌ **错误**：比较 A(-1, -6) 和 B(2, 3) 在 y = 6/x 上的 y 值大小，直接说 A 的 y 小于 B 的 y
> ✅ **正确**：A 在第三象限，B 在第一象限，跨象限不能直接比较，实际上 A 的 y = -6 < B 的 y = 3

## 📝 典型例题

**例 1**：反比例函数 y = 6/x 的图象在第几象限？y 随 x 如何变化？

> 解：k = 6 > 0，图象在第一、三象限
> 在每个象限内，y 随 x 增大而减小


**例 3**：反比例函数 y = k/x 的图象经过点 (2, -3)，求 k 并判断图象在第几象限。

> 解：代入 (2, -3)：-3 = k/2，k = -6
> k < 0，图象在第二、四象限

**例 4**：已知点 A(1, y₁)、B(2, y₂)、C(-3, y₃) 在反比例函数 y = 6/x 的图象上，比较 y₁、y₂、y₃ 的大小。

> 解：k = 6 > 0，图象在第一、三象限
> 在第一象限内，y 随 x 增大而减小：1 < 2，y₁ > y₂ > 0
> C 在第三象限，y₃ < 0
> y₁ > y₂ > y₃

**例 2**：已知反比例函数 y = k/x 过点 (2, 3)，求 k。

> 解：代入得 3 = k/2 → k = 6

**例 3**：点 P 在反比例函数 y = 12/x 的图象上，过 P 作 x 轴、y 轴的垂线，求矩形面积。

> 解：矩形面积 = |k| = 12

**例 4**：已知点 A(-1, y₁) 和 B(2, y₂) 在反比例函数 y = -4/x 的图象上，比较 y₁ 和 y₂ 的大小。

> 解：k = -4 < 0，图象在第二、四象限
> A(-1, y₁) 在第二象限，y₁ > 0
> B(2, y₂) 在第四象限，y₂ < 0
> 所以 y₁ > y₂
