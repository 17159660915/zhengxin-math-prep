# 23.2 一次函数的图象和性质 - 思维训练

## 第1题
**题目：** 一次函数y=2x-3中，k和b各是多少？图象经过哪些象限？

**解析：** k=2>0，b=-3<0。直线上升，交y轴负半轴。经过第一、三、四象限。

## 第2题
**题目：** 一次函数y=-x+2的图象经过哪些象限？

**解析：** k=-1<0，b=2>0。直线下降，交y轴正半轴。经过第一、二、四象限。


## 第3题

**题目：** 一次函数 y = kx + b 的图象经过点 (1, 3) 和 (-1, -1)，求函数的解析式。

**解析：** k+b=3，-k+b=-1。相加：2b=2，b=1。k+1=3，k=2。y=2x+1。

## 第4题

**题目：** 一次函数 y = -2x + 4 的图象与 x 轴、y 轴分别交于 A、B 两点，求 △AOB 的面积。

**解析：** x=0时 y=4，B(0,4)。y=0时 -2x+4=0，x=2，A(2,0)。面积 = 1/2×2×4 = 4。

## 第5题

**题目：** 已知一次函数 y = (k-1)x + 2k - 3 的图象经过第一、二、四象限，求 k 的取值范围。

**解析：** 经过第一、二、四象限，则 k-1 < 0，2k-3 > 0。k < 1，k > 1.5。无解。所以应为一、二、三象限或一、三、四象限。重新分析：k-1<0且2k-3>0得 1.5<k<1，无解。所以图象不可能同时经过一、二、四象限。
