## 第1题

**题目：** 已知一次函数 y = kx + b 的图象经过点 A(1, 3) 和 B(-2, -3)，求 k 和 b 的值。

**解析：** 代入 A：k+b=3
代入 B：-2k+b=-3
相减：3k=6, k=2
代入：2+b=3, b=1

答案：k=2, b=1

---

## 第2题

**题目：** 已知直线 y = 2x + 3 与直线 y = -x + b 交于 x 轴上同一点，求 b 的值。

**解析：** 直线 y=2x+3 与 x 轴交点：y=0 → 2x+3=0 → x=-1.5
交点 (-1.5, 0) 也在 y=-x+b 上
0 = -(-1.5)+b = 1.5+b, b=-1.5

答案：b=-1.5

---

## 第3题

**题目：** 一次函数 y = (k-2)x + 3k - 1 的图象经过原点，求 k 的值。

**解析：** 图象过原点 → 0 = (k-2)×0 + 3k-1 → 0 = 3k-1 → k=1/3

答案：k=1/3

---

## 第4题

**题目：** 已知一次函数 y = (3m-1)x + 2 - m 的图象与 y 轴交点在 x 轴上方，求 m 的取值范围。

**解析：** 与 y 轴交点：(0, 2-m)
在 x 轴上方 → 2-m > 0 → m < 2
一次函数 → 3m-1≠0 → m≠1/3
∴ m < 2 且 m≠1/3

答案：m<2 且 m≠1/3

---

## 第5题

**题目：** 已知直线 y = kx + b 与直线 y = 2x 平行，且过点 (1, -1)，求这条直线的解析式。

**解析：** 平行 → k=2
y=2x+b, 代入 (1,-1)：-1=2+b, b=-3
∴ y=2x-3

答案：y=2x-3
