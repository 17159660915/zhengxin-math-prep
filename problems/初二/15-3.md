# 15.3 等腰三角形 - 思维训练

## 第1题
**题目：** 等腰三角形ABC中，AB=AC，角A=80度，求角B和角C。


**解析：** AB=AC，角B=角C。角B+角C+角A=180度，2角B=100度，角B=角C=50度。

## 第2题
**题目：** **题目：** 等腰三角形一腰上的高与另一腰的夹角为 30，求这个等腰三角形的顶角。

**解析：** 分两种情况。锐角三角形时，顶角 = 90 - 30 = 60。钝角三角形时，顶角 = 90 + 30 = 120。
## 第3题

**题目：** 等腰三角形 ABC 中，AB = AC，∠A = 40°，求 ∠B 和 ∠C 的度数。

**解析：** ∠B = ∠C = (180°-40°)/2 = 70°。

## 第4题

**题目：** 等腰三角形的一个角是 80°，求另外两个角的度数。讨论所有可能情况。

**解析：** ①80°为顶角：底角各50°。②80°为底角：顶角=180°-80°×2=20°，另一底角也为80°。两种情况：50°,50°或80°,20°。

## 第5题

**题目：** △ABC 中，AB = AC，D 是 BC 上一点，且 AD = BD，∠BAD = 30°，求 ∠C 的度数。

**解析：** AD = BD → ∠B = ∠BAD = 30°。AB = AC → ∠C = ∠B = 30°。∠BAC = 180°-30°-30°=120°。



## 第6题

**题目：** 等腰三角形 ABC 中，AB = AC，底边 BC 上的高 AD = 4，BC = 6。求腰长 AB 和三角形面积。

**解析：** 等腰三角形底边上的高也是中线。BD = BC/2 = 3。在 Rt ABD 中，AB = sqrt(BD + AD) = sqrt(9 + 16) = 5。面积 = (1/2) x 6 x 4 = 12。

## 第7题

**题目：** 在等腰三角形 ABC 中，AB = AC，角 A = 36，角 C 的平分线交 AB 于 D。求证：AD = BC。

**解析：** A = 36，B = C = 72。CD 平分 C，ACD = 36 = A，AD = CD。CDB = 180 - 72 - 36 = 72 = B，BC = CD。所以 AD = BC。

## 第7题

**题目：** 等腰三角形的一个角为70度，求另外两个角的度数。分情况讨论。

**解析：** ①若70度是顶角，底角=(180-70)/2=55度。②若70度是底角，另一个底角也是70度，顶角=180-70*2=40度。两种情况：(70,55,55)或(70,70,40)。

## 第8题

**题目：** 等腰三角形一腰上的高与另一腰的夹角为 30，求这个等腰三角形的顶角。

**解析：** 分两种情况。当等腰三角形为锐角三角形时，顶角 = 90 - 30 = 60。当等腰三角形为钝角三角形时，顶角 = 90 + 30 = 120。
