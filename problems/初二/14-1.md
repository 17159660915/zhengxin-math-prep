## 第1题


**题目：** 如图，AB = AC，AD 平分 ∠BAC，D 在 BC 上。求证：BD = CD。

**解析：** 在 △ABD 和 △ACD 中：
AB = AC（已知）
∠BAD = ∠CAD（AD 平分 ∠BAC）
AD = AD（公共边）
∴ △ABD ≌ △ACD（SAS）
∴ BD = CD（全等三角形对应边相等）

答案：BD = CD

## 第2题

**题目：** 在 △ABC 中，∠ACB = 90°，AC = BC，D 是 AB 的中点，E、F 分别在 AC、BC 上，且 DE ⊥ DF。求证：DE = DF。


**解析：** 连接 CD。
△ABC 是等腰直角三角形，D 是斜边中点
∴ CD ⊥ AB 且 CD = AD = BD
∠ECD = 45° = ∠FBD
∠EDC + ∠CDF = 90° = ∠FDB + ∠CDF
∴ ∠EDC = ∠FDB
在 △EDC 和 △FDB 中：
CD = BD, ∠ECD = ∠FBD, ∠EDC = ∠FDB
∴ △EDC ≌ △FDB（ASA）
∴ DE = DF

答案：DE = DF

## 第3题

**题目：** 已知点 D 在 △ABC 的边 BC 上，且 BD = CD，∠BAD = ∠CAD。求证：AB = AC。


**解析：** 在 △ABD 和 △ACD 中：
BD = CD（已知）
∠BAD = ∠CAD（已知）
AD = AD（公共边）
这是 SSA，不能判定全等！

需要辅助线：过 D 作 DE ⊥ AB 于 E，DF ⊥ AC 于 F
∠BAD=∠CAD，AD 是角平分线
角平分线上的点到角两边距离相等 → DE = DF
在 Rt△BDE 和 Rt△CDF 中：
BD = CD, DE = DF
∴ Rt△BDE ≌ Rt△CDF（HL）
∴ ∠B = ∠C → AB = AC

答案：AB = AC

## 第4题

**题目：** 在 △ABC 中，AB = AC，D 是 BC 上一点，E 是 AD 上一点，且 ∠BED = ∠CED = 90°。求证：BE = CE。


**解析：** 在 Rt△BED 和 Rt△CED 中：
DE = DE（公共边）
∠BED = ∠CED = 90°
BD 不一定等于 CD，所以不能用 HL。

由 AB = AC 知 △ABC 是等腰三角形。
作 AF ⊥ BC 于 F，则 BF = CF（三线合一）
D 在 BC 上，要证 BE = CE，需证 ∠BDE = ∠CDE
但题目条件不足，需补充条件 D 是 BC 中点。

（原题条件不足，需添加 D 是 BC 中点或 BD = CD）

答案：条件不足，需补充 BD = CD

## 第5题

**题目：** 如图，在四边形 ABCD 中，AB = CD，AD = BC。求证：∠A = ∠C。

**解析：** 连接 BD。
在 △ABD 和 △CDB 中：
AB = CD（已知）
AD = CB（已知）
BD = DB（公共边）
∴ △ABD ≌ △CDB（SSS）
∴ ∠A = ∠C（全等三角形对应角相等）

答案：∠A = ∠C

## 第6题

**题目：** 在△ABC中∠ACB=90度，AC=BC，D是AB中点，E在AC上F在BC上且DE⊥DF。求证DE=DF。

**解析：** 连接CD。CD=AD=BD且CD⊥AB。∠DCE=∠DBF=45度。∠CDE+∠EDF=∠CDF+∠EDF=90度->∠CDE=∠CDF。△CDE≌△CDF(ASA)。DE=DF。

## 第7题

**题目：** 在△ABC中AB=AC，D是BC上一点，E是AD上一点且∠BED=∠CED=90度。求证BE=CE。

**解析：** ∠BED=∠CED=90度，DE=DE。需证△BED≌△CED，但需BD=CD或∠BDE=∠CDE。AB=AC->AD⊥BC且平分BC，所以BD=CD。△BED≌△CED(SAS)。BE=CE。

---

## 第8题

**题目：** 在△ABC中AB=AC，D是BC中点，E是AB上一点，F是AC上一点且DE⊥DF。求证BE=AF。

**解析：** 连接AD。AD⊥BC且AD平分∠BAC。∠B=∠C=45度。∠BDE+∠EDF=∠CDF+∠EDF=90度->∠BDE=∠CDF。△BDE≌△CDF(ASA)。BE=CF。同理可证AE=AF。
