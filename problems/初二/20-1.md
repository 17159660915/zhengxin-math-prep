## 第1题

**题目：**

![勾股定理](problems-diagrams/03-pythagorean.png)
 在 △ABC 中，∠C = 90°，D 是 AB 上一点，且 CD ⊥ AB。若 AC = 6，BC = 8，求 CD 的长。

**解析：** AB = √(6²+8²) = 10
S△ABC = 1/2×6×8 = 24
S△ABC = 1/2×AB×CD = 1/2×10×CD = 5CD
5CD = 24, CD = 4.8

答案：4.8

## 第2题

**题目：** 在 △ABC 中，AB = 15，AC = 13，BC 边上的高 AD = 12，求 BC 的长。

**解析：** 分两种情况：
① D 在 BC 上：
BD = √(15²-12²) = √(225-144) = √81 = 9
CD = √(13²-12²) = √(169-144) = √25 = 5
BC = 9+5 = 14
② D 在 BC 延长线上：
BC = 9-5 = 4

答案：14 或 4

## 第3题

**题目：** 在 △ABC 中，∠C = 90°，∠A = 30°，AB = 10，求 △ABC 的面积。

**解析：** 30°所对直角边是斜边的一半：BC = 5
AC = √(10²-5²) = √(100-25) = √75 = 5√3
S = 1/2×5×5√3 = 25√3/2

答案：25√3/2

---

## 第4题

**题目：** 如图，△ABC 中，AB = AC = 5，BC = 6，求 △ABC 的面积。

**解析：** 等腰三角形，作 AD ⊥ BC 于 D
BD = CD = 3
AD = √(5²-3²) = √(25-9) = 4
S = 1/2×6×4 = 12

答案：12

## 第5题

**题目：** 在 △ABC 中，∠C = 90°，AC = 3，BC = 4。以 △ABC 的三边为直径作半圆，求三个半圆面积之和。

**解析：** AB = √(3²+4²) = 5
三个半圆面积之和 = π/8(AC²+BC²+AB²)
= π/8(9+16+25) = π/8×50 = 25π/4

答案：25π/4
