# 20.2 勾股定理的逆定理及其应用 - 思维训练

## 第1题
**题目：** 判断边长为6,8,10的三角形是否为直角三角形。

**解析：** 最长边为10，6^2+8^2=36+64=100=10^2。满足勾股定理逆定理，是直角三角形。

## 第2题
**题目：** 判断边长为5,12,13的三角形是否为直角三角形，并指出直角所对的边。

**解析：** 最长边为13，5^2+12^2=25+144=169=13^2。是直角三角形，13所对的角为直角。


## 第3题

**题目：** 判断以 3k、4k、5k（k>0）为边长的是否为直角三角形。求 k=2 时的面积。

**解析：** (3k)²+(4k)² = 9k²+16k² = 25k² = (5k)²，是直角三角形，直角边为 3k 和 4k。k=2时边长6,8,10，面积=1/2×6×8=24。

## 第4题

**题目：** 三角形三边长为 a、b、c，满足 a²+b²+c² = 6a+8b+10c-50，判断三角形形状。

**解析：** a²-6a+9 + b²-8b+16 + c²-10c+25 = 0，(a-3)²+(b-4)²+(c-5)²=0。a=3，b=4，c=5。3²+4²=5²，是直角三角形。

## 第5题

**题目：** 如图，四边形 ABCD 中，∠A = 90°，AB = 3，AD = 4，BC = 13，CD = 12。求证：∠DBC = 90°。

**解析：** BD² = AB²+AD² = 9+16=25，BD=5。5²+12²=25+144=169=13²，BD²+CD²=BC²，所以 △DBC 是直角三角形，∠DBC=90°。


## 第6题

**题目：** 判断边长为6,8,10的三角形是否为直角三角形。

**解析：** 6^2+8^2=36+64=100=10^2，是直角三角形。

**解析：** 5^2+12^2=25+144=169=13^2，是直角三角形，直角所对的边是13。

## 第8题

**题目：** 三角形三边长为a、b、c，满足a^2+b^2+c^2=6a+8b+10c-50，判断三角形形状。

**解析：** 配方：(a-3)^2+(b-4)^2+(c-5)^2=0，a=3,b=4,c=5。3^2+4^2=25=5^2，是直角三角形。
