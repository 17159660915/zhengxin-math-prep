# 21.2 平行四边形 - 思维训练

## 第1题
**题目：** ABCD中，AB=8，BC=5，求周长。

**解析：** 平行四边形对边相等。周长=2(AB+BC)=2(8+5)=26。

## 第2题
**题目：** ABCD中，对角线AC、BD交于点O，AO=5，求OC。

**解析：** 平行四边形对角线互相平分。OC=AO=5。


## 第3题

**题目：** 平行四边形 ABCD 中，∠A = 50°，求 ∠B、∠C、∠D 的度数。

**解析：** ∠C = ∠A = 50°，∠B = ∠D = 180°-50°=130°。

## 第4题

**题目：** 平行四边形 ABCD 中，对角线 AC、BD 相交于点 O，AC = 10，BD = 14，求 OA、OB 的长。

**解析：** 平行四边形对角线互相平分。OA = AC/2 = 5，OB = BD/2 = 7。

## 第5题

**题目：** 如图，E、F 分别是平行四边形 ABCD 的边 AD、BC 的中点。求证：BE = DF。

**解析：** AD ∥ BC，AD = BC。E、F 是中点，ED = AD/2 = BC/2 = BF。ED ∥ BF，四边形 BEDF 是平行四边形，BE = DF。
