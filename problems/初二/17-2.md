# 17.2 用公式法分解因式 - 思维训练

## 第1题
**题目：** 分解因式：x^3-2x^2+x。

**解析：** 先提公因式x：x(x^2-2x+1)。再套完全平方：x(x-1)^2。

## 第2题
**题目：** 分解因式：2x^2-8。

**解析：** 先提公因式2：2(x^2-4)。再套平方差：2(x+2)(x-2)。


## 第3题

**题目：** 分解因式：x⁴ - 81。

**解析：** x⁴ - 81 = (x²)² - 9² = (x²-9)(x²+9) = (x-3)(x+3)(x²+9)。

## 第4题

**题目：** 分解因式：x² - 4xy + 4y² - 9。

**解析：** x² - 4xy + 4y² - 9 = (x-2y)² - 3² = (x-2y-3)(x-2y+3)。

## 第5题

**题目：** 已知 a² + b² + 2a - 4b + 5 = 0，求 a + b 的值。

**解析：** 配方：(a²+2a+1) + (b²-4b+4) = 0，即 (a+1)² + (b-2)² = 0。a = -1，b = 2，a+b = 1。


## 第6题

**题目：** 分解因式：x^3-4x

**解析：** =x(x^2-4)=x(x+2)(x-2)

## 第7题

**题目：** 分解因式：a^3+2a^2b+ab^2

**解析：** =a(a^2+2ab+b^2)=a(a+b)^2

## 第8题

**题目：** 分解因式：x^2-y^2-2x+1

**解析：** =(x^2-2x+1)-y^2=(x-1)^2-y^2=(x-1+y)(x-1-y)
