## 第1题

**题目：** 已知函数 y = √(2x-1) + 1/(x-3)，求自变量 x 的取值范围。

**解析：** √(2x-1) → 2x-1≥0 → x≥0.5
1/(x-3) → x-3≠0 → x≠3
综合：x≥0.5 且 x≠3

答案：x≥0.5 且 x≠3

## 第2题

**题目：** 已知 y 与 x² 成正比例，且当 x=2 时 y=12。求 y 与 x 的函数关系式，并求当 x=-3 时 y 的值。

**解析：** y = kx², 代入 (2,12)：12 = k×4, k=3
∴ y = 3x²
当 x=-3 时：y = 3×9 = 27

答案：y=3x², x=-3时y=27

## 第3题

**题目：** 已知 y = y₁ + y₂，y₁ 与 x 成正比例，y₂ 与 x² 成反比例。当 x=1 时 y=5，当 x=2 时 y=7。求 y 与 x 的函数关系式。

**解析：** 设 y₁ = k₁x, y₂ = k₂/x²
y = k₁x + k₂/x²
代入 (1,5)：k₁+k₂=5
代入 (2,7)：2k₁+k₂/4=7
解得：k₁=3, k₂=2
∴ y = 3x + 2/x²

答案：y = 3x + 2/x²

## 第4题

**题目：** 已知函数 y = 2x - 1 的图象上有一点 P 到 x 轴的距离为 3，求点 P 的坐标。

**解析：** 到 x 轴距离为 3 → |y|=3 → y=3 或 y=-3
y=3 时：2x-1=3 → x=2 → P(2,3)
y=-3 时：2x-1=-3 → x=-1 → P(-1,-3)

答案：(2,3) 或 (-1,-3)

## 第5题

**题目：** 已知等腰三角形的周长为 20，底边为 y，腰长为 x。求 y 与 x 的函数关系式，并求 x 的取值范围。

**解析：** 周长 = 2x+y = 20 → y = 20-2x
三角形三边关系：2x > y → 2x > 20-2x → 4x > 20 → x > 5
y > 0 → 20-2x > 0 → x < 10
∴ 5 < x < 10

答案：y=20-2x, 5<x<10
