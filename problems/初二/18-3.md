# 18.3 分式的加法与减法 - 思维训练

## 第1题
**题目：** 计算1/(x-1)+1/(x+1)。

**解析：** 通分，最简公分母为(x-1)(x+1)。原式=(x+1)/[(x-1)(x+1)]+(x-1)/[(x-1)(x+1)]=2x/(x^2-1)。

## 第2题
**题目：** 计算1/(x^2-1)-1/(x^2+2x+1)。

**解析：** x^2-1=(x+1)(x-1)，x^2+2x+1=(x+1)^2。最简公分母=(x+1)^2(x-1)。原式=(x+1)/[(x+1)^2(x-1)]-(x-1)/[(x+1)^2(x-1)]=2/[(x+1)^2(x-1)]。


## 第3题

**题目：** 计算：1/(x-2) + 1/(x+2) - 4/(x²-4)。

**解析：** 1/(x-2) + 1/(x+2) = (x+2+x-2)/(x²-4) = 2x/(x²-4)。2x/(x²-4) - 4/(x²-4) = (2x-4)/(x²-4) = 2(x-2)/(x²-4) = 2/(x+2)。

## 第4题

**题目：** 已知 a² + 3a + 1 = 0，求 a² + 1/a² 的值。

**解析：** a²+3a+1=0，两边除以a（a≠0）：a+3+1/a=0，a+1/a=-3。a²+1/a² = (a+1/a)²-2 = 9-2 = 7。

## 第5题

**题目：** 计算：1/(1×3) + 1/(3×5) + 1/(5×7) + ... + 1/(99×101)。

**解析：** 1/(2n-1)(2n+1) = 1/2[1/(2n-1)-1/(2n+1)]。原式 = 1/2[(1-1/3)+(1/3-1/5)+...+(1/99-1/101)] = 1/2(1-1/101) = 1/2×100/101 = 50/101。


## 第6题

**题目：** 计算：1/(x-1)-1/(x+1)

**解析：** =(x+1-(x-1))/(x^2-1)=2/(x^2-1)

## 第7题

**题目：** 计算：x/(x^2-1) + 1/(x+1)

**解析：** =x/((x+1)(x-1))+(x-1)/((x+1)(x-1))=(x+x-1)/((x+1)(x-1))=(2x-1)/(x^2-1)

---

## 第8题

**题目：** 已知 1/a+1/b=5，求 (a+b)/(ab) 的值。

**解析：** 1/a+1/b=(b+a)/(ab)=5，所以 (a+b)/(ab)=5。
