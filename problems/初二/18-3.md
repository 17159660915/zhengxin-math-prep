# 18.3 分式的加法与减法 - 思维训练

## 第1题
**题目：** 计算1/(x-1)+1/(x+1)。

**解析：** 通分，最简公分母为(x-1)(x+1)。原式=(x+1)/[(x-1)(x+1)]+(x-1)/[(x-1)(x+1)]=2x/(x^2-1)。

## 第2题
**题目：** 计算1/(x^2-1)-1/(x^2+2x+1)。

**解析：** x^2-1=(x+1)(x-1)，x^2+2x+1=(x+1)^2。最简公分母=(x+1)^2(x-1)。原式=(x+1)/[(x+1)^2(x-1)]-(x-1)/[(x+1)^2(x-1)]=2/[(x+1)^2(x-1)]。
