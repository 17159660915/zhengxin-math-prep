## 第1题

**题目：** 已知 a² + b² = 34，a + b = 8，求 ab 的值。

**解析：** (a+b)² = a²+2ab+b²
64 = 34+2ab
2ab = 30, ab = 15

答案：15

---

## 第2题

**题目：** 分解因式：(x² + 4)² - 16x²

**解析：** (x²+4)²-16x² = (x²+4)²-(4x)²
= (x²+4+4x)(x²+4-4x)
= (x²+4x+4)(x²-4x+4)
= (x+2)²(x-2)²

答案：(x+2)²(x-2)²

---

## 第3题

**题目：** 已知 a + b + c = 0，求证：a³ + b³ + c³ = 3abc。

**解析：** a+b+c=0 → c = -(a+b)
a³+b³+c³ = a³+b³-(a+b)³
= a³+b³-(a³+3a²b+3ab²+b³)
= -3a²b-3ab² = -3ab(a+b) = 3ab[-(a+b)]
= 3abc

答案：证明成立

## 第4题

**题目：** 已知 x² - 3x + 1 = 0，求 x² + 1/x² 的值（不用求 x 的值）。

**解析：** x²-3x+1=0，两边除以 x（x≠0）：x-3+1/x=0, x+1/x=3
x²+1/x² = (x+1/x)²-2 = 3²-2 = 7

答案：7

---

## 第5题

**题目：** 分解因式：x⁴ + x² + 1

**解析：** x⁴+x²+1 = x⁴+2x²+1-x² = (x²+1)²-x²
= (x²+1+x)(x²+1-x)
= (x²+x+1)(x²-x+1)

答案：(x²+x+1)(x²-x+1)
