# 16.3 乘法公式 - 思维训练

## 第1题
**题目：** 计算(2x+1)(2x-1)。

**解析：** 平方差公式，a=2x，b=1。(2x+1)(2x-1)=(2x)^2-1^2=4x^2-1。

## 第2题
**题目：** 计算(x+2)^2-(x-2)^2。

**解析：** (x+2)^2=x^2+4x+4，(x-2)^2=x^2-4x+4。相减：(x^2+4x+4)-(x^2-4x+4)=8x。


## 第3题

**题目：** 计算：998² 的值。（用平方差公式）

**解析：** 998² = (1000-2)² = 1000² - 2×1000×2 + 2² = 1000000 - 4000 + 4 = 996004。

## 第4题

**题目：** 已知 x + 1/x = 3，求 x² + 1/x² 和 x⁴ + 1/x⁴ 的值。

**解析：** x² + 1/x² = (x+1/x)² - 2 = 9 - 2 = 7。x⁴ + 1/x⁴ = (x²+1/x²)² - 2 = 49 - 2 = 47。

## 第5题

**题目：** 计算：2026² - 2025² + 2024² - 2023² + ... + 2² - 1²。

**解析：** 相邻两项用平方差公式：n²-(n-1)² = (n+n-1)(n-n+1) = 2n-1。原式 = (2×2026-1)+(2×2024-1)+...+(2×2-1) = 4051+4047+...+3。共1013项，首项4051，末项3，公差-4。和 = 1013×(4051+3)/2 = 1013×2027 = 2053351。


## 第6题

**题目：** 计算：(x+2)(x-2)-(x-1)^2

**解析：** =x^2-4-(x^2-2x+1)=x^2-4-x^2+2x-1=2x-5

## 第7题

**题目：** 已知 a+b=5，ab=3，求 a^2+b^2 和 (a-b)^2。

**解析：** a^2+b^2=(a+b)^2-2ab=25-6=19。(a-b)^2=(a+b)^2-4ab=25-12=13。

## 第8题

**题目：** 计算：2025^2-2024*2026（用乘法公式）

**解析：** 2025^2-(2025-1)(2025+1)=2025^2-(2025^2-1)=1。
