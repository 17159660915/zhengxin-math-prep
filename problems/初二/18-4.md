# 18.4 整数指数幂 - 思维训练

## 第1题
**题目：** 计算2^(-3)*3^2。

**解析：** 2^(-3)=1/8，3^2=9。2^(-3)*3^2=1/8*9=9/8。

## 第2题
**题目：** 用科学记数法表示0.0000034。

**解析：** 小数点向右移动6位到3.4。0.0000034=3.4*10^(-6)。


## 第3题

**题目：** 计算：(-2)⁻² + (1/2)⁻³ - (π-3)⁰。

**解析：** (-2)⁻² = 1/4，(1/2)⁻³ = 1/(1/8) = 8，(π-3)⁰ = 1。原式 = 1/4 + 8 - 1 = 7.25 = 29/4。

## 第4题

**题目：** 将 0.000000056 用科学记数法表示，并比较 5.6×10⁻⁸ 与 5.6×10⁻⁷ 的大小。

**解析：** 0.000000056 = 5.6×10⁻⁸。5.6×10⁻⁸ < 5.6×10⁻⁷。

## 第5题

**题目：** 已知 10ᵐ = 2，10ⁿ = 3，求 10²ᵐ⁻³ⁿ 的值。

**解析：** 10²ᵐ⁻³ⁿ = 10²ᵐ ÷ 10³ⁿ = (10ᵐ)² ÷ (10ⁿ)³ = 2² ÷ 3³ = 4/27。


## 第6题

**题目：** 计算：a^(-3)b^2 * a^5b^(-2)

**解析：** =a^(-3+5)*b^(2-2)=a^2*b^0=a^2

## 第7题

**题目：** 计算：(-2x^(-1)y^2)^(-2)

**解析：** =(-2)^(-2)*x^2*y^(-4)=1/4*x^2*y^(-4)=x^2/(4y^4)
