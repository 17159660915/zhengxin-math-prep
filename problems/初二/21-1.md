## 第1题

**题目：**

![特殊四边形](problems-diagrams/05-quadrilaterals.png)


![平行四边形](problems-diagrams/04-parallelogram.png)
 在平行四边形 ABCD 中，∠A 的平分线交 BC 于 E，且 BE = 3，EC = 2，求平行四边形 ABCD 的周长。

**解析：** AD ∥ BC → ∠AEB = ∠EAD（内错角）
AE 平分 ∠A → ∠BAE = ∠EAD
∴ ∠BAE = ∠AEB → AB = BE = 3
BC = BE+EC = 5
周长 = 2(AB+BC) = 2(3+5) = 16

答案：16

## 第2题

**题目：** 在矩形 ABCD 中，AB = 3，BC = 4，E 是 BC 上一点，且 BE = 1，求点 D 到 AE 的距离。

**解析：** 连接 DE。
AE = √(AB²+BE²) = √(9+1) = √10
S△ADE = S矩形 - S△ABE - S△CDE
= 3×4 - 1/2×3×1 - 1/2×3×4
= 12 - 1.5 - 6 = 4.5
又 S△ADE = 1/2×AE×h
4.5 = 1/2×√10×h, h = 9/√10 = 9√10/10

答案：9√10/10

## 第3题

**题目：** 在菱形 ABCD 中，对角线 AC = 6，BD = 8，求菱形的高。

**解析：** 菱形对角线互相垂直平分
边长 = √((6/2)²+(8/2)²) = √(9+16) = 5
S = 1/2×AC×BD = 1/2×6×8 = 24
S = 边长×高, 24 = 5h, h = 4.8

答案：4.8

## 第4题

**题目：** 在正方形 ABCD 中，E 是 CD 上一点，且 CE = 2DE，求 ∠AEB 的度数。

**解析：** 设正方形边长为 3，则 DE=1, CE=2
AE = √(3²+1²) = √10
BE = √(3²+2²) = √13
AB = 3
在 △AEB 中，cos∠AEB = (AE²+BE²-AB²)/(2×AE×BE)
= (10+13-9)/(2×√10×√13) = 14/(2√130) = 7/√130
∠AEB = arccos(7/√130) ≈ 52.1°

答案：arccos(7/√130)

## 第5题

**题目：** 在平行四边形 ABCD 中，E、F 分别是 AB、CD 的中点。求证：DE = BF。

**解析：** 平行四边形 ABCD → AB∥CD, AB=CD
E、F 是中点 → AE=EB=AB/2, CF=FD=CD/2
∴ EB=FD
又 EB∥FD
∴ 四边形 EBFD 是平行四边形
∴ DE = BF

答案：DE = BF
