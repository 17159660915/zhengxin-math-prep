# 13.3 三角形的内角与外角 - 思维训练

## 第1题
**题目：** 三角形ABC中，角A=50度，角B=2角A，求角C。

**解析：** 角B=2*50=100度。角C=180-50-100=30度。

## 第2题

**题目：** 如图，角ACD是三角形ABC的外角，角A=60度，角B=50度，求角ACD。

**解析：** 三角形外角等于不相邻两内角之和。角ACD=角A+角B=60+50=110度。


## 第3题

**题目：** 三角形 ABC 中，∠A = 2∠B，∠C = 3∠B，求各角的度数。

**解析：** ∠A + ∠B + ∠C = 180°，2∠B + ∠B + 3∠B = 180°，6∠B = 180°，∠B = 30°，∠A = 60°，∠C = 90°。

## 第4题

**题目：** 如图，∠ACD 是三角形 ABC 的外角，∠ACD = 120°，∠A = 2∠B，求 ∠A 和 ∠B 的度数。

**解析：** 外角等于不相邻两内角之和：∠ACD = ∠A + ∠B = 120°。∠A = 2∠B，代入得 2∠B + ∠B = 120°，3∠B = 120°，∠B = 40°，∠A = 80°。

## 第5题

**题目：** 三角形 ABC 中，∠A = 50°，∠B = 60°，∠C 的平分线与 ∠B 的外角平分线相交于点 D，求 ∠D 的度数。

**解析：** ∠C = 180°-50°-60°=70°。∠C的平分线分得两个35°。∠B的外角=180°-60°=120°，其平分线分得60°。在三角形中利用内角和定理求∠D。


## 第6题

**题目：** 三角形ABC中，角A=50度，角B=2倍角A，求角C。

**解析：** 角B=2*50=100度。角C=180-50-100=30度。

## 第7题

**题目：** 三角形ABC中，角A=60度，角B和角C的平分线相交于点O，求角BOC的度数。

**解析：** 角BOC=90+角A/2=90+30=120度。公式：角平分线交角=90+顶角/2。

---

## 第8题

**题目：** 三角形ABC中，角A=50度，角B=60度，角C的平分线与角B的外角平分线相交于点P，求角BPC的度数。

**解析：** 角C=180-50-60=70度。角C平分线分角C为35度。角B的外角=120度，其平分线分60度。角BPC=180-35-(60+60)=180-155=25度。
