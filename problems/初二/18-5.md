# 18.5 分式方程 - 思维训练

## 第1题
**题目：** 解方程1/x=2。

**解析：** 去分母（两边同乘x，x不等于0）：1=2x，x=1/2。验根：当x=1/2时，x不等于0，不是增根。原方程的解为x=1/2。

## 第2题
**题目：** 解方程1/(x-1)=2/(x^2-1)。

**解析：** 最简公分母为(x-1)(x+1)。去分母：x+1=2，x=1。验根：当x=1时，x-1=0，分母为0，是增根。原方程无解。


## 第3题

**题目：** 解方程：1/(x-2) + 3 = 1/(x-2) + 5。

**解析：** 两边减去 1/(x-2)：3 = 5，矛盾。方程无解。

## 第4题

**题目：** 若关于 x 的方程 2/(x-2) + m/(x²-4) = 3/(x+2) 有增根，求 m 的值。

**解析：** 去分母：2(x+2)+m=3(x-2)。2x+4+m=3x-6，-x+10+m=0，x=10+m。增根为 x=2 或 x=-2。x=2时 m=-8，x=-2时 m=-12。

## 第5题

**题目：** 甲、乙两人加工同一种零件，甲每小时比乙多加工 2 个，甲加工 60 个所用的时间与乙加工 50 个所用的时间相等。求甲、乙每小时各加工多少个。

**解析：** 设乙每小时加工 x 个，则甲每小时加工 x+2 个。60/(x+2) = 50/x，60x=50(x+2)，60x=50x+100，10x=100，x=10。乙每小时10个，甲每小时12个。


## 第6题

**题目：** 解方程：1/(x-1)=2/(x+1)

**解析：** 两边乘(x-1)(x+1)：x+1=2x-2，x=3。检验：x=3时分母不为0。

## 第7题

**题目：** 关于x的方程 2/(x-1)=a/(x+1) 有增根，求a的值。

**解析：** 增根使分母为0：x=1或x=-1。x=1：2/0=a/2，无意义。x=-1：2/(-2)=a/0，无意义。所以a无法使方程有增根，需检查。设x=1：2/0无意义。x=-1：2/(-2)=a/0，无意义。所以无解。

## 第8题

**题目：** 完成某项工程，甲单独做需10天，乙单独做需15天。甲先做3天，然后乙加入合作，还需几天完成？

**解析：** 甲效率1/10，乙效率1/15。甲做3天完成3/10。剩余7/10。合作效率=1/10+1/15=1/6。还需(7/10)/(1/6)=42/10=4.2天。
