# 13.2 与三角形有关的线段 - 思维训练

## 第1题
**题目：** 三角形ABC中，AB=8，AC=6，BC=10，AD是中线。求三角形ABD和三角形ACD的周长差。

**解析：** AD是中线，BD=CD=5。三角形ABD周长=AB+AD+BD=8+AD+5=13+AD。三角形ACD周长=AC+AD+CD=6+AD+5=11+AD。周长差=13+AD-(11+AD)=2。

## 第2题
**题目：** 三角形ABC中，角A=50度，角B=60度，CD是角平分线。求角ACD的度数。

**解析：** 角C=180-50-60=70度。CD平分角C，角ACD=70/2=35度。


## 第3题

**题目：** 三角形 ABC 中，AB = 7，AC = 5，BC 为整数，求 BC 的最大值和最小值。

**解析：** 三角不等式：7-5 < BC < 7+5，即 2 < BC < 12。BC为整数，最小值为3，最大值为11。

## 第4题

**题目：** 三角形 ABC 中，AD 是 BC 边上的中线，且 AB = 8，AC = 6，求 AD 的取值范围。（提示：倍长中线法）

**解析：** 延长 AD 至 E，使 DE = AD，连接 CE。则 △ABD ≌ △ECD，CE = AB = 8。在 △ACE 中，AC=6，CE=8，AE=2AD。由三角不等式：8-6 < 2AD < 8+6，2 < 2AD < 14，1 < AD < 7。

## 第5题

**题目：** 三角形 ABC 中，∠A = 90°，AC = 12，BC = 13，求 AB 边上的高。

**解析：** 由勾股定理：AB² = BC² - AC² = 169-144=25，AB=5。面积法：1/2×AB×AC = 1/2×BC×h，5×12 = 13×h，h = 60/13。


## 第6题

**题目：** 三角形ABC中，AB=7，AC=5，BC为整数，求BC的最大值和最小值。

**解析：** 根据三角形三边关系：AB-AC<BC<AB+AC，2<BC<12。BC为整数，所以最小3，最大11。

## 第7题

**题目：** 三角形ABC中，AD是BC边上的中线，且AB=8，AC=6，求三角形ABD与三角形ACD的周长差。

**解析：** AD是中线->BD=CD。AB+AD+BD-(AC+AD+CD)=AB-AC=8-6=2。周长差为2。

---

## 第8题

**题目：** 三角形ABC中，角A=90度，AC=12，BC=13，求AB的长。

**解析：** 直角三角形中，AB^2+AC^2=BC^2，AB^2+144=169，AB^2=25，AB=5。
