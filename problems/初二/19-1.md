## 第1题

**题目：** 已知 x = √(3+2√2)，y = √(3-2√2)，求 x² + y² 和 x + y 的值。

**解析：** x²=3+2√2, y²=3-2√2
x²+y²=6
x+y = √(3+2√2)+√(3-2√2)
(x+y)² = x²+y²+2xy = 6+2√(3+2√2)(3-2√2) = 6+2√1 = 8
x+y = 2√2（正数）

答案：x²+y²=6, x+y=2√2

## 第2题

**题目：** 比较 √(n+1) - √n 与 √(n+2) - √(n+1) 的大小（n≥1）。

**解析：** √(n+1)-√n = 1/(√(n+1)+√n)
√(n+2)-√(n+1) = 1/(√(n+2)+√(n+1))
分子相同，分母越大值越小
√(n+2)+√(n+1) > √(n+1)+√n
∴ √(n+1)-√n > √(n+2)-√(n+1)

答案：√(n+1)-√n > √(n+2)-√(n+1)

## 第3题

**题目：** 化简：√(a+2√(a-1)) + √(a-2√(a-1))（a≥1）

**解析：** 设 √(a-1)=t，则 a=t²+1
原式 = √(t²+1+2t) + √(t²+1-2t)
= √(t+1)² + √(t-1)²
= |t+1| + |t-1|
= t+1+|t-1|
当 t≥1 即 a≥2 时：= t+1+t-1 = 2t = 2√(a-1)
当 1≤t<1 即 1≤a<2 时：= t+1+1-t = 2

答案：a≥2时2√(a-1), 1≤a<2时2

## 第4题

**题目：** 已知 a = √2 + 1，b = √2 - 1，求 a² + b² 和 b/a + a/b 的值。

**解析：** a²=(√2+1)²=2+2√2+1=3+2√2
b²=(√2-1)²=2-2√2+1=3-2√2
a²+b²=6
ab=(√2+1)(√2-1)=2-1=1
b/a+a/b = (b²+a²)/ab = 6/1 = 6

答案：6, 6

## 第5题

**题目：** 已知 x = √(7+4√3)，求 x - 1/x 的值。

**解析：** 7+4√3 = 4+4√3+3 = (2+√3)²
x = √(2+√3)² = 2+√3
1/x = 1/(2+√3) = (2-√3)/(4-3) = 2-√3
x - 1/x = (2+√3)-(2-√3) = 2√3

答案：2√3
