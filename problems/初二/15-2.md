# 15.2 画轴对称的图形 - 思维训练

## 第1题
**题目：**


 点P(-2,5)关于x轴对称的点P'坐标是多少？关于y轴对称呢？

**解析：** 关于x轴对称：x不变，y变号，P'(-2,-5)。关于y轴对称：y不变，x变号，P'(2,5)。

## 第2题
**题目：** A(1,2)，B(4,3)，在x轴上找一点P，使PA+PB最小。

**解析：** 作A关于x轴的对称点A'(1,-2)。连接A'B，与x轴的交点即为P。直线A'B的方程：过A'(1,-2)和B(4,3)，斜率=5/3，方程y+2=5/3(x-1)。令y=0，得0+2=5/3(x-1)，x-1=6/5，x=11/5。P(11/5,0)。


## 第3题

**题目：** 点 A(1, 2) 关于 x 轴对称的点为 A₁，关于 y 轴对称的点为 A₂，关于原点对称的点为 A₃。求 A₁、A₂、A₃ 的坐标。

**解析：** A₁(1, -2)，A₂(-1, 2)，A₃(-1, -2)。

## 第4题

**题目：** 已知点 A(m, n) 关于 x 轴的对称点在第三象限，求 m、n 的正负。

**解析：** A 关于 x 轴对称的点为 (m, -n)。该点在第三象限，所以 m < 0，-n < 0，即 n > 0。所以 m < 0，n > 0，A 在第二象限。

## 第5题

**题目：** 如图，在 3×3 的正方形网格中，以一条网格线为对称轴，设计一个轴对称图案。

**解析：** 以中间竖线为对称轴，在左侧画一个图形，右侧对称画出即可。注意对应点到对称轴的距离相等。
