# 24.2 数据的离散程度 - 思维训练

## 第1题
**题目：** 数据2,4,6,8,10的平均数=6，求方差。

**解析：** s^2=[(2-6)^2+(4-6)^2+(6-6)^2+(8-6)^2+(10-6)^2]/5=[16+4+0+4+16]/5=40/5=8。

## 第2题
**题目：** 甲乙两名选手比赛成绩的方差分别为s^2甲=1.2，s^2乙=2.5，谁的成绩更稳定？

**解析：** 方差越小越稳定，s^2甲<s^2乙，所以甲的成绩更稳定。


## 第3题

**题目：** 一组数据 2, 3, 5, 7, 8, x 的中位数是 5.5，求 x 的值。

**解析：** 6个数，中位数是第3和第4个数的平均数。(5+x)/2=5.5，5+x=11，x=6。

## 第4题

**题目：** 一组数据 1, 2, 2, 3, 4, 4, 5, 5, 5 的众数、中位数、平均数各是多少？

**解析：** 众数：5（出现3次）。中位数（第5个）：4。平均数=(1+2+2+3+4+4+5+5+5)/9=31/9≈3.44。

## 第5题

**题目：** 已知一组数据 1, 2, 3, 4, 5 的方差为 2，求数据 2, 4, 6, 8, 10 的方差。

**解析：** 新数据 = 原数据×2，方差变为原来的 2²=4倍。2×4=8。


## 第6题

**题目：** 一组数据最大值95，最小值45，组距取10，求组数。

**解析：** (95-45)/10=5，组数=5+1=6组。

## 第7题

**题目：** 某班40人，身高150~160cm的有12人，求此组的频率。

**解析：** 频率=频数/总数=12/40=0.3。

## 第8题

**题目：** 一组数据共50个，分成5组，第1-4组的频数分别为8,12,10,14，求第5组的频数。

**解析：** 第5组频数=50-(8+12+10+14)=6。
