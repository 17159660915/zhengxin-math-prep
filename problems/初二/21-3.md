# 21.3 特殊的平行四边形 - 思维训练

## 第1题
**题目：** 矩形ABCD中，对角线AC、BD交于点O，角AOB=60度，AB=4，求AC。

**解析：** 矩形对角线相等且互相平分。OA=OB=OC=OD。三角形AOB中，OA=OB，角AOB=60度，三角形AOB是等边三角形，OA=AB=4，AC=2OA=8。

## 第2题
**题目：** 菱形ABCD中，对角线AC=6，BD=8，求边长。

**解析：** 菱形对角线互相垂直平分。在Rt三角形AOB中，OA=3，OB=4。AB^2=3^2+4^2=25，AB=5。
