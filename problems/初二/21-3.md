# 21.3 特殊的平行四边形 - 思维训练

## 第1题
**题目：** 矩形ABCD中，对角线AC、BD交于点O，角AOB=60度，AB=4，求AC。

**解析：** 矩形对角线相等且互相平分。OA=OB=OC=OD。三角形AOB中，OA=OB，角AOB=60度，三角形AOB是等边三角形，OA=AB=4，AC=2OA=8。

## 第2题
**题目：** 菱形ABCD中，对角线AC=6，BD=8，求边长。

**解析：** 菱形对角线互相垂直平分。在Rt三角形AOB中，OA=3，OB=4。AB^2=3^2+4^2=25，AB=5。


## 第3题

**题目：** 矩形 ABCD 中，AB = 6，BC = 8，求对角线 AC 的长和 △AOB 的周长。

**解析：** AC = √(AB²+BC²) = √(36+64) = 10。矩形对角线互相平分，OA=OB=5。△AOB 周长 = 6+5+5=16。

## 第4题

**题目：** 菱形 ABCD 的周长为 20，一条对角线 AC = 6，求另一条对角线 BD 的长。

**解析：** 菱形周长20 → 边长=5。菱形对角线互相垂直平分。OA=3，AB=5，OB=√(25-9)=4，BD=8。

## 第5题

**题目：** 正方形 ABCD 中，E 为 BC 上一点，且 BE = 2，EC = 3，求 AE 的长。

**解析：** 正方形边长=5。AB=5，BE=2，Rt△ABE 中，AE = √(25+4) = √29。


## 第6题

**题目：** 矩形ABCD中，AB=6，BC=8，求对角线AC的长和三角形AOB的周长。

**解析：** AC=sqrt(6^2+8^2)=10。OA=OB=5。三角形AOB周长=6+5+5=16。

## 第7题

**题目：** 菱形ABCD的周长为20，一条对角线AC=6，求另一条对角线BD的长。

**解析：** 边长=20/4=5。菱形对角线互相垂直平分。OA=3，AB=5，OB=sqrt(25-9)=4，BD=8。

## 第8题

**题目：** 正方形ABCD中，对角线AC=10，求正方形的边长和面积。

**解析：** 设边长为a，a^2+a^2=10^2，2a^2=100，a^2=50，a=5sqrt(2)。面积=50。
