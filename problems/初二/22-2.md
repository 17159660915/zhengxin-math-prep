# 22.2 函数的表示 - 思维训练

## 第1题
**题目：** 画出函数y=2x+1的图象。

**解析：** 列表（取3个点）：x=-1时y=-1；x=0时y=1；x=1时y=3。描点(-1,-1)、(0,1)、(1,3)，连线（过三点的直线）。

## 第2题
**题目：** 从图象看，y=-x+2当x增大时y如何变化？

**解析：** 图象是下降的直线，当x增大时y减小。


## 第3题

**题目：** 用列表法和图象法表示函数 y = 2x - 1，x 取 -2, -1, 0, 1, 2。

**解析：** 列表：x=-2,y=-5；x=-1,y=-3；x=0,y=-1；x=1,y=1；x=2,y=3。图象：在坐标系中描出这5个点，连线得一条直线。

## 第4题

**题目：** 已知函数 y = kx + b，当 x=1 时 y=3，当 x=-2 时 y=-3，求 k、b 的值。

**解析：** k+b=3，-2k+b=-3。相减：3k=6，k=2。代入：2+b=3，b=1。函数为 y=2x+1。

## 第5题

**题目：** 已知函数 y = √(x-2)，求 x 的取值范围，并判断 y 是否为 x 的函数。

**解析：** x-2 ≥ 0，x ≥ 2。对于每个 x ≥ 2，y 有唯一确定的值，y 是 x 的函数。
