# 23.3 一次函数与方程(组)不等式 - 思维训练

## 第1题
**题目：** 一次函数y=3x-6与x轴的交点坐标是多少？方程3x-6=0的解是多少？


**解析：** 令y=0，3x-6=0，x=2。交点坐标(2,0)，方程的解为x=2。

## 第2题
**题目：** **题目：** 已知直线 y = kx + 3 与 y = -x + 1 平行，求 k 的值，并求这两条直线与 y 轴围成的面积。

**解析：** 平行则斜率相等，k = -1。与 y 轴交点分别是 (0,3) 和 (0,1)，底边 = 2，高 = 2/2，面积 = 2 x 1 / 2 = 1。
## 第3题

**题目：** 利用一次函数 y = 2x - 4 的图象，解不等式 2x - 4 > 0。

**解析：** 图象与 x 轴交于点 (2, 0)。图象在 x 轴上方的部分对应 2x-4>0，即 x > 2。

## 第4题

**题目：** 已知一次函数 y = kx + b 的图象经过点 (2, 6) 且与直线 y = -x + 3 平行，求函数的解析式。

**解析：** 两直线平行，k 相等。k = -1。代入点 (2, 6)：6 = -1×2 + b，b = 8。y = -x + 8。

## 第5题

**题目：** 一次函数 y = 2x + 1 与 y = -x + 4 的图象相交于点 P。求点 P 的坐标，并判断点 P 在第几象限。

**解析：** 2x+1 = -x+4 → 3x=3 → x=1。y=2×1+1=3。P(1, 3) 在第一象限。



## 第6题

**题目：** 一次函数 y = 2x - 8 与 y 轴的交点坐标是多少？方程 2x - 8 = 0 的解是多少？两者有什么关系？

**解析：** 与 y 轴交点：x = 0，y = -8，交点 (0, -8)。方程 2x - 8 = 0 的解是 x = 4。函数与 x 轴的交点横坐标就是方程的解。

## 第7题

**题目：** 求直线 y = 2x + 1 与 y = -x + 4 的交点坐标，并求这两条直线与 x 轴围成的三角形面积。

**解析：** 联立 2x + 1 = -x + 4，3x = 3，x = 1，y = 3，交点 (1,3)。与 x 轴交点：y=2x+1 过 (-0.5, 0)，y=-x+4 过 (4, 0)。底边 = 4 - (-0.5) = 4.5，高 = 3。面积 = (1/2) x 4.5 x 3 = 6.75。

## 第7题

**题目：** 求直线y=x+2与y=-x+4的交点坐标。

**解析：** x+2=-x+4，2x=2，x=1，y=3。交点(1,3)。

## 第8题

**题目：** 已知直线 y = kx + 3 与 y = -x + 1 平行，求 k 的值，并求这两条直线与 y 轴围成的面积。

**解析：** 平行则斜率相等，k = -1。两条直线为 y = -x + 3 和 y = -x + 1。与 y 轴交点分别是 (0,3) 和 (0,1)，距离为 2。两条平行线之间的距离为 2/2 = 2。面积 = 2 x 2 / 2 = 2。
