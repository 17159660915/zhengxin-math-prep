## 第1题

**题目：** 一组数据 2, 4, 6, 8, x 的平均数等于中位数，求 x 的所有可能值。

**解析：** 平均数 = (2+4+6+8+x)/5 = (20+x)/5
排序后找中位数：
若 x≤2：2,4,6,8,x → 排序：x,2,4,6,8 中位数=4 → (20+x)/5=4 → x=0
若 2<x≤4：2,x,4,6,8 中位数=4 → x=0（不符合）
若 4<x≤6：2,4,x,6,8 中位数=x → (20+x)/5=x → 20+x=5x → x=5
若 6<x≤8：2,4,6,x,8 中位数=6 → (20+x)/5=6 → x=10（不符合）
若 x>8：2,4,6,8,x 中位数=6 → x=10

答案：x=0, 5, 10

## 第2题

**题目：** 已知数据 x₁, x₂, ..., xₙ 的平均数是 x̄，方差是 S²。求数据 2x₁+3, 2x₂+3, ..., 2xₙ+3 的平均数和方差。

**解析：** 平均数 = 2x̄+3
方差 = 4S²

答案：平均数为2x̄+3，方差为4S²

## 第3题

**题目：** 某班 40 人，数学成绩平均分为 80 分，其中 20 名男生的平均分为 75 分，求女生平均分。

**解析：** 总分 = 40×80 = 3200
男生总分 = 20×75 = 1500
女生总分 = 3200-1500 = 1700
女生平均分 = 1700/20 = 85

答案：85分

## 第4题

**题目：** 一组数据的中位数是 15，众数是 18，平均数是 16。已知这组数据有 5 个数，且都是整数，求这组数据。

**解析：** 5个数，中位数是第3个=15
众数是18，出现至少2次
平均数是16，总和=80
设五数为 a,b,15,18,18（18出现两次）
a+b+15+18+18=80, a+b=29
a,b 都小于15（否则中位数不是15）
且 a,b 都不等于18（否则众数更多）
→ a=14, b=15
但15已出现，不符。
尝试：a,b,15,18,c 且 c=18或15
若c=18：a+b+15+18+18=80, a+b=29
a,b<15且整数，a=14,b=15（15重复）
数据：14,15,15,18,18
中位数=15, 众数=15和18(双), 平均=16

答案：14,15,15,18,18

## 第5题

**题目：** 已知数据 a, b, c 的方差为 2，求数据 2a, 2b, 2c 的方差。

**解析：** 方差的性质：数据乘以 k，方差变为 k² 倍
2a,2b,2c 的方差 = 2²×2 = 8

答案：8
