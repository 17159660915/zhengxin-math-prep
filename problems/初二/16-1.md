## 第1题

**题目：** 已知 2x + 3y = 5，xy = 1，求 4x² + 9y² 的值。

**解析：** 4x²+9y² = (2x)²+(3y)² = (2x+3y)² - 2·2x·3y
= 5² - 12xy = 25 - 12 = 13

答案：13

---

## 第2题

**题目：** 已知 3ⁿ = a，2ⁿ = b，求 6ⁿ⁺¹ 的值（用 a、b 表示）。

**解析：** 6ⁿ⁺¹ = 6ⁿ × 6 = (3×2)ⁿ × 6 = 3ⁿ×2ⁿ×6 = 6ab

答案：6ab

## 第3题

**题目：** 已知 x + 1/x = 3，求 x² + 1/x² 和 x⁴ + 1/x⁴ 的值。

**解析：** x²+1/x² = (x+1/x)² - 2 = 3² - 2 = 7
x⁴+1/x⁴ = (x²+1/x²)² - 2 = 7² - 2 = 47

答案：7, 47

## 第4题

**题目：** 已知 a + b = 5，ab = 3，求 a³ + b³ 的值。

**解析：** a³+b³ = (a+b)³ - 3ab(a+b) = 5³ - 3×3×5 = 125 - 45 = 80

答案：80

## 第5题

**题目：** 已知 2x² - 3x + 1 = 0，求 4x⁴ - 6x³ + 2x² 的值。

**解析：** 4x⁴-6x³+2x² = 2x²(2x²-3x+1) = 2x²×0 = 0

答案：0
