# 18.2 分式的乘法与除法 - 思维训练

## 第1题
**题目：** 计算(x^2-y^2)/x^2 * x/(x+y)。

**解析：** 分子=(x+y)(x-y)。原式=(x+y)(x-y)/x^2 * x/(x+y)=(x-y)/x。

## 第2题
**题目：** 计算(x^2-4)/(x^2-1) / (x+2)/(x+1)。

**解析：** 原式=(x^2-4)/(x^2-1) * (x+1)/(x+2)=(x+2)(x-2)/[(x+1)(x-1)] * (x+1)/(x+2)=(x-2)/(x-1)。


## 第3题

**题目：** 计算：(a²-4)/(a²+2a) ÷ (a-2)/a。

**解析：** [(a+2)(a-2)]/[a(a+2)] × a/(a-2) = (a-2)/a × a/(a-2) = 1。

## 第4题

**题目：** 计算：1/(x-1) - 1/(x+1) - 2/(x²-1)。

**解析：** 1/(x-1) - 1/(x+1) = (x+1-x+1)/(x²-1) = 2/(x²-1)。2/(x²-1) - 2/(x²-1) = 0。

## 第5题

**题目：** 已知 1/a + 1/b = 3，求 (a+2ab+b)/(a-3ab+b) 的值。

**解析：** 1/a + 1/b = (a+b)/ab = 3，a+b = 3ab。原式 = (a+b+2ab)/(a+b-3ab) = (3ab+2ab)/(3ab-3ab) = 5ab/0，分母为0，值不存在。
