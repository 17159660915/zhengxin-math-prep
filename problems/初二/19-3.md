# 19.3 二次根式的加法与减法 - 思维训练

## 第1题
**题目：** 计算根号12+根号27-根号48。

**解析：** 根号12=2根号3，根号27=3根号3，根号48=4根号3。原式=2根号3+3根号3-4根号3=根号3。

## 第2题
**题目：** 计算(根号8+根号3)-(根号12-根号2)。

**解析：** =根号8+根号3-根号12+根号2=2根号2+根号3-2根号3+根号2=(2根号2+根号2)+(根号3-2根号3)=3根号2-根号3。


## 第3题

**题目：** 计算：(√8 + √18) × √2。

**解析：** (√8+√18)×√2 = √8×√2 + √18×√2 = √16 + √36 = 4+6 = 10。

## 第4题

**题目：** 已知 x = √3 + 1，求 x² - 2x + 1 的值。

**解析：** x² - 2x + 1 = (x-1)² = (√3+1-1)² = (√3)² = 3。

## 第5题

**题目：** 比较大小：√7 + √3 与 √5 + √5。

**解析：** 两边平方：(√7+√3)² = 10+2√21，(√5+√5)² = 10+2√25 = 20。√21 < 5 = √25，所以 10+2√21 < 20，√7+√3 < √5+√5。
