## 第1题

**题目：**

 三角形两边长分别为 5 和 8，第三边长为整数，且周长为奇数，求第三边的长。

**解析：** 第三边 x 的范围：8-5 < x < 8+5 → 3 < x < 13
整数 x 可取：4,5,6,7,8,9,10,11,12
周长 = 5+8+x = 13+x 为奇数，所以 x 为偶数
x 可取：4,6,8,10,12

答案：4, 6, 8, 10, 12

---

## 第2题

**题目：** 在 △ABC 中，AD 是中线，AB = 8，AC = 6，求 △ABD 与 △ACD 的周长差。

**解析：** AD 是中线 → BD = CD
△ABD 周长 = AB+AD+BD
△ACD 周长 = AC+AD+CD
周长差 = AB-AC = 8-6 = 2

答案：2

---

## 第3题

**题目：** 已知等腰三角形的一边长为 5，另一边长为 11，求这个等腰三角形的周长。

**解析：** 分两种情况：
① 腰=5，底=11 → 5+5<11，不满足三角形三边关系
② 腰=11，底=5 → 11+11>5, 11+5>11，成立
周长 = 11+11+5 = 27

答案：27

## 第4题

**题目：** 在 △ABC 中，∠A = 50°，∠B = 60°，CD 是 ∠ACB 的平分线，求 ∠ADC 的度数。

**解析：** ∠C = 180°-50°-60° = 70°
CD 平分 ∠C → ∠ACD = 35°
∠ADC = 180°-∠A-∠ACD = 180°-50°-35° = 95°

答案：95°

## 第5题

**题目：** 在 △ABC 中，AB = AC，BD 是 AC 边上的中线，将 △ABC 的周长分成 15 和 18 两部分，求各边长。

**解析：** 设 AB=AC=2x，AD=DC=x，BC=y
情况①：AB+AD=15, BC+CD=18
2x+x=15 → 3x=15 → x=5, AB=AC=10
y+5=18 → y=13, BC=13
10+10>13, 10+13>10 ✅

情况②：AB+AD=18, BC+CD=15
3x=18 → x=6, AB=AC=12
y+6=15 → y=9, BC=9
12+12>9, 12+9>12 ✅

答案：10,10,13 或 12,12,9

## 第6题

**题目：** 三角形两边长5和8，第三边为整数且周长为奇数，求第三边。

**解析：** 第三边范围3<x<13，整数4~12。周长为奇数->5+8+x为奇数->x为偶数。x=4,6,8,10,12。

## 第7题

**题目：** 等腰三角形一边长5另一边长11，求周长。

**解析：** 若5为腰则5+5<11不构成三角形。所以腰为11，底为5，周长=11+11+5=27。

## 第8题

**题目：** 三角形ABC中AB=AC，BD是中线，将周长分为12和15两部分，求腰长。

**解析：** 设腰长2x，底y。若AB+AD=12，BC+CD=15则3x=12，x=4，腰8，底11。若AB+AD=15，BC+CD=12则3x=15，x=5，腰10，底7。
