# 23.4 实际问题与一次函数 - 思维训练

## 第1题
**题目：** 某出租车起步价8元（含3km），超过3km后每公里2元。写出费用y（元）与路程x（km）的函数关系式。

**解析：** 当0<x<=3时，y=8。当x>3时，y=8+2(x-3)=2x+2。

## 第2题
**题目：** A方案：月租20元，每分钟0.1元。B方案：无月租，每分钟0.3元。每月通话x分钟，哪种方案更划算？

**解析：** A：y1=20+0.1x，B：y2=0.3x。令y1=y2，20+0.1x=0.3x，20=0.2x，x=100。当x<100时B更划算，x=100时两者相同，x>100时A更划算。


## 第3题

**题目：** 某地出租车收费标准：起步价 8 元（含 3km），超过 3km 后每公里 2 元。写出车费 y（元）与行驶里程 x（km）的函数关系式。

**解析：** 当 0 < x ≤ 3 时，y = 8。当 x > 3 时，y = 8 + 2(x-3) = 2x + 2。

## 第4题

**题目：** 某公司每月手机话费方案：月租 30 元，通话 0.2 元/分钟。写出月话费 y（元）与通话时间 x（分钟）的函数关系式。若某月通话 500 分钟，需交多少话费？

**解析：** y = 30 + 0.2x。x=500时，y=30+0.2×500=130元。

## 第5题

**题目：** 弹簧原长 10cm，每挂 1kg 物体伸长 0.5cm。求弹簧总长 y（cm）与所挂物体质量 x（kg）的函数关系式，并求 x 的取值范围。

**解析：** y = 10 + 0.5x。x ≥ 0（质量不能为负）。


## 第6题

**题目：** 某出租车起步价8元（含3km），超过3km后每公里2元。写出费用y（元）与路程x（km）的函数关系式。

**解析：** y=8 (x<=3)，y=8+2(x-3)=2x+2 (x>3)。

## 第7题

**题目：** A方案：月租20元，每分钟0.1元。B方案：无月租，每分钟0.3元。每月通话x分钟，哪种方案更划算？

**解析：** A:y=20+0.1x，B:y=0.3x。20+0.1x=0.3x，20=0.2x，x=100。x<100时B划算，x>100时A划算。
