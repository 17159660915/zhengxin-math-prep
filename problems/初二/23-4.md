# 23.4 实际问题与一次函数 - 思维训练

## 第1题
**题目：** 某出租车起步价8元（含3km），超过3km后每公里2元。写出费用y（元）与路程x（km）的函数关系式。

**解析：** 当0<x<=3时，y=8。当x>3时，y=8+2(x-3)=2x+2。

## 第2题
**题目：** **题目：** 某学校图书馆有座位 200 个，每天开放期间每张桌子坐 4 人。设开放 x 小时，每小时平均有 30 人进馆，每人平均停留 2 小时。写出馆内人数 y 与时间 x 的函数关系式。

**解析：** 每小时进馆 30 人，离馆 30 人（2小时前进入的），净增为 0。y = 60 人（恒定）。x >= 2 时馆内稳定在 60 人。
## 第3题

**题目：** 某地出租车收费标准：起步价 8 元（含 3km），超过 3km 后每公里 2 元。写出车费 y（元）与行驶里程 x（km）的函数关系式。

**解析：** 当 0 < x ≤ 3 时，y = 8。当 x > 3 时，y = 8 + 2(x-3) = 2x + 2。

## 第4题

**题目：** 某公司每月手机话费方案：月租 30 元，通话 0.2 元/分钟。写出月话费 y（元）与通话时间 x（分钟）的函数关系式。若某月通话 500 分钟，需交多少话费？

**解析：** y = 30 + 0.2x。x=500时，y=30+0.2×500=130元。

## 第5题

**题目：** 弹簧原长 10cm，每挂 1kg 物体伸长 0.5cm。求弹簧总长 y（cm）与所挂物体质量 x（kg）的函数关系式，并求 x 的取值范围。

**解析：** y = 10 + 0.5x。x ≥ 0（质量不能为负）。



## 第6题

**题目：** 某水龙头每秒钟漏水 0.05 毫升，设 t 秒后漏水量为 y 毫升。写出 y 与 t 的函数关系式，并求 1 小时后漏了多少水。

**解析：** y = 0.05t。1 小时 = 3600 秒，y = 0.05 x 3600 = 180 毫升。

## 第7题

**题目：** 某停车场收费标准：前 1 小时收费 5 元，之后每半小时收费 2 元（不足半小时按半小时算）。写出停车时间 t（小时）与费用 y（元）的函数关系式（t 为整数小时）。

**解析：** 当 t = 1 时，y = 5。当 t > 1 时，y = 5 + 4(t-1) = 4t + 1。所以 y = { 5（t=1），4t+1（t是大于1的整数）}。

## 第7题

**题目：** A方案：月租20元，每分钟0.1元。B方案：无月租，每分钟0.3元。每月通话x分钟，哪种方案更划算？

**解析：** A:y=20+0.1x，B:y=0.3x。20+0.1x=0.3x，20=0.2x，x=100。x<100时B划算，x>100时A划算。

## 第8题

**题目：** 某学校图书馆有座位 200 个，每天开放期间每张桌子坐 4 人。设开放 x 小时，每小时平均有 30 人进馆，每人平均停留 2 小时。写出馆内人数 y 与时间 x 的函数关系式（x 为整数小时）。

**解析：** 每小时进馆 30 人，离开人数 = 30（2小时前进入的人），所以净增 = 0。y = 30 x 2 = 60 人（恒定）。只要 x >= 2，馆内人数稳定在 60 人，不会达到 200 人上限。
