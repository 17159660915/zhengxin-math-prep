# 24.3 数据的四分位数 - 思维训练

## 第1题
**题目：** 数据1,3,5,7,9,11,13,15，求Q1、Q2、Q3。

**解析：** 排序后共8个数据。Q2=(7+9)/2=8（中位数）。Q1=(3+5)/2=4。Q3=(11+13)/2=12。

## 第2题
**题目：** 一组数据的Q1=20，Q3=60，求四分位距。

**解析：** 四分位距=Q3-Q1=60-20=40。


## 第3题

**题目：** 一组数据 5, 7, 9, 11, 13 的方差是多少？

**解析：** 平均数 = (5+7+9+11+13)/5 = 9。方差 = [(5-9)²+(7-9)²+(9-9)²+(11-9)²+(13-9)²]/5 = (16+4+0+4+16)/5 = 40/5 = 8。

## 第4题

**题目：** 甲、乙两组各 5 名学生的成绩：甲：85, 90, 90, 95, 100；乙：88, 89, 90, 91, 92。哪组成绩更稳定？

**解析：** 甲平均=92，甲方差=26。乙平均=90，乙方差=2。乙的方差更小，乙组更稳定。

## 第5题

**题目：** 数据 x₁, x₂, ..., xₙ 的平均数为 x̄，方差为 S²。求数据 3x₁+2, 3x₂+2, ..., 3xₙ+2 的平均数和方差。

**解析：** 平均数 = 3x̄+2，方差 = 3²×S² = 9S²。
