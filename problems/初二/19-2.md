# 19.2 二次根式的乘法与除法 - 思维训练

## 第1题
**题目：** 计算根号12乘根号3。

**解析：** 根号12乘根号3=根号(12*3)=根号36=6。

## 第2题
**题目：** 分母有理化：1/(根号5+根号2)。

**解析：** 1/(根号5+根号2)=(根号5-根号2)/[(根号5+根号2)(根号5-根号2)]=(根号5-根号2)/(5-2)=(根号5-根号2)/3。


## 第3题

**题目：** 计算：√12 × √27 ÷ √3。

**解析：** √12×√27÷√3 = √(12×27÷3) = √108 = 6√3。

## 第4题

**题目：** 化简：√(45) + √(80) - √(125)。

**解析：** √45 = 3√5，√80 = 4√5，√125 = 5√5。原式 = 3√5+4√5-5√5 = 2√5。

## 第5题

**题目：** 分母有理化：1/(√2+√3) + 1/(√3+√4) + 1/(√4+√5)。

**解析：** 1/(√2+√3) = √3-√2，1/(√3+√4) = √4-√3，1/(√4+√5) = √5-√4。相加得 √5-√2。


## 第6题

**题目：** 计算：sqrt(12)*sqrt(3)-sqrt(27)

**解析：** =sqrt(36)-3sqrt(3)=6-3sqrt(3)

## 第8题

**题目：** 比较大小：2sqrt(3) 与 3sqrt(2)（不用计算器）

**解析：** (2sqrt(3))^2=12，(3sqrt(2))^2=18。12<18，所以2sqrt(3)<3sqrt(2)。
