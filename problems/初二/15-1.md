## 第1题

**题目：** 在 △ABC 中，AB = AC，∠A = 40°，点 D 在 BC 上，且 AD = BD，求 ∠ADC 的度数。

**解析：** AB=AC → ∠B=∠C=(180°-40°)/2=70°
AD=BD → ∠BAD=∠B=70°
但 ∠BAD+∠B+∠BDA=180°，∠BAD=70°, ∠B=70° → ∠BDA=40°
∠ADC = 180°-∠BDA = 140°

答案：140°

## 第2题

**题目：** 在 △ABC 中，AB = AC，∠BAC = 120°，D 是 BC 上一点，且 AD ⊥ BC，求 BD 与 CD 的关系。


**解析：** AB=AC → △ABC 是等腰三角形
AD ⊥ BC → AD 是底边上的高
等腰三角形三线合一 → AD 也是中线
∴ BD = CD

答案：BD = CD

## 第3题

**题目：** 已知点 P 在 ∠AOB 内部，且到角两边 OA、OB 的距离相等，∠AOB = 60°，OP = 10，求点 P 到 OA 的距离。

**解析：** P 到 OA、OB 距离相等 → P 在 ∠AOB 的平分线上
∠AOP = 30°
过 P 作 PC ⊥ OA 于 C
在 Rt△OPC 中，∠POC = 30°，OP = 10
PC = OP × sin30° = 10 × 1/2 = 5

答案：5

## 第4题

**题目：** 在 △ABC 中，AB = AC，D 是 AB 上一点，E 是 AC 延长线上一点，且 BD = CE，DE 交 BC 于 F。求证：DF = EF。

**解析：** 过 D 作 DG ∥ AC 交 BC 于 G。
AB=AC → ∠B=∠ACB
DG∥AC → ∠DGB=∠ACB=∠B
∴ DB=DG
又 BD=CE → DG=CE
∵ DG∥AC → ∠GDF=∠E, ∠DGF=∠ECF
在 △DGF 和 △ECF 中：
DG=CE, ∠GDF=∠E, ∠DGF=∠ECF
∴ △DGF ≌ △ECF（ASA）
∴ DF=EF

答案：DF = EF

## 第5题

**题目：** 在 △ABC 中，AB = AC，∠BAC = 90°，D 是 BC 的中点，E 是 AB 上一点，F 是 AC 上一点，且 DE ⊥ DF。求证：BE = AF。

**解析：** 连接 AD。
等腰直角三角形，D 是斜边中点
∴ AD ⊥ BC, AD = BD = CD, ∠BAD = ∠CAD = 45°
∠BDE + ∠EDA = 90° = ∠FDA + ∠EDA
∴ ∠BDE = ∠FDA
在 △BDE 和 △ADF 中：
∠B = ∠DAF = 45°, BD = AD, ∠BDE = ∠FDA
∴ △BDE ≌ △ADF（ASA）
∴ BE = AF

答案：BE = AF

## 第6题

**题目：** 在△ABC中AB=AC，∠A=40度，D在BC上且AD=BD。求∠C的度数。

**解析：** ∠B=∠C=(180-40)/2=70度。AD=BD->∠BAD=∠B=70度，矛盾因为∠A=40度。所以D在BC上但AD=BD不成立。需重新分析：设∠C=x，∠B=x。AD=BD->∠BAD=x。x+40+x=180，x=70。∠C=70度。

## 第7题

**题目：** 在△ABC中AB=AC，∠BAC=120度，D是BC上一点且AD=BD。求∠ADC。

**解析：** ∠B=∠C=(180-120)/2=30度。AD=BD->∠BAD=∠B=30度。∠DAC=120-30=90度。∠ADC=180-90-30=60度。

## 第8题

**题目：** 在△ABC中AB=AC，D是AB上一点，E是AC延长线上一点且BD=CE。求证DE被BC平分。

**解析：** 过D作DF∥AC交BC于F。∠DFB=∠ACB=∠B，DF=DB=CE。△DFG≌△ECG(AAS)。DG=GE。
