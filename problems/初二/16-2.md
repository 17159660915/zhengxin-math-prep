# 16.2 整式的乘法 - 思维训练

## 第1题
**题目：** 计算(-2ab)*(3a^2b-2ab^2+1)。

**解析：** (-2ab)*3a^2b=-6a^3b^2，(-2ab)*(-2ab^2)=4a^2b^3，(-2ab)*1=-2ab。结果=-6a^3b^2+4a^2b^3-2ab。

## 第2题
**题目：** 计算(x-3)(2x+1)。

**解析：** (x-3)(2x+1)=x*2x+x*1-3*2x-3*1=2x^2+x-6x-3=2x^2-5x-3。


## 第3题

**题目：** 计算：(x+1)(x+2)(x+3)。

**解析：** (x+1)(x+2)(x+3) = [(x+1)(x+2)](x+3) = (x²+3x+2)(x+3) = x³+3x²+3x²+9x+2x+6 = x³+6x²+11x+6。

## 第4题

**题目：** 已知 (x² + px + 8)(x² - 3x + q) 的展开式中不含 x³ 项和 x 项，求 p、q 的值。

**解析：** 展开式中 x³ 项系数：-3+p，x 项系数：8×(-3)+p×q = -24+pq。不含 x³ 项则 -3+p=0，p=3。不含 x 项则 -24+pq=0，q=8。

## 第5题

**题目：** 计算：123456² - 123455×123457。

**解析：** 设 a = 123456，原式 = a² - (a-1)(a+1) = a² - (a²-1) = 1。


## 第6题

**题目：** 计算：(-2x^2y)^3 * (3xy^2)^2

**解析：** =(-8x^6y^3)*(9x^2y^4)=-72x^8y^7

## 第7题

**题目：** 已知 2^m=3，2^n=5，求 2^(m+n) 和 2^(2m-n) 的值。

**解析：** 2^(m+n)=2^m*2^n=3*5=15。2^(2m-n)=2^(2m)/2^n=(2^m)^2/2^n=9/5=1.8。

## 第8题

**题目：** 计算：(-a)^3 * a^2 + (-a^3)^2 - a^7 / a^2

**解析：** =-a^3*a^2+a^6-a^5=-a^5+a^6-a^5=a^6-2a^5
