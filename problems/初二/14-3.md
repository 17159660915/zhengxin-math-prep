# 14.3 角的平分线 - 思维训练

## 第1题
**题目：** OC平分角AOB，P在OC上，PD垂直于OA，PE垂直于OB，PD=5，求PE。

![角平分线](problems-diagrams/p2-14-3-q1.png)

**解析：** 角平分线上的点到角两边距离相等。PE=PD=5。

## 第2题
**题目：** 点P在角AOB内部，PD垂直于OA，PE垂直于OB，PD=PE，能否判断P在角AOB的平分线上？

![角平分线](problems-diagrams/p2-14-3-q1.png)

**解析：** 能。角的内部到角两边距离相等的点在角的平分线上。
