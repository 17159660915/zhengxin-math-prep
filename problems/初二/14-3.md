# 14.3 角的平分线 - 思维训练

## 第1题
**题目：** OC平分角AOB，P在OC上，PD垂直于OA，PE垂直于OB，PD=5，求PE。


**解析：** 角平分线上的点到角两边距离相等。PE=PD=5。

## 第2题
**题目：** **题目：** 三角形 ABC 中，角 B = 60，角 C = 40，AD 平分角 A 交 BC 于 D。求角 ADB 的度数。

**解析：** A = 180 - 60 - 40 = 80。AD 平分 A，BAD = 40。在 ABD 中，ADB = 180 - 60 - 40 = 80。
## 第3题

**题目：** 如图，点 P 在 ∠AOB 的内部，且 P 到 OA、OB 的距离相等。求证：OP 平分 ∠AOB。

**解析：** 作 PC ⊥ OA 于 C，PD ⊥ OB 于 D。PC = PD，OP = OP。Rt△OCP ≌ Rt△ODP（HL），∠COP = ∠DOP，OP 平分 ∠AOB。

## 第4题

**题目：** △ABC 中，∠A = 60°，∠B 和 ∠C 的平分线相交于点 O。求 ∠BOC 的度数。

**解析：** ∠BOC = 90° + 1/2∠A = 90° + 30° = 120°。

## 第5题

**题目：** 如图，△ABC 中，∠C = 90°，AD 平分 ∠BAC，BD = 10，CD = 6，求点 D 到 AB 的距离。

**解析：** 角平分线性质：角平分线上的点到角两边的距离相等。D 到 AB 的距离 = D 到 AC 的距离 = CD = 6。



## 第6题

**题目：** 已知 AOB = 60，OC 平分 AOB，点 P 在 OC 上，PD 垂直于 OA 于 D，PE 垂直于 OB 于 E。求证 PD = PE。

**解析：** 角平分线上的点到角两边的距离相等。OC 平分 AOB，P 在 OC 上，所以 PD = PE。

## 第7题

**题目：** 三角形 ABC 中，角平分线 AD 交 BC 于 D，且 AB = 7，AC = 5，BC = 6。求 BD 和 DC 的长。

**解析：** 角平分线定理：BD/DC = AB/AC = 7/5。设 BD = 7k，DC = 5k，则 7k + 5k = 6，12k = 6，k = 0.5。BD = 3.5，DC = 2.5。

## 第7题

**题目：** 点P在角AOB内部，PD垂直于OA，PE垂直于OB，PD=PE，能否判断P在角AOB的平分线上？

**解析：** 能。到角两边距离相等的点在这个角的平分线上。
