## 第1题

**题目：** 已知 1/a + 1/b = 1/6，1/b + 1/c = 1/9，1/c + 1/a = 1/15，求 abc/(ab+bc+ca) 的值。

**解析：** 三式相加：2(1/a+1/b+1/c) = 1/6+1/9+1/15 = (15+10+6)/90 = 31/90
1/a+1/b+1/c = 31/180
所求 = abc/(ab+bc+ca) = 1/(1/a+1/b+1/c) = 180/31

答案：180/31

## 第2题

**题目：** 已知 x² - 3x + 1 = 0，求 x² + 1/x² 的值。

**解析：** x²-3x+1=0，x≠0，两边除以x：x-3+1/x=0, x+1/x=3
x²+1/x² = (x+1/x)²-2 = 9-2 = 7

答案：7

---

## 第3题

**题目：** 若分式 (x² - 4)/(x² - x - 2) 的值为 0，求 x 的值。

**解析：** 分式为0 → 分子=0且分母≠0
x²-4=0 → x=±2
x=-2时分母=4+2-2=4≠0，可取
x=2时分母=4-2-2=0，增根舍去

答案：x=-2

## 第4题

**题目：** 已知 a + b + c = 0，求 a/(b+c) + b/(c+a) + c/(a+b) 的值。

**解析：** a+b+c=0 → b+c=-a, c+a=-b, a+b=-c
原式 = a/(-a) + b/(-b) + c/(-c) = -1-1-1 = -3

答案：-3

## 第5题

**题目：** 解方程：1/(x+1) + 1/(x+2) = 1/(x+3) + 1/(x+4)

**解析：** 两边通分：
(2x+3)/(x²+3x+2) = (2x+7)/(x²+7x+12)
(2x+3)(x²+7x+12) = (2x+7)(x²+3x+2)
展开化简得：2x²+10x+11=0
x = [-10±√(100-88)]/4 = [-10±√12]/4 = (-5±√3)/2
验根：所有分母不为0，成立。

答案：x=(-5±√3)/2
