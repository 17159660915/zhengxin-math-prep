# 14.2 三角形全等的判定 - 思维训练

## 第1题
**题目：** AB=DE，BC=EF，角B=角E，三角形ABC和三角形DEF全等吗？用的是哪种判定？


**解析：** AB=DE，角B=角E，BC=EF，两边及其夹角对应相等，三角形ABC全等于三角形DEF（SAS）。

## 第2题
**题目：** **题目：** 在 ABC 中，AB = AC，D 是 BC 中点，连接 AD。求证：AD 平分 BAC。

**解析：** AB = AC（已知），BD = CD（D 是中点），AD = AD（公共边）。ABD ≅ ACD（SSS），所以 BAD = CAD，AD 平分 BAC。
## 第3题

**题目：** 如图，AB = AC，D 是 BC 上一点，且 AD = BD。求证：∠C = ∠BAD。

**解析：** AB = AC → ∠B = ∠C。AD = BD → ∠B = ∠BAD。所以 ∠C = ∠BAD。

## 第4题

**题目：** 如图，△ABC 中，∠C = 90°，D 是 AB 上一点，且 CD = BD。求证：D 是 AB 的中点。

**解析：** CD = BD → ∠B = ∠BCD。∠B + ∠A = 90°，∠BCD + ∠ACD = 90°。所以 ∠A = ∠ACD，AD = CD。又 CD = BD，所以 AD = BD，D 是 AB 中点。

## 第5题

**题目：** 如图，AC = BD，AB = CD。求证：△ABC ≌ △DCB。

**解析：** AC = BD，AB = CD，BC = CB（公共边），所以 △ABC ≌ △DCB（SSS）。



## 第6题

**题目：** 在 ABC 和 DEF 中，AB = DE，AC = DF，BC = EF，那么 ABC 和 DEF 的关系是什么？如果 ABC 的周长为 18，AB = 5，BC = 7，求 AC 的长。

**解析：** 三边对应相等，两个三角形全等（SSS）。AC = 18 - 5 - 7 = 6。

## 第7题

**题目：** 如图，在四边形 ABCD 中，AB = AD，BC = DC，AC 是公共边。ABC 和 ADC 全等吗？为什么？

**解析：** 全等（SSS）。AB = AD（已知），BC = DC（已知），AC = AC（公共边）。所以 ABC ≅ ADC。

## 第7题

**题目：** 角A=角D，角B=角E，AC=DF，三角形ABC和三角形DEF全等吗？

**解析：** 全等。AAS判定：两角及其中一角的对边对应相等。
