# 8.2 立方根 - 思维训练

## 第1题
**题目：** 已知 ³√x = -3，求 x 的值。若 ³√(x + 2) = 4，求 x 的值。

**解析：** ³√x = -3 → x = (-3)³ = -27。³√(x + 2) = 4 → x + 2 = 64 → x = 62。

## 第2题
**题目：** 比较 ³√25 和 3 的大小。比较 ³√(-10) 和 -2 的大小。

**解析：** 3³ = 27，25 < 27，所以 ³√25 < ³√27 = 3，即 ³√25 < 3。(-2)³ = -8，-10 < -8，所以 ³√(-10) < ³√(-8) = -2，即 ³√(-10) < -2。
