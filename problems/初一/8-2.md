# 8.2 立方根 - 思维训练

## 第1题
**题目：** 已知 ³√x = -3，求 x 的值。若 ³√(x + 2) = 4，求 x 的值。

**解析：** ³√x = -3 → x = (-3)³ = -27。³√(x + 2) = 4 → x + 2 = 64 → x = 62。

## 第2题
**题目：** 比较 ³√25 和 3 的大小。比较 ³√(-10) 和 -2 的大小。

**解析：** 3³ = 27，25 < 27，所以 ³√25 < ³√27 = 3，即 ³√25 < 3。(-2)³ = -8，-10 < -8，所以 ³√(-10) < ³√(-8) = -2，即 ³√(-10) < -2。


## 第3题

**题目：** 判断：① 8 的立方根是 ±2？② 负数没有立方根？③ 立方根等于它本身的数有 0 和 ±1？

**解析：** ①×，8的立方根是2，不是±2（平方根才有±）。②×，负数有立方根，如-8的立方根是-2。③√，0³=0，1³=1，(-1)³=-1。

## 第4题

**题目：** 已知 x³ = 64，y² = 25，求 x + y 的立方根。

**解析：** x = ³√64 = 4，y = ±5。x+y = 4+5=9 或 4-5=-1。9的立方根 = ³√9，-1的立方根 = -1。

## 第5题

**题目：** 若 ³√x + ³√-x = 0 对任意实数 x 都成立吗？请说明理由。

**解析：** 成立。因为 ³√-x = -³√x（立方根的性质），所以 ³√x + ³√-x = ³√x - ³√x = 0，对任意实数 x 都成立。


## 第6题

**题目：** 已知 sqrt(x-2) + |y+3| = 0，求 x 和 y 的值。

**解析：** sqrt(x-2) >= 0，|y+3| >= 0，两个非负数之和为0，各自为0。x-2=0，x=2。y+3=0，y=-3。

## 第7题

**题目：** 一个正方形的面积为75，求它的边长（精确到0.1）。

**解析：** 边长=sqrt(75)=sqrt(25*3)=5*sqrt(3)≈5*1.732=8.66≈8.7。

## 第8题

**题目：** 判断：sqrt(16) 的平方根是多少？sqrt(81) 的平方根是多少？

**解析：** sqrt(16)=4，4的平方根=±2。sqrt(81)=9，9的平方根=±3。注意：先求算术平方根，再求平方根。
