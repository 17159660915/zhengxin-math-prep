# 4.2 整式的加法与减法 - 思维训练

## 第1题
**题目：** 若多项式 2x² - 3x + 1 与多项式 ax² + bx - 1 的和不含 x² 项和 x 项，求 a、b 的值。

**解析：** 两式相加：(2 + a)x² + (-3 + b)x + 0。不含 x² 项 → 2 + a = 0 → a = -2。不含 x 项 → -3 + b = 0 → b = 3。

## 第2题
**题目：** 已知 A = 3x² - 2x + 1，B = 2x² - x - 1，求 A - 2B 的值，并判断当 x 取何值时这个值最小。

**解析：** A - 2B = (3x² - 2x + 1) - 2(2x² - x - 1) = 3x² - 2x + 1 - 4x² + 2x + 2 = -x² + 3。当 x = 0 时，值最大为 3；当 x ≠ 0 时，值小于 3。所以最小值不存在，但最大值是 3。


## 第3题

**题目：** 已知 A = 2x² + 3xy - 2x - 1，B = -x² + xy - 1。求 3A + 6B 的值，并说明结果与 x 的取值是否有关。

**解析：** 3A + 6B = 3(2x²+3xy-2x-1) + 6(-x²+xy-1) = 6x²+9xy-6x-3-6x²+6xy-6 = 15xy-6x-9。结果含 x，与 x 取值有关。

## 第4题

**题目：** 若关于 x 的多项式 (mx² + 2x - 1) - (3x² - nx + 2) 化简后不含 x² 项和 x 项，求 m 和 n 的值。

**解析：** 化简：(m-3)x² + (2+n)x + (-3)。不含 x² 项则 m-3=0 → m=3。不含 x 项则 2+n=0 → n=-2。

## 第5题

**题目：** 已知 a - b = 3，c + d = 2，求 (b + c) - (a - d) 的值。

**解析：** (b + c) - (a - d) = b + c - a + d = -(a-b) + (c+d) = -3 + 2 = -1。


## 第6题

**题目：** 化简：3(2x^2-xy+y^2)-2(3x^2-2xy+y^2)+(x^2-xy-y^2)

**解析：** =6x^2-3xy+3y^2-6x^2+4xy-2y^2+x^2-xy-y^2=x^2。结果只含 x^2，不含 xy 和 y^2。

## 第7题

**题目：** 已知 A=2x^2+3xy-2x-1，B=-x^2+xy-1。求 3A+6B 的值，并说明当 y 取何值时，该值与 x 无关。

**解析：** 3A+6B=3(2x^2+3xy-2x-1)+6(-x^2+xy-1)=6x^2+9xy-6x-3-6x^2+6xy-6=15xy-6x-9=3x(5y-2)-9。当 5y-2=0 即 y=0.4 时，与 x 无关，值为-9。

## 第8题

**题目：** 一个多项式减去 2x^2-3x+1 等于 3x^2+2x-5，求这个多项式。

**解析：** 所求多项式=(3x^2+2x-5)+(2x^2-3x+1)=5x^2-x-4。
