# 10.3 实际问题与二元一次方程组 - 思维训练

## 第1题
**题目：** 买 3 支钢笔和 2 本笔记本共 19 元，买 5 支钢笔和 3 本笔记本共 31 元。求钢笔和笔记本的单价。

**解析：** 设钢笔 x 元/支，笔记本 y 元/本。{ 3x + 2y = 19，5x + 3y = 31 }。①×3 - ②×2：9x - 10x + 6y - 6y = 57 - 62，-x = -5，x = 5。代入①：15 + 2y = 19，y = 2。钢笔 5 元，笔记本 2 元。

## 第2题
**题目：** 一个两位数，个位数字与十位数字之和为 11，交换十位与个位数字后新数比原数大 27，求原数。

**解析：** 设十位数字为 x，个位数字为 y。{ x + y = 11，10y + x - (10x + y) = 27 }。化简：{ x + y = 11，y - x = 3 }。两式相加：2y = 14，y = 7，x = 4。原数 = 47。
