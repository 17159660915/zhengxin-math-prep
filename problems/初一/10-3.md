# 10.3 实际问题与二元一次方程组 - 思维训练

## 第1题
**题目：** 甲、乙两人各有一些钱，如果甲给乙 10 元，则甲的钱是乙的一半；如果乙给甲 10 元，则甲的钱是乙的 2 倍。两人原来各有多少钱？

**解析：** 设钢笔 x 元/支，笔记本 y 元/本。{ 3x + 2y = 19，5x + 3y = 31 }。①×3 - ②×2：9x - 10x + 6y - 6y = 57 - 62，-x = -5，x = 5。代入①：15 + 2y = 19，y = 2。钢笔 5 元，笔记本 2 元。

## 第2题
**题目：** 小明和小红同时从学校出发去图书馆，小明每分钟走 60 米，小红每分钟走 80 米。小红到达图书馆后立即返回，在距离图书馆 200 米处遇到小明。学校到图书馆的距离是多少米？

**解析：** 设十位数字为 x，个位数字为 y。{ x + y = 11，10y + x - (10x + y) = 27 }。化简：{ x + y = 11，y - x = 3 }。两式相加：2y = 14，y = 7，x = 4。原数 = 47。


## 第3题

**题目：** 甲乙两人从相距 36km 的两地同时出发相向而行，2 小时后相遇。若甲先出发 1 小时，然后乙出发，则乙出发 1.5 小时后两人相遇。求甲乙的速度。

**解析：** 设甲速 x km/h，乙速 y km/h。2x+2y=36，x+1.5x+1.5y=36。化简：x+y=18，2.5x+1.5y=36。解得 x=9，y=9。两人速度相同，都是 9km/h。

## 第4题

**题目：** 某班有 45 人，男生人数比女生人数的 2 倍少 6 人。求男女生各多少人。

**解析：** 设女生 x 人，男生 y 人。x+y=45，y=2x-6。代入：x+2x-6=45，3x=51，x=17。y=28。男生 28 人，女生 17 人。

## 第5题

**题目：** 小明用 10 元钱买了面值 0.8 元和 1.2 元的邮票共 11 枚。求两种邮票各买了多少枚。

**解析：** 设 0.8 元邮票 x 枚，1.2 元邮票 y 枚。x+y=11，0.8x+1.2y=10。由①：x=11-y，代入②：0.8(11-y)+1.2y=10，8.8-0.8y+1.2y=10，0.4y=1.2，y=3。x=8。0.8元8枚，1.2元3枚。
