# 10.3 实际问题与二元一次方程组 - 思维训练

## 第1题
**题目：** 甲、乙两人各有一些钱，如果甲给乙 10 元，则甲的钱是乙的一半；如果乙给甲 10 元，则甲的钱是乙的 2 倍。两人原来各有多少钱？

**解析：** 设甲有 x 元，乙有 y 元。甲给乙 10 元：甲剩 x-10，乙有 y+10，x-10 = (y+10)/2 → 2x - 20 = y + 10 → 2x - y = 30。乙给甲 10 元：甲有 x+10，乙剩 y-10，x+10 = 2(y-10) → x+10 = 2y-20 → x - 2y = -30。解得 x = 30，y = 30。两人原来各有 30 元。

## 第2题
**题目：** 某商店将一件商品按进价提高 40% 后标价，又以 8 折优惠卖出，结果仍获利 12 元。求这件商品的进价。

**解析：** 设进价为 x 元。标价 = x(1+40%) = 1.4x。售价 = 1.4x × 0.8 = 1.12x。利润 = 售价 - 进价 = 1.12x - x = 0.12x。0.12x = 12，x = 100。进价 100 元。


## 第3题

**题目：** 甲乙两人从相距 36km 的两地同时出发相向而行，2 小时后相遇。若甲先出发 1 小时，然后乙出发，则乙出发 1.5 小时后两人相遇。求甲乙的速度。

**解析：** 设甲速 x km/h，乙速 y km/h。2x+2y=36，x+1.5x+1.5y=36。化简：x+y=18，2.5x+1.5y=36。解得 x=9，y=9。两人速度相同，都是 9km/h。

## 第4题

**题目：** 某班有 45 人，男生人数比女生人数的 2 倍少 6 人。求男女生各多少人。

**解析：** 设女生 x 人，男生 y 人。x+y=45，y=2x-6。代入：x+2x-6=45，3x=51，x=17。y=28。男生 28 人，女生 17 人。

## 第5题

**题目：** 父亲今年 45 岁，儿子今年 15 岁。多少年后父亲的年龄是儿子年龄的 2 倍？多少年前父亲的年龄是儿子年龄的 5 倍？

**解析：** 设 x 年后父亲年龄是儿子的 2 倍：45 + x = 2(15 + x)，45 + x = 30 + 2x，x = 15。15 年后父亲 60 岁，儿子 30 岁。设 y 年前父亲年龄是儿子的 5 倍：45 - y = 5(15 - y)，45 - y = 75 - 5y，4y = 30，y = 7.5。7.5 年前父亲 37.5 岁，儿子 7.5 岁。


## 第6题

**题目：** 一个两位数，个位数字比十位数字大 3，且这个两位数的两倍比它的十位数字和个位数字的乘积大 10。求这个两位数。

**解析：** 设十位数字为 x，个位数字为 y。y = x + 3，2(10x + y) = 10x + y + xy + 10。代入 y = x+3：2(10x + x+3) = 10x + (x+3) + x(x+3) + 10，22x + 6 = 11x + 3 + x² + 3x + 10，22x + 6 = x² + 14x + 13，x² - 8x + 7 = 0，(x-1)(x-7)=0。x=1 或 x=7，对应 y=4 或 y=10（舍去）。所以两位数是 14。

## 第7题

**题目：** 某农场有鸡兔共 100 只，总腿数为 280 条。鸡和兔各有多少只？如果鸡和兔的数量互换，总腿数会变成多少？

**解析：** 设鸡 x 只、兔 y 只。x+y=100，2x+4y=280。解得 x=60，y=40。互换后：鸡 40 只、兔 60 只，腿数 = 40×2 + 60×4 = 80+240=320 条。

## 第8题

**题目：** 解方程组 { ax + y = 5，2x - by = 1 }，已知 x=2、y=1 是该方程组的解，求 a 和 b 的值。再求当 x=3 时 y 的值。

**解析：** 代入 x=2、y=1：2a + 1 = 5 → a = 2；4 - b = 1 → b = 3。原方程组为 { 2x + y = 5，2x - 3y = 1 }。x=3 时：{ 6 + y = 5 → y = -1；6 - 3y = 1 → y = 5/3 }，矛盾！说明 x=3 时方程组无解。
