# 7.4 平移 - 思维训练

## 第1题
**题目：** 三角形 ABC 沿 x 轴正方向平移 3 个单位，再沿 y 轴负方向平移 2 个单位。已知 A(1, 2)、B(3, 4)、C(2, 1)，求平移后各顶点坐标。

**解析：** 向右平移 3 → x 坐标 +3；向下平移 2 → y 坐标 -2。A'(4, 0)、B'(6, 2)、C'(5, -1)。平移后三角形形状大小不变。

## 第2题

**题目：** 在平移过程中，图形上任意一对对应点的连线有什么性质？如果平移距离为 5，方向为北偏东 30°，那么对应点连线的长度和方向各是多少？

**解析：** 对应点连线平行且相等。长度 = 平移距离 = 5，方向与平移方向相同，即北偏东 30°。


## 第3题

**题目：** 在平移过程中，图形上任意一对对应点的连线有什么性质？如果平移距离为 5，方向为北偏东 30°，那么对应点连线的长度和方向各是多少？

**解析：** 对应点连线平行且相等。长度 = 平移距离 = 5，方向 = 平移方向 = 北偏东 30°。

## 第4题

**题目：** 三角形 ABC 沿水平方向向右平移 4 个单位，再向上平移 2 个单位。已知 A(1, 2)，B(4, 3)，C(3, 5)，求平移后三角形各顶点坐标。

**解析：** A' = (1+4, 2+2) = (5, 4)，B' = (4+4, 3+2) = (8, 5)，C' = (3+4, 5+2) = (7, 7)。

## 第5题

**题目：** 正方形 ABCD 的边长为 3，E 是 AB 的中点。将三角形 AED 沿 AD 方向平移 3 个单位，求平移后三角形覆盖的面积。

**解析：** 平移后三角形与正方形重叠部分为梯形，需要计算重叠面积。具体涉及平移后三角形的顶点位置，分为两部分考虑。


## 第6题

**题目：** 三角形ABC顶点A(1,2)、B(4,2)、C(3,5)，向右平移3再向下平移2，求新顶点坐标和面积。

**解析：** A'(4,0)、B'(7,0)、C'(6,3)。底AB=3，高=3，面积=4.5。平移不改变面积。

## 第7题

**题目：** 两个全等三角形通过平移重合。A(1,2)、B(3,4)、C(5,1)，A对应A'(4,5)，求平移向量和B'、C'。

**解析：** 平移向量=(4-1,5-2)=(3,3)。B'(3+3,4+3)=(6,7)。C'(5+3,1+3)=(8,4)。

## 第8题

**题目：** 三角形ABC沿x轴方向平移3，沿y轴方向平移-2，A(1,2)的对应点A'坐标？

**解析：** A'(1+3,2-2)=(4,0)。
