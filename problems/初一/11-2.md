# 11.2 一元一次不等式 - 思维训练

## 第1题
**题目：** 关于 x 的不等式 2x - a ≤ 0 只有 3 个正整数解，求 a 的取值范围。


**解析：** 3x - 6 ≤ 5x + 2，-2x ≤ 8，x ≥ -4。数轴：在 -4 处画实心圆点，向右画射线。负整数解：x = -4, -3, -2, -1。

## 第2题
**题目：** 关于 x 的不等式 2x - a < 3x + 1 的解集为 x > -3，求 a 的值。

**解析：** 2x - a < 3x + 1，移项得 -x < 1 + a，x > -(1 + a)。已知解集为 x > -3，所以 -(1 + a) = -3，1 + a = 3，a = 2。


## 第3题

**题目：** 不等式 2(x-1) ≥ 5x - 10 的解集在数轴上表示出来，并求它的最大整数解。

**解析：** 2x-2 ≥ 5x-10 → -3x ≥ -8 → x ≤ 8/3。最大整数解为 2。

## 第4题

**题目：** 已知关于 x 的不等式 3x - a ≤ 2x 的解集为 x ≤ 4，求 a 的值。

**解析：** 3x - a ≤ 2x → x ≤ a。解集为 x ≤ 4，所以 a = 4。

## 第5题

**题目：** 某次数学竞赛共 20 题，答对一题得 5 分，答错一题扣 3 分，不答不得分。小明得了 76 分，他最多答错了几题？

**解析：** 设答对 x 题，答错 y 题，不答 z 题。x+y+z=20，5x-3y=76。由②：5x=76+3y，x=(76+3y)/5。x+y≤20。y=3时x=17，x+y=20≤20，z=0。y=8时x=20，x+y=28>20，不可。所以最多答错3题。
