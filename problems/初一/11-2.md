# 11.2 一元一次不等式 - 思维训练

## 第1题
**题目：** 解不等式 3(x - 2) ≤ 5x + 2，并在数轴上表示解集。求该不等式的所有负整数解。

**解析：** 3x - 6 ≤ 5x + 2，-2x ≤ 8，x ≥ -4。数轴：在 -4 处画实心圆点，向右画射线。负整数解：x = -4, -3, -2, -1。

## 第2题
**题目：** 关于 x 的不等式 2x - a < 3x + 1 的解集为 x > -3，求 a 的值。

**解析：** 2x - a < 3x + 1，移项得 -x < 1 + a，x > -(1 + a)。已知解集为 x > -3，所以 -(1 + a) = -3，1 + a = 3，a = 2。
