## 第1题

**题目：** 解方程：
(x-1)/2 - (2x-3)/3 = 1 - (x+2)/6

**解析：** 去分母（乘6）：3(x-1) - 2(2x-3) = 6 - (x+2)
去括号：3x-3 - 4x+6 = 6 - x - 2
合并：-x+3 = 4 - x
移项：-x+x = 4-3 → 0=1
矛盾！方程无解。

答案：无解

## 第2题

**题目：** 方程 2x + 3 = 5x - 6 与方程 3x - a = 2x + 7 有相同的解，求 a 的值。

**解析：** 解第一个方程：2x+3 = 5x-6 → 3+6 = 5x-2x → 9=3x → x=3
代入第二个方程：3×3 - a = 2×3 + 7 → 9-a = 6+7 → 9-a=13 → a=-4

答案：a = -4

## 第3题

**题目：** 小明和小红在解方程 3x - 2 = 5x + 4 时，小明把常数项移到左边，小红把含 x 的项移到左边，然后分别求解。两人得到的解相同吗？为什么？

**解析：** 小明：3x-2-5x-4=0 → -2x-6=0 → x=-3
小红：3x-5x = 4+2 → -2x=6 → x=-3
两人的解相同。因为移项的本质是等式两边同时加减同一个数，无论怎么移，最终结果一样。

答案：相同，因为移项的依据是等式的性质

## 第4题

**题目：** 某中学组织学生春游，如果租用 45 座客车，有 15 人没有座位；如果租用 60 座客车，则多出一辆车且其他车刚好坐满。求学生人数和 45 座客车的数量。

**解析：** 设 45 座客车有 x 辆。
学生总数 = 45x + 15
用 60 座客车：需要 (x-1) 辆，刚好坐满
60(x-1) = 45x + 15
60x - 60 = 45x + 15
15x = 75，x = 5
学生数 = 45×5+15 = 225+15 = 240

答案：学生240人，45座客车5辆

## 第5题

**题目：** 方程 (k² - 1)x² + (k - 1)x + 3 = 0 是关于 x 的一元一次方程，求 k 的值。

**解析：** 一元一次方程 → 最高次为1 → 二次项系数为0且一次项系数不为0
k²-1=0 → k²=1 → k=±1
且 k-1≠0 → k≠1
所以 k=-1

答案：k = -1

## 第6题

**题目：** 在一条笔直的公路上，甲、乙两人相距 20km，甲的速度是 4km/h，乙的速度是 6km/h。两人同时出发，几小时后相距 50km？请考虑所有可能的情况。

**解析：** 分情况讨论：
① 相向而行：4t+6t+20=50 → 10t=30 → t=3h
② 相向而行，相遇后继续走：4t+6t-20=50 → 10t=70 → t=7h
③ 同向而行（甲追乙，乙快追不上）：实际上乙更快，会越拉越远
  同向（乙追甲）：6t-4t+20=50 → 2t=30 → t=15h
④ 同向相反方向（背向）：4t+6t+20=50 → 10t=30 → t=3h（与①相同）

答案：3h、7h、15h，共三种情况

## 第8题

**题目：** 关于x的方程2(x-1)-a=0与(x+1)/2-1=0同解，求a。

**解析：** 解第二个：(x+1)/2=1，x+1=2，x=1。代入第一个：2(1-1)-a=0，a=0。
