## 第1题

**题目：** 一个三位数，百位数字是 a，十位数字比百位数字大 2，个位数字是十位数字的 2 倍。用代数式表示这个三位数，并求当 a=3 时的值。

**解析：** 百位：a，十位：a+2，个位：2(a+2)
三位数 = 100a + 10(a+2) + 2(a+2)
= 100a + 10a + 20 + 2a + 4
= 112a + 24
当 a=3 时：112×3+24 = 336+24 = 360

答案：112a+24，a=3时值为360

## 第2题

**题目：** 某商品原价 p 元，先涨价 10% 后又降价 10%，最后的价格是多少？与原价相比是涨了还是跌了？

**解析：** 涨价10%后：p(1+10%) = 1.1p
再降价10%后：1.1p(1-10%) = 1.1p×0.9 = 0.99p
最后价格 = 0.99p，比原价 p 便宜了 1%。

答案：0.99p，比原价跌了1%

## 第3题

**题目：** 用火柴棒摆正方形，摆 1 个正方形需要 4 根，摆 2 个需要 7 根，摆 3 个需要 10 根。摆 n 个正方形需要多少根火柴？

![示意图](problems-diagrams/p1-3-1-q3.png)

**解析：** 观察规律：
n=1时：4根
n=2时：7根 = 4+3
n=3时：10根 = 4+3+3
所以摆 n 个正方形需要 4+3(n-1) = 3n+1 根。

答案：3n+1 根

## 第4题

**题目：** 已知 a + b = 5，ab = 3，求 (a - b)² 的值。

**解析：** (a-b)² = a² - 2ab + b² = (a² + 2ab + b²) - 4ab = (a+b)² - 4ab
= 5² - 4×3 = 25 - 12 = 13

答案：13

## 第5题

**题目：** 三个连续奇数，中间一个是 2n+1，求这三个数的和，并说明和有什么特点。

**解析：** 三个连续奇数：2n-1, 2n+1, 2n+3
和 = (2n-1)+(2n+1)+(2n+3) = 6n+3 = 3(2n+1)
和是 3 的倍数，且是中间数的 3 倍。

答案：6n+3，和是 3 的倍数

## 第6题

**题目：** 已知a+b=3，ab=1，求a^2+b^2和(a-b)^2的值。

**解析：** (a+b)^2=a^2+2ab+b^2，9=a^2+2+b^2，a^2+b^2=7。(a-b)^2=7-2=5。

## 第7题

**题目：** 若x-1/x=3，求x^2+1/x^2的值。

**解析：** (x-1/x)^2=x^2-2+1/x^2，9=x^2+1/x^2-2，x^2+1/x^2=11。

## 第8题

**题目：** 当x=2时代数式ax^3+bx+1值为6，求x=-2时该式的值。

**解析：** x=2：8a+2b+1=6，8a+2b=5。x=-2：-8a-2b+1=-(8a+2b)+1=-5+1=-4。
