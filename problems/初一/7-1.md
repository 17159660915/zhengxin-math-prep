## 第1题

**题目：** 三条直线相交于一点，可以形成多少对对顶角？多少对邻补角？

**解析：** 三条直线交于一点，共有6条射线，每两条射线组成一个角。
对顶角：每两条直线形成2对对顶角，3条直线共3×2=6对
邻补角：每两条直线形成4对邻补角，3条直线共3×4=12对

答案：6对对顶角，12对邻补角

## 第2题

**题目：** 如图，AB ∥ CD，∠A = 120°，∠C = 130°，求 ∠AEC 的度数（E 在 AB 和 CD 之间）。

**解析：** 过 E 作 EF ∥ AB（也 ∥ CD）。
∠AEF = 180°-120° = 60°（同旁内角互补）
∠FEC = 180°-130° = 50°（同旁内角互补）
∠AEC = 60°+50° = 110°

答案：110°

## 第3题

**题目：** 平面内有 4 条直线，最多可以有几个交点？最少有几个？

**解析：** 最多：每两条直线都有一个交点，C(4,2) = 6个交点
最少：4条直线都平行，0个交点；或3条平行1条相交（3个交点）

答案：最多6个，最少0个

## 第4题

**题目：** 已知 ∠1 和 ∠2 互余，∠2 和 ∠3 互补，且 ∠1 = 40°，求 ∠3 的度数。

**解析：** ∠1+∠2=90° → 40°+∠2=90° → ∠2=50°
∠2+∠3=180° → 50°+∠3=180° → ∠3=130°

答案：130°

## 第5题

**题目：** 在同一平面内，有 5 条直线，其中恰好有 2 条平行，其余都不平行，最多可以有多少个交点？

**解析：** 2条平行线没有交点。剩下3条两两相交，且与2条平行线也相交。
3条直线两两相交：C(3,2)=3个交点
每条平行线与3条直线相交：2×3=6个交点
总：3+6=9个

答案：9个交点
