## 第1题

**题目：**

 三条直线相交于一点，可以形成多少对对顶角？多少对邻补角？

**解析：** 三条直线交于一点，共有6条射线，每两条射线组成一个角。
对顶角：每两条直线形成2对对顶角，3条直线共3×2=6对
邻补角：每两条直线形成4对邻补角，3条直线共3×4=12对

答案：6对对顶角，12对邻补角

## 第2题

**题目：** 如图，AB ∥ CD，∠A = 120°，∠C = 130°，求 ∠AEC 的度数（E 在 AB 和 CD 之间）。

![示意图](problems-diagrams/p1-7-1-q2.png)

**解析：** 过 E 作 EF ∥ AB（也 ∥ CD）。
∠AEF = 180°-120° = 60°（同旁内角互补）
∠FEC = 180°-130° = 50°（同旁内角互补）
∠AEC = 60°+50° = 110°

答案：110°

## 第3题

**题目：** 平面内有 4 条直线，最多可以有几个交点？最少有几个？

![示意图](problems-diagrams/p1-7-1-q3.png)


**解析：** 最多：每两条直线都有一个交点，C(4,2) = 6个交点
最少：4条直线都平行，0个交点；或3条平行1条相交（3个交点）

答案：最多6个，最少0个

## 第4题

**题目：** 已知 ∠1 和 ∠2 互余，∠2 和 ∠3 互补，且 ∠1 = 40°，求 ∠3 的度数。

**解析：** ∠1+∠2=90° → 40°+∠2=90° → ∠2=50°
∠2+∠3=180° → 50°+∠3=180° → ∠3=130°

答案：130°

## 第5题

**题目：** 在同一平面内，有 5 条直线，其中恰好有 2 条平行，其余都不平行，最多可以有多少个交点？

![示意图](problems-diagrams/p1-7-1-q5.png)


**解析：** 2条平行线没有交点。剩下3条两两相交，且与2条平行线也相交。
3条直线两两相交：C(3,2)=3个交点
每条平行线与3条直线相交：2×3=6个交点
总：3+6=9个

答案：9个交点

## 第6题

**题目：** 命题「相等的角是对顶角」是真命题吗？举反例。

**解析：** 假命题。反例：等腰直角三角形两锐角都是45度，相等但不是对顶角。

## 第7题

**题目：** 写出命题「如果a>0,b>0那么a+b>0」的逆命题并判断真假。

**解析：** 逆命题：如果a+b>0那么a>0且b>0。假命题。反例：a=5,b=-3，a+b=2>0但b<0。

## 第8题

**题目：** 用反证法证明：一条直线与两条平行线中的一条相交，则也与另一条相交。

**解析：** 假设与另一条不相交则平行，则该直线与两条平行线都平行，与已知矛盾。所以假设不成立。
