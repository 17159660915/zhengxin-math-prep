## 第1题

**题目：** 解不等式组：{ 2x - 1 > 3, x + 2 ≤ 8, 3x - 7 > 2x - 5 }

**解析：** ① 2x-1>3 → 2x>4 → x>2
② x+2≤8 → x≤6
③ 3x-7>2x-5 → x>2
公共部分：2 < x ≤ 6

答案：2 < x ≤ 6

---

## 第2题

**题目：** 求不等式组 { 2x + 1 > -3, 3x - 5 ≤ 7, x - 1 < 2x + 3 } 的整数解。

**解析：** ① 2x>-4 → x>-2
② 3x≤12 → x≤4
③ -x<4 → x>-4
解集：-2 < x ≤ 4
整数解：-1, 0, 1, 2, 3, 4

答案：-1, 0, 1, 2, 3, 4

## 第3题

**题目：** 若关于 x 的不等式组 { 2x - 1 > 3, x - a < 0 } 有解，求 a 的取值范围。

**解析：** ① 2x-1>3 → 2x>4 → x>2
② x-a<0 → x<a
要使有解，需要 a > 2

答案：a > 2

## 第4题

**题目：** 某商店销售一种商品，进价 50 元，标价 80 元。为了促销，商店决定打折销售，但要保证利润率不低于 20%，最多可以打几折？

**解析：** 设打 x 折。
售价 = 80 × x/10 = 8x 元
利润 = 8x - 50
利润率 = (8x-50)/50 ≥ 20% = 0.2
8x-50 ≥ 10
8x ≥ 60
x ≥ 7.5

答案：最多打 7.5 折

## 第5题

**题目：** 已知关于 x 的不等式组 { x - a ≥ 0, 3 - 2x > -1 } 的整数解共有 3 个，求 a 的取值范围。

**解析：** ① x ≥ a
② 3-2x>-1 → -2x>-4 → x<2
解集：a ≤ x < 2
整数解有3个，即 -1, 0, 1
所以 -2 < a ≤ -1

答案：-2 < a ≤ -1

## 第6题

**题目：** 解不等式2(x-1)>=5x-10，求最大整数解。

**解析：** 2x-2>=5x-10，-3x>=-8，x<=8/3。最大整数解为2。

## 第7题

**题目：** 关于x的不等式2x-a<=0只有3个正整数解，求a范围。

**解析：** x<=a/2。正整数解1,2,3，所以3<=a/2<4，6<=a<8。

## 第8题

**题目：** 关于x的不等式2x-a<3x+1解集为x>-3，求a。

**解析：** 2x-a<3x+1->-a-1<x。解集x>-3，所以-a-1=-3，a=2。
