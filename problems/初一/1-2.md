# 1.2 有理数及其大小比较 - 思维训练

## 第1题
**题目：** 已知 a、b 是有理数，且 a < b < 0。比较 |a| 和 |b| 的大小，并说明理由。

**解析：** 因为 a < b < 0，所以 a 和 b 都是负数。在数轴上，a 在 b 的左边。绝对值表示点到原点的距离，离原点越远绝对值越大。由于 a 在 b 的左边，a 离原点更远，所以 |a| > |b|。

## 第2题
**题目：** 已知 |x| = 5，|y| = 3，且 x > y，求 x 和 y 的所有可能值。

**解析：** |x| = 5 得 x = 5 或 x = -5；|y| = 3 得 y = 3 或 y = -3。要求 x > y，分情况：
- 若 x = 5，则 5 > 3 且 5 > -3，y可以是 3 或 -3。
- 若 x = -5，则 -5 > 3 不成立，-5 > -3 不成立，舍去。
所以 x = 5，y = 3 或 y = -3。


## 第3题

**题目：** 五个有理数：-2/3, 0.5, -1.5, 3/4, -0.75。将它们按从小到大排列，并用"<"连接。

**解析：** 统一化为小数：-0.667, 0.5, -1.5, 0.75, -0.75。排序：-1.5 < -0.75 < -0.667 < 0.5 < 0.75。即 -1.5 < -0.75 < -2/3 < 0.5 < 3/4

## 第4题

**题目：** 已知有理数 a、b 在数轴上的位置：a 在 -1 和 0 之间，b 在 1 和 2 之间。判断以下式子的正负：a+b, a-b, b-a, a²+b²

**解析：** a+b：a<0, b>0, |b|>|a|，所以 a+b > 0。a-b：a<b，所以 a-b < 0。b-a：b>a，所以 b-a > 0。a²+b²：两个非负数，和必 > 0。

## 第5题

**题目：** 已知 |x| = 5，|y| = 3，且 |x-y| = y-x，求 x+y 的值。

**解析：** |x-y| = y-x 说明 y-x ≥ 0，即 y ≥ x。x = ±5，y = ±3。y ≥ x 的情况：x = -5, y = 3（3 > -5）；x = -5, y = -3（-3 > -5）。x+y = -5+3 = -2 或 -5+(-3) = -8。


## 第6题

**题目：** 已知 a、b、c 都是有理数，且 a < b < 0 < c，|a| > |c|。比较 a、b、c、-a、-b、-c 的大小，并按从小到大顺序排列。

**解析：** 先化简符号：-a>0，-b>0，-c<0。因为 a<b<0，所以 -a>-b>0。因为 |a|>|c|，所以 -a>c。又因为 c>0>-c。排序：a < b < -c < c < -b < -a。

## 第7题

**题目：** 若 |x| = 3，|y| = 5，|z| = 7，且 x > y > z，求 x、y、z 的值。

**解析：** x 的可能值：±3；y 的可能值：±5；z 的可能值：±7。由 x>y>z，且 3>-5>-7，所以 x=3，y=-5，z=-7。

---

## 第8题

**题目：** 已知 a、b 互为相反数，c、d 互为倒数，|m| = 2。求 (a+b)/m + m^2 - cd 的值。

**解析：** a+b=0，cd=1，|m|=2 所以 m^2=4。原式 = 0/m + 4 - 1 = 3。与 m 的符号无关。
