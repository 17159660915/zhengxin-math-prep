# 1.2 有理数及其大小比较 - 思维训练

## 第1题
**题目：** 已知 a、b 是有理数，且 a < b < 0。比较 |a| 和 |b| 的大小，并说明理由。

**解析：** 因为 a < b < 0，所以 a 和 b 都是负数。在数轴上，a 在 b 的左边。绝对值表示点到原点的距离，离原点越远绝对值越大。由于 a 在 b 的左边，a 离原点更远，所以 |a| > |b|。

## 第2题
**题目：** 已知 |x| = 5，|y| = 3，且 x > y，求 x 和 y 的所有可能值。

**解析：** |x| = 5 得 x = 5 或 x = -5；|y| = 3 得 y = 3 或 y = -3。要求 x > y，分情况：
- 若 x = 5，则 5 > 3 且 5 > -3，y可以是 3 或 -3。
- 若 x = -5，则 -5 > 3 不成立，-5 > -3 不成立，舍去。
所以 x = 5，y = 3 或 y = -3。
