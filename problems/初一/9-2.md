# 9.2 坐标方法的简单应用 - 思维训练

## 第1题
**题目：** 点 A(2, -1) 向右平移 3 个单位，再向下平移 4 个单位，求平移后坐标。若点 B(x, y) 经过同样的平移后得到 B'(5, 2)，求 B 的坐标。

**解析：** A 向右 3 → x = 2+3 = 5，向下 4 → y = -1-4 = -5，A'(5, -5)。B 经过同样平移得 B'(5, 2)，反向操作：B 的 x = 5-3 = 2，y = 2+4 = 6，B(2, 6)。

## 第2题
**题目：** 三角形 ABC 三个顶点 A(1, 2)、B(3, 4)、C(5, 1)，向左平移 2 个单位再向上平移 3 个单位，求新顶点坐标。

**解析：** 向左平移 2 → x 各减 2；向上平移 3 → y 各加 3。A'(-1, 5)、B'(1, 7)、C'(3, 4)。
