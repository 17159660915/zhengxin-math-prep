# 9.2 坐标方法的简单应用 - 思维训练

## 第1题
**题目：** 在平面直角坐标系中，点 A(1, 2)、B(4, 2)、C(3, 5) 构成三角形。将此三角形向左平移 2 个单位，再向上平移 1 个单位后，新三角形 A'B'C' 的面积是多少？与原三角形面积有什么关系？

**解析：** A(1,2)→A'(-1,3)，B(4,2)→B'(2,3)，C(3,5)→C'(1,6)。平移不改变图形形状和大小，面积不变。原三角形面积 = 1/2 × 3 × 3 = 4.5，新三角形面积也是 4.5。

## 第2题
**题目：** 三角形 ABC 三个顶点 A(1, 2)、B(3, 4)、C(5, 1)，向左平移 2 个单位再向上平移 3 个单位，求新顶点坐标。

**解析：** 向左平移 2 → x 各减 2；向上平移 3 → y 各加 3。A'(-1, 5)、B'(1, 7)、C'(3, 4)。


## 第3题

**题目：** 在平面直角坐标系中，点 P(2, -3) 先向左平移 3 个单位，再向上平移 5 个单位得到点 Q。求 Q 的坐标，并判断 Q 在第几象限。

**解析：** P(2,-3) 左移3 → (-1,-3)，上移5 → (-1,2)。Q(-1,2) 在第二象限。

## 第4题

**题目：** 点 A(1, 2)、B(4, 2)、C(3, 5) 构成三角形。将三角形 ABC 向下平移 2 个单位，再向左平移 1 个单位，求新三角形各顶点坐标。

**解析：** A' = (1-1, 2-2) = (0, 0)，B' = (4-1, 2-2) = (3, 0)，C' = (3-1, 5-2) = (2, 3)。

## 第5题

**题目：** 四边形 ABCD 的顶点坐标为 A(0, 0)、B(4, 0)、C(5, 3)、D(1, 3)。将四边形向右平移 2 个单位后，求新四边形面积与原四边形面积的关系。

**解析：** 平移不改变图形形状和大小，面积不变。原四边形面积 = 梯形面积 = 1/2×(4+4)×3 = 12。新四边形面积也是 12。
