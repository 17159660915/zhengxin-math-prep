# 2.2 有理数的乘法与除法 - 思维训练

## 第1题
**题目：** 计算：(-1) × (-2) × (-3) × ... × (-2026)。积是正数还是负数？说明理由。

**解析：** 从 1 到 2026 共有 2026 个因数，每个因数都加了负号，所以负因数的个数是 2026。2026 是偶数，所以积为正。答案为 1×2×3×...×2026 = 2026!（正数）。

## 第2题
**题目：** 已知 a、b 互为相反数，c、d 互为倒数，m 的倒数是它本身，求 m(a+b) - cd 的值。

**解析：** a、b 互为相反数 → a + b = 0。c、d 互为倒数 → cd = 1。m 的倒数是它本身 → m = 1 或 m = -1。所以 m(a+b) - cd = m×0 - 1 = -1。


## 第3题

**题目：** 计算 (-1)×(-2)×(-3)×(-4)×(-5) 的结果是正数还是负数？如果继续乘到 (-10)，结果的正负号如何？

**解析：** 负因数的个数决定符号。5个负数相乘 → 奇数个 → 结果为负。乘到(-10)共10个负数 → 偶数个 → 结果为正。

## 第4题

**题目：** 已知 a、b 互为相反数，c、d 互为倒数，m 的绝对值是 2。求 m² - (a+b+cd)m + (a+b)²⁰²⁶ + (-cd)²⁰²⁷ 的值。

**解析：** a+b=0，cd=1，m=±2。原式 = m² - (0+1)m + 0 + (-1)²⁰²⁷ = 4 - m - 1 = 3 - m。m=2时值为1，m=-2时值为5。

## 第5题

**题目：** 计算：1/(1×2) + 1/(2×3) + 1/(3×4) + ... + 1/(99×100)。

**解析：** 1/n(n+1) = 1/n - 1/(n+1)。原式 = (1-1/2)+(1/2-1/3)+...+(1/99-1/100) = 1-1/100 = 99/100。
