# 7.3 定义、命题、定理 - 思维训练

## 第1题
**题目：** 判断下列命题是真命题还是假命题。如果是假命题，请举出反例。① 如果 a² = b²，那么 a = b。② 如果 a > b，那么 a² > b²。

**解析：** ① 假命题。反例：a = 2，b = -2，a² = b² = 4，但 a ≠ b。② 假命题。反例：a = 1，b = -2，1 > -2，但 1² = 1，(-2)² = 4，1 < 4。

## 第2题
**题目：** 将命题"对顶角相等"改写成"如果…那么…"的形式，并写出它的逆命题，判断逆命题的真假。

**解析：** "如果两个角是对顶角，那么这两个角相等。"逆命题："如果两个角相等，那么这两个角是对顶角。"逆命题是假命题，反例：角平分线分出的两个角相等，但它们不是对顶角。


## 第3题

**题目：** 判断下列命题的真假，并说明理由：① 若 a² = b²，则 a = b。② 若 a > b，则 a² > b²。

**解析：** ①假，a²=b²可得 a=±b，例如 a=2,b=-2时 a²=b²但 a≠b。②假，例如 a=1,b=-2时 a>b但 a²=1<b²=4。

## 第4题

**题目：** 将命题「直角三角形的两个锐角互余」改写成「如果…那么…」的形式，并写出它的逆命题。逆命题是真命题吗？

**解析：** 如果一个三角形是直角三角形，那么它的两个锐角互余。逆命题：如果一个三角形的两个锐角互余，那么这个三角形是直角三角形。逆命题是真命题。

## 第5题

**题目：** 证明：垂直于同一条直线的两条直线互相平行。（在同一平面内）

**解析：** 已知 a⊥c，b⊥c。求证 a∥b。假设 a 与 b 不平行，则 a 与 b 相交于一点。过交点作 c 的垂线，根据垂线性质，过一点有且只有一条直线与 c 垂直，矛盾。所以 a∥b。


## 第6题

**题目：** 命题「相等的角是对顶角」是真命题还是假命题？如果是假命题，请举出反例。

**解析：** 假命题。反例：直角三角形的两个锐角都是45度时，它们相等但不是对顶角。角平分线分出的两个角相等但不是对顶角。

## 第7题

**题目：** 写出命题「如果 a>0，b>0，那么 a+b>0」的逆命题，并判断逆命题的真假。

**解析：** 逆命题：如果 a+b>0，那么 a>0 且 b>0。假命题。反例：a=5，b=-3，a+b=2>0，但 b<0。

## 第8题

**题目：** 用反证法证明：在同一平面内，如果一条直线与两条平行线中的一条相交，那么它也与另一条相交。

**解析：** 假设这条直线与另一条平行线不相交，则它们平行。那么这条直线与两条平行线都平行，与已知「与其中一条相交」矛盾。所以假设不成立，它也与另一条相交。
