# 6.3 角 - 思维训练

## 第1题
**题目：** 一个角的补角比它的余角的 3 倍大 20°，求这个角的度数。

**解析：** 设这个角为 x。补角 = 180° - x，余角 = 90° - x。列方程：180 - x = 3(90 - x) + 20，即 180 - x = 270 - 3x + 20，180 - x = 290 - 3x，2x = 110，x = 55°。

## 第2题
**题目：** 时钟显示 3 点 15 分时，时针和分针的夹角是多少度？

**解析：** 分针每分钟走 6°，3 点 15 分时分针在 3 的位置（90°）。时针每小时走 30°，15 分钟走 7.5°。3 点时，时针在 90° 位置，15 分钟后时针在 90° + 7.5° = 97.5°。分针在 15 分钟时在 90°。夹角 = |97.5° - 90°| = 7.5°。




## 第3题

**题目：** 从 2 点 15 分到 2 点 45 分，时针转了多少度？分针转了多少度？

**解析：** 分针从15分到45分走了30分钟，30×6°=180°。时针30分钟走30×0.5°=15°。

## 第4题

**题目：** ∠AOB = 80°，OC 平分 ∠AOB，OD 平分 ∠BOC，OE 平分 ∠AOD。求 ∠COE 的度数。

**解析：** ∠AOB=80°，OC平分 → ∠AOC=∠BOC=40°。OD平分∠BOC → ∠COD=20°。∠AOD=∠AOC+∠COD=60°。OE平分∠AOD → ∠AOE=30°。∠COE=∠AOC-∠AOE=40°-30°=10°。

## 第5题

**题目：** 一个角的余角比它的补角的三分之一大 10°，求这个角的度数。

**解析：** 设角为 x。余角 90°-x，补角 180°-x。90-x = 1/3(180-x) + 10。90-x = 60 - x/3 + 10 → 90-x = 70 - x/3 → 20 = 2x/3 → x = 30°。
