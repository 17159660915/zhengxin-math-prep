# 6.2 直线、射线、线段 - 思维训练

## 第1题
**题目：** 平面上有 6 个点，其中任意 3 点不共线。过每两点画一条直线，一共可以画多少条？如果这 6 个点中有 3 个点共线，最多可以画多少条？

**解析：** 任意 3 点不共线时，从 6 个点中选 2 个，C(6,2) = 15 条。若有 3 点共线：这 3 点只能确定 1 条直线（而不是 3 条），所以比原来少 2 条，共 15 - 2 = 13 条。

## 第2题
**题目：** 已知线段 AB = 10，点 C 在线段 AB 上，且 AC = 3CB。点 M 是 AC 的中点，点 N 是 CB 的中点，求 MN 的长度。

**解析：** 设 CB = x，则 AC = 3x。AB = AC + CB = 3x + x = 4x = 10，x = 2.5。AC = 7.5，CB = 2.5。M 是 AC 中点 → AM = MC = 3.75。N 是 CB 中点 → CN = NB = 1.25。MN = MC + CN = 3.75 + 1.25 = 5。
