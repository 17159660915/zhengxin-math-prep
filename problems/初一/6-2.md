# 6.2 直线、射线、线段 - 思维训练

## 第1题
**题目：** 平面上有 6 个点，其中任意 3 点不共线。过每两点画一条直线，一共可以画多少条？如果这 6 个点中有 3 个点共线，最多可以画多少条？

**解析：** 任意 3 点不共线时，从 6 个点中选 2 个，C(6,2) = 15 条。若有 3 点共线：这 3 点只能确定 1 条直线（而不是 3 条），所以比原来少 2 条，共 15 - 2 = 13 条。

## 第2题
**题目：** 已知线段 AB = 10，点 C 在线段 AB 上，且 AC = 3CB。点 M 是 AC 的中点，点 N 是 CB 的中点，求 MN 的长度。

**解析：** 设 CB = x，则 AC = 3x。AB = AC + CB = 3x + x = 4x = 10，x = 2.5。AC = 7.5，CB = 2.5。M 是 AC 中点 → AM = MC = 3.75。N 是 CB 中点 → CN = NB = 1.25。MN = MC + CN = 3.75 + 1.25 = 5。


## 第3题

**题目：** 已知线段 AB = 10cm，点 C 在 AB 的延长线上，且 AC = 3BC，求 BC 的长。

**解析：** 设 BC = x，则 AC = AB + BC = 10 + x。AC = 3BC → 10 + x = 3x → 2x = 10 → x = 5cm。

## 第4题

**题目：** 线段 AB 上有两点 C、D，AC:CB = 2:3，AD:DB = 3:4，且 CD = 2cm，求 AB 的长。

**解析：** 设 AB = 35k。AC = 2/5×35k = 14k，CB = 21k。AD = 3/7×35k = 15k，DB = 20k。CD = AD - AC = 15k - 14k = k = 2cm。AB = 35×2 = 70cm。

## 第5题

**题目：** 在同一条直线上有 A、B、C、D 四个点，AB = 5，BC = 3，CD = 4。若 AD 的长度为整数，求 AD 的所有可能值。

**解析：** 按顺序 A-B-C-D：AD=5+3+4=12。A-C-B-D：AC=2，CB=3，BD=4，AD=2+3+4=9。A-B-D-C：AB=5，BD=3，DC=4，AD=5+3=8。A-D-B-C：AD=5-3-4=-2不可能。AD 的可能值为 12、9、8。
