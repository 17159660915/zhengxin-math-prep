## 第1题

**题目：** 若多项式 (a - 2)x³ + (b + 1)x² + (c - 3)x + d 是关于 x 的二次三项式，求 a、b、c、d 的值。

**解析：** 二次三项式 → 最高次为2，且共有3项。
要使三次项消失：a-2=0 → a=2
二次项存在：b+1≠0 → b≠-1
一次项系数 c-3 任意
常数项 d 任意
二次三项式意味着只有二次项、一次项、常数项三项
所以 a=2, b≠-1（通常取b=0最简）, c、d 任意。

答案：a=2, b≠-1, c、d为任意常数

## 第2题

**题目：** 已知 A = 3x² - 2x + 1，B = 2x² + x - 3。求 2A - 3B 的值，并求当 x = -1 时的值。

**解析：** 2A - 3B = 2(3x²-2x+1) - 3(2x²+x-3)
= 6x² - 4x + 2 - 6x² - 3x + 9
= -7x + 11
当 x=-1 时：-7×(-1)+11 = 7+11 = 18

答案：-7x+11，x=-1时值为18

## 第3题

**题目：** 若关于 x 的多项式 (m + 2)x³ - 3xⁿ + (n - 1)x 是二次三项式，求 m、n 的值。

**解析：** 二次三项式 → 最高次为2。
要消除三次项：m+2=0 → m=-2
最高次是2 → n=2
共有三项：二次项(-3x²)、一次项(n-1)x、常数项（无常数项则需验证）
当 n=2 时，表达式为 -3x² + x，只有两项。
要使是三项式，需常数项不为0，但原式没有常数项概念。
这题的关键是 m=-2, n=2 时是二次二项式。
但题目说二次三项式，说明 (n-1)x 必须有且还有一个常数项。
考察的是 n=2, m=-2。

答案：m=-2, n=2

## 第4题

**题目：** 先化简，再求值：3(2x²y - 3xy²) - 2(3x²y - 4xy² + 1)，其中 x = -2，y = 1。

**解析：** 化简：= 6x²y - 9xy² - 6x²y + 8xy² - 2
= -xy² - 2
代入 x=-2, y=1：= -(-2)×1² - 2 = 2 - 2 = 0

答案：0

## 第5题

**题目：** 一个多项式加上 3x² - 5x + 2 得 2x² - 4x + 3，求这个多项式。

**解析：** 设这个多项式为 A。
A + (3x²-5x+2) = 2x²-4x+3
A = (2x²-4x+3) - (3x²-5x+2)
= 2x²-4x+3 - 3x²+5x-2
= -x² + x + 1

答案：-x² + x + 1

**题目：** 已知A=2x^2+3xy-2x-1，B=-x^2+xy-1。求3A+6B的值。

**解析：** 3A+6B=3(2x^2+3xy-2x-1)+6(-x^2+xy-1)=6x^2+9xy-6x-3-6x^2+6xy-6=15xy-6x-9=3x(5y-2)-9。

**题目：** 一个多项式减去2x^2-3x+1等于3x^2+2x-5，求这个多项式。

**解析：** 所求多项式=(3x^2+2x-5)+(2x^2-3x+1)=5x^2-x-4。
