## 第1题

**题目：**

 已知点 P(2a - 3, a + 1) 在第三象限，求 a 的取值范围。

**解析：** 第三象限 x<0, y<0
2a-3<0 → a<1.5
a+1<0 → a<-1
取交集：a < -1

答案：a < -1

---

## 第2题

**题目：** 点 P(x, y) 满足 |x| = 3，|y| = 5，且点 P 在第四象限，求 P 的坐标。

**解析：** 第四象限 x>0, y<0
|x|=3 → x=±3，取 x=3
|y|=5 → y=±5，取 y=-5
P(3, -5)

答案：P(3, -5)

## 第3题

**题目：** 已知点 A(2, 3)、B(-2, 1)、C(0, -2)，求三角形 ABC 的面积。

![示意图](problems-diagrams/p1-9-1-q3.png)


**解析：** 用坐标法计算面积：
S = 1/2|(x₁(y₂-y₃)+x₂(y₃-y₁)+x₃(y₁-y₂))|
= 1/2|2(1-(-2)) + (-2)(-2-3) + 0(3-1)|
= 1/2|2×3 + (-2)×(-5) + 0|
= 1/2|6+10| = 8

答案：8 平方单位

## 第4题

**题目：** 点 P(3, -2) 先向右平移 4 个单位，再向上平移 3 个单位得到点 Q。求 Q 关于原点的对称点坐标。

**解析：** P(3,-2) 右移4得 (7,-2)
再上移3得 Q(7,1)
Q 关于原点对称：(-7,-1)

答案：(-7, -1)

## 第5题

**题目：** 已知点 A(1, 2)、B(5, 2)、C(3, 6)，判断三角形 ABC 的形状。

![示意图](problems-diagrams/p1-9-1-q5.png)


**解析：** AB=|5-1|=4（水平）
AC=√((3-1)²+(6-2)²) = √(4+16) = √20 = 2√5
BC=√((3-5)²+(6-2)²) = √(4+16) = 2√5
AC=BC → 等腰三角形
AB²=16, AC²+BC²=20+20=40≠16，不是直角三角形

答案：等腰三角形

## 第6题

**题目：** 点A(1,2)、B(5,2)、C(3,6)构成三角形。关于x轴对称求新三角形顶点坐标。

**解析：** 关于x轴对称：横坐标不变，纵坐标取相反数。A'(1,-2)、B'(5,-2)、C'(3,-6)。

**题目：** 点P(2a-1,a+3)在第二象限，求a范围。

**解析：** 第二象限：x<0,y>0。2a-1<0->a<0.5。a+3>0->a>-3。-3<a<0.5。

## 第8题

**题目：** 四边形ABCD顶点A(0,0)、B(4,0)、C(5,3)、D(1,3)，判断形状。

**解析：** AB∥CD且AB=CD=4，是平行四边形。AD不垂直AB，不是矩形。
