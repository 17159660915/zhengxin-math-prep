## 第1题

**题目：** 已知线段 AB = 12cm，点 C 在直线 AB 上，且 AC = 4cm，M 是 AB 的中点，N 是 AC 的中点，求 MN 的长度。

**解析：** 分两种情况：
① C 在 A 和 B 之间：
  AC=4, CB=8
  M 是 AB 中点 → AM=MB=6
  N 是 AC 中点 → AN=NC=2
  MN = AM-AN = 6-2 = 4cm
② C 在 A 的延长线上：
  AC=4, AB=12
  M 是 AB 中点 → AM=MB=6
  N 是 AC 中点 → AN=2
  MN = AM+AN = 6+2 = 8cm

答案：4cm 或 8cm

## 第2题

**题目：** 从 8 点整开始，经过多少分钟，时针和分针第一次重合？

**解析：** 8点整时，时针在8，分针在12，相差240°。
分针速度：360°/60min = 6°/min
时针速度：30°/60min = 0.5°/min
相对速度：6-0.5 = 5.5°/min
追及时间：240÷5.5 = 2400/55 = 480/11 ≈ 43.64分钟

答案：480/11 分钟

## 第3题

**题目：** ∠AOB = 120°，OC 是 ∠AOB 内部的射线，OD 平分 ∠AOC，OE 平分 ∠COB。求 ∠DOE 的度数。

**解析：** 设 ∠AOC = 2α，则 ∠COB = 120°-2α
OD 平分 ∠AOC → ∠DOC = α
OE 平分 ∠COB → ∠COE = (120°-2α)/2 = 60°-α
∠DOE = ∠DOC + ∠COE = α + (60°-α) = 60°

答案：60°（与 OC 的位置无关）

## 第4题

**题目：** 一个角的补角比这个角的余角的 3 倍少 10°，求这个角的度数。

**解析：** 设这个角为 x°。
补角 = 180°-x，余角 = 90°-x
180-x = 3(90-x) - 10
180-x = 270-3x-10
180-x = 260-3x
2x = 80，x = 40

答案：40°

## 第5题

**题目：** 在一条直线上顺次取 A、B、C、D 四点，使 AB:BC:CD = 2:3:4，M 是 AB 的中点，N 是 CD 的中点，且 MN = 12cm，求 AD 的长。

**解析：** 设 AB=2k, BC=3k, CD=4k，则 AD=9k
M 是 AB 中点 → AM=MB=k
N 是 CD 中点 → CN=ND=2k
MN = MB+BC+CN = k+3k+2k = 6k
6k = 12，k=2
AD = 9k = 18cm

答案：18cm
