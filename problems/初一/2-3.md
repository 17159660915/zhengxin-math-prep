# 2.3 有理数的乘方 - 思维训练

## 第1题
**题目：** 计算 (-2)³ + (-3)²。比较 (-2)³ 和 -2³ 是否相等，说明理由。

**解析：** (-2)³ = (-2)×(-2)×(-2) = -8，(-3)² = 9，所以 (-2)³ + (-3)² = -8 + 9 = 1。(-2)³ = -8，-2³ = -8，两者相等。注意 (-2)² = 4 而 -2² = -4，但奇数次方时两者相等。

## 第2题
**题目：** 观察 1² = 1，11² = 121，111² = 12321，1111² = 1234321。根据规律写出 11111² 的值，并说明 111111111² 的结果中数字 9 出现了几次。

**解析：** 规律：n 个 1 的平方 = 123...(n)...321。所以 11111² = 123454321。111111111² = 12345678987654321，其中数字 9 出现 1 次（在正中间）。


## 第3题

**题目：** 计算 (-2)³⁰ × (-1/2)³¹。

**解析：** (-2)³⁰ × (-1/2)³¹ = (-2)³⁰ × (-1/2)³⁰ × (-1/2) = [(-2)×(-1/2)]³⁰ × (-1/2) = 1³⁰ × (-1/2) = -1/2

## 第4题

**题目：** 比较大小：2⁵⁵、3⁴⁴、4³³、5²²。（提示：化为同指数比较）

**解析：** 2⁵⁵ = (2⁵)¹¹ = 32¹¹，3⁴⁴ = (3⁴)¹¹ = 81¹¹，4³³ = (4³)¹¹ = 64¹¹，5²² = (5²)¹¹ = 25¹¹。比较底数：81 > 64 > 32 > 25，所以 3⁴⁴ > 4³³ > 2⁵⁵ > 5²²。

## 第5题

**题目：** 已知 10ᵃ = 20，10ᵇ = 1/5，求 3ᵃ ÷ 3ᵇ 的值。

**解析：** 10ᵃ = 20，10ᵇ = 0.2，相除得 10ᵃ⁻ᵇ = 100 = 10²，所以 a-b = 2。3ᵃ ÷ 3ᵇ = 3ᵃ⁻ᵇ = 3² = 9。


## 第6题

**题目：** 观察下列等式：1=1^2，1+3=2^2，1+3+5=3^2，1+3+5+7=4^2。按此规律，1+3+5+...+(2n-1) 等于多少？并计算 1+3+5+...+99 的值。

**解析：** 规律：前 n 个连续奇数的和等于 n^2。1+3+5+...+(2n-1)=n^2。1+3+5+...+99 中，2n-1=99，n=50。原式=50^2=2500。

## 第7题

**题目：** 计算：(-2)^2 * (-3) - (-4) / (-1/2) * 2

**解析：** (-2)^2=4，4*(-3)=-12。(-4)/(-1/2)=(-4)*(-2)=8，8*2=16。原式=-12-16=-28。

## 第8题

**题目：** 若 a、b 均为非零有理数，求 |a|/a + |b|/b + |ab|/(ab) 的所有可能值。

**解析：** a>0,b>0：|a|/a=1，|b|/b=1，|ab|/ab=1，和=3。a>0,b<0：1-1-1=-1。a<0,b>0：-1+1-1=-1。a<0,b<0：-1-1+1=-1。所以可能值为3或-1。
