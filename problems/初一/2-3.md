# 2.3 有理数的乘方 - 思维训练

## 第1题
**题目：** 计算 (-2)³ + (-3)²。比较 (-2)³ 和 -2³ 是否相等，说明理由。

**解析：** (-2)³ = (-2)×(-2)×(-2) = -8，(-3)² = 9，所以 (-2)³ + (-3)² = -8 + 9 = 1。(-2)³ = -8，-2³ = -8，两者相等。注意 (-2)² = 4 而 -2² = -4，但奇数次方时两者相等。

## 第2题
**题目：** 观察 1² = 1，11² = 121，111² = 12321，1111² = 1234321。根据规律写出 11111² 的值，并说明 111111111² 的结果中数字 9 出现了几次。

**解析：** 规律：n 个 1 的平方 = 123...(n)...321。所以 11111² = 123454321。111111111² = 12345678987654321，其中数字 9 出现 1 次（在正中间）。
