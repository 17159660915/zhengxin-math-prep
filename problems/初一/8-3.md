# 8.3 实数及其简单运算 - 思维训练

## 第1题
**题目：** 下列各数中，哪些是有理数？哪些是无理数？3.14，-5，√7，0，π/2，0.1010010001...，√9，1/3。

**解析：** 有理数：3.14（有限小数）、-5（整数）、0、√9 = 3（整数）、1/3 = 0.333...（循环小数）。无理数：√7（开不尽）、π/2（含 π）、0.1010010001...（无限不循环）。

## 第2题
**题目：** 比较 √10 和 3.2 的大小。不用计算器，说明理由。

**解析：** 3.2² = 10.24，10 < 10.24，所以 √10 < √10.24 = 3.2。即 √10 < 3.2。


## 第3题

**题目：** 比较大小：√5 + √3 与 √6 + √2。（不用计算器）

**解析：** 两边平方：(√5+√3)² = 8+2√15，(√6+√2)² = 8+2√12。因为 √15 > √12，所以 √5+√3 > √6+√2。

## 第4题

**题目：** 已知 a、b 为有理数，且 (a + √3)(b - √3) = 7 - 4√3，求 a + b 的值。

**解析：** 展开：ab - a√3 + b√3 - 3 = 7 - 4√3 → (ab-3) + (b-a)√3 = 7 - 4√3。ab-3=7，b-a=-4。解得 ab=10，b-a=-4。a²+b² = (a-b)²+2ab = 16+20=36。a+b = ±√(a²+b²+2ab) = ±√(36+20) = ±√56 = ±2√14。

## 第5题

**题目：** √2 的小数部分为 a，√3 的小数部分为 b，求 a + b 的值。（精确到 0.01）

**解析：** √2 ≈ 1.414，a = 0.414。√3 ≈ 1.732，b = 0.732。a+b = 1.146。
