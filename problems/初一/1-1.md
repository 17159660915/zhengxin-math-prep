## 第1题

**题目：** 有三个数 a、b、c，已知 a > 0，b < 0，c < 0。若 |a| = |b|，且 |c| = 2|b|，将 a、b、c、-a、-b、-c 这六个数按从小到大顺序排列。


**解析：** 由条件：a > 0, b < 0, c < 0, |a|=|b|, |c|=2|b|。设 |b|=t，则 a=t, b=-t, c=-2t。
-a=-t, -b=t, -c=2t。
从小到大：c < b < -a < a < -b < -c，即 -2t < -t < -t < t < t < 2t，
其中 -a 和 b 相等，a 和 -b 相等。

答案：c < b = -a < a = -b < -c

## 第2题

**题目：** 若 |x| = 5，|y| = 3，且 |x - y| = y - x，求 x + y 的值。

**解析：** 由 |x-y| = y-x 知 y-x ≥ 0，即 y ≥ x。
|x|=5 → x=5 或 x=-5
|y|=3 → y=3 或 y=-3
满足 y ≥ x 的组合：(x=-5, y=3) 和 (x=-5, y=-3)
① x=-5, y=3：x+y=-2
② x=-5, y=-3：x+y=-8

答案：-2 或 -8

## 第3题

**题目：** 已知 a、b 互为相反数，c、d 互为倒数，m 的绝对值是 2。求 m² + (a+b)m - 3cd 的值。

**解析：** a+b=0（相反数之和为0），cd=1（倒数之积为1），|m|=2 → m²=4
原式 = 4 + 0×m - 3×1 = 4 - 3 = 1

答案：1（与 m 的正负无关）

## 第4题

**题目：** 数轴上点 A 表示 -3，点 B 表示 5。点 P 从 A 出发以每秒 2 个单位的速度向右运动，点 Q 从 B 出发以每秒 1 个单位的速度向左运动。几秒后 P、Q 相遇？相遇点表示什么数？

**解析：** 设 t 秒后相遇。P 的位置：-3+2t，Q 的位置：5-t。
相遇时 -3+2t = 5-t → 3t = 8 → t = 8/3 秒
相遇点：-3+2×(8/3) = -3+16/3 = 7/3

答案：8/3 秒后相遇，相遇点表示 7/3

## 第5题

**题目：** 已知 |a - 3| + (b + 2)² = 0，求 a - b 的值。

**解析：** |a-3| ≥ 0，(b+2)² ≥ 0，两个非负数之和为0 → 各自为0
a-3=0 → a=3
b+2=0 → b=-2
a-b = 3-(-2) = 5

答案：5

## 第6题

**题目：** 如果 a 是有理数，那么 |a| + a 的值可能是什么？请分情况讨论。

**解析：** 当 a ≥ 0 时，|a| = a，|a|+a = 2a ≥ 0
当 a < 0 时，|a| = -a，|a|+a = -a+a = 0
所以 |a|+a 的值要么是 0（a<0时），要么是正数（a>0时）。

答案：0 或正数，不可能是负数

## 第6题

**题目：** 已知a,b互为相反数，c,d互为倒数，|m|=2。求(a+b)/m+m^2-cd的值。

**解析：** a+b=0，cd=1，|m|=2所以m^2=4。原式=0/m+4-1=3。与m的符号无关。

## 第7题

**题目：** 若|x|=3，|y|=5，|z|=7，且x>y>z，求x,y,z。

**解析：** x的可能值:±3；y:±5；z:±7。由x>y>z且3>-5>-7，所以x=3,y=-5,z=-7。

## 第8题

**题目：** 已知a,b,c都是有理数，a<b<0<c，|a|>|c|。比较a,b,c,-a,-b,-c的大小。

**解析：** 先化简符号：-a>0,-b>0,-c<0。a<b<0所以-a>-b>0。|a|>|c|所以-a>c。排序：a<b<-c<c<-b<-a。
