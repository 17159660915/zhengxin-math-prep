## 第1题

**题目：** 已知 √(x - 2) + √(y + 3) + |z - 5| = 0，求 x + y + z 的值。

**解析：** 三个非负数之和为0 → 各自为0
x-2=0 → x=2
y+3=0 → y=-3
z-5=0 → z=5
x+y+z = 2-3+5 = 4

答案：4

## 第2题

**题目：** 比较大小：√(n+1) - √n 与 √(n+2) - √(n+1)（n 为正整数）。

**解析：** √(n+1)-√n = 1/(√(n+1)+√n)
√(n+2)-√(n+1) = 1/(√(n+2)+√(n+1))
因为 √(n+2)+√(n+1) > √(n+1)+√n
所以 1/(√(n+2)+√(n+1)) < 1/(√(n+1)+√n)
即 √(n+2)-√(n+1) < √(n+1)-√n

答案：√(n+1)-√n > √(n+2)-√(n+1)

## 第3题

**题目：** 已知 a 是 √10 的整数部分，b 是 √10 的小数部分，求 a - b 的值。

**解析：** 3²=9, 4²=16，所以 3<√10<4
a=3（整数部分）
b=√10-3（小数部分）
a-b = 3-(√10-3) = 6-√10

答案：6-√10

## 第4题

**题目：** 若 √a 的平方根是 ±3，求 a 的值。

**解析：** √a 的平方根是 ±3，说明 √a = 9
因为 9 的平方根是 ±3
所以 a = 81

答案：a=81

## 第5题

**题目：** 已知 x = √(3 + 2√2)，y = √(3 - 2√2)，求 x² + y² 和 xy 的值。

**解析：** x² = 3+2√2, y² = 3-2√2
x²+y² = 6
xy = √(3+2√2)(3-2√2) = √(9-8) = √1 = 1

答案：x²+y²=6, xy=1
