# 5.2 解一元一次方程 - 思维训练

## 第1题
**题目：** 解方程 3(x - 1) - 2(x + 1) = 5(x - 3) - 4(x - 2)，观察系数特征，找到最简解法。

**解析：** 两边分别展开：3x - 3 - 2x - 2 = 5x - 15 - 4x + 8，即 x - 5 = x - 7，两边减 x 得 -5 = -7，矛盾。所以方程无解。

## 第2题
**题目：** 已知关于 x 的方程 2(x - a) = 3x - 1 的解与方程 x - 3 = 2x + 1 的解互为相反数，求 a 的值。

**解析：** 解 x - 3 = 2x + 1 得 x = -4。互为相反数 → 另一个解为 4。代入 2(4 - a) = 3×4 - 1，得 8 - 2a = 12 - 1 = 11，-2a = 3，a = -3/2。


## 第3题

**题目：** 解方程：2(x - 1) - 3(x + 2) = 4 - (x - 5)。

**解析：** 2x - 2 - 3x - 6 = 4 - x + 5 → -x - 8 = 9 - x → -x + x = 9 + 8 → 0 = 17，方程无解。

## 第4题

**题目：** 解方程：x/2 - (x-1)/3 = 1。

**解析：** 两边乘6：3x - 2(x-1) = 6 → 3x - 2x + 2 = 6 → x = 4。

## 第5题

**题目：** 已知关于 x 的方程 2(x - k) = 3x - 4 的解是 x = 2，求 k 的值。

**解析：** 代入 x=2：2(2 - k) = 3×2 - 4 → 4 - 2k = 6 - 4 → 4 - 2k = 2 → -2k = -2 → k = 1。
