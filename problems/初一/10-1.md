## 第1题

**题目：** 解方程组：{ 3x + 2y = 11, 2x + 5y = 22 }

**解析：** 加减法：①×2 - ②×3
6x+4y=22, 6x+15y=66
相减：-11y=-44, y=4
代入①：3x+8=11, x=1

答案：{x=1, y=4}

## 第2题

**题目：** 已知 { x=2, y=1 } 是方程组 { ax+by=7, bx+ay=8 } 的解，求 a+b 的值。

**解析：** 代入得：2a+b=7…①, 2b+a=8…②
①+②：3a+3b=15, a+b=5

答案：a+b=5

## 第3题

**题目：** 一个两位数，个位数字与十位数字之和为 12，若交换十位与个位数字，新数比原数大 18，求原数。

**解析：** 设十位为 x，个位为 y
x+y=12
10y+x-(10x+y)=18 → 9y-9x=18 → y-x=2
解得：x=5, y=7
原数=57

答案：57

## 第4题

**题目：** 甲、乙两人同解方程组 { ax+by=2, cx-3y=4 }，甲正确解得 { x=1, y=-1 }，乙因抄错 c 解得 { x=2, y=-2 }，求 a、b、c 的值。

**解析：** 甲正确解代入：a-b=2…①, c+3=4 → c=1
乙抄错c，但没抄错a、b，代入ax+by=2：2a-2b=2 → a-b=1…②
①和②矛盾！说明乙抄错的方程是cx-3y=4，但ax+by=2没错。
等等，乙的解 {x=2,y=-2} 代入 ax+by=2：2a-2b=2, a-b=1。
而甲的解也满足 ax+by=2：a-b=2。
两个方程都成立说明 a-b 同时等于1和2，矛盾。
说明乙抄的是cx-3y=4以外的方程，即乙抄错了ax+by=2。
那么乙的解{x=2,y=-2}代入cx-3y=4：2c+6=4, c=-1
但甲的解代入cx-3y=4得c=1。
说明乙抄错了c，c的值应以甲为准：c=1

重新分析：甲解得 {x=1,y=-1} 代入 ax+by=2：a-b=2
乙抄错c，但ax+by=2没抄错，代入 {x=2,y=-2}：2a-2b=2, a-b=1
矛盾仍然存在，说明乙抄的方程不是ax+by=2。

实际上，两人解的是同一个方程组，甲正确解出c=1。
乙抄错了cx-3y=4中的c，所以乙的{x=2,y=-2}代入cx-3y=4时能得到解。
设乙抄的c为c'，则2c'+6=4, c'=-1
而a、b的解由甲的正确解给出：a-b=2
还需要另一个条件。由甲的解：a×1+b×(-1)=2, c×1-3×(-1)=4 → c=1

答案：c=1, a-b=2（a、b有无数解，如a=3,b=1）

## 第5题

**题目：** 某班组织活动，去公园划船。如果每条船坐 4 人，则多 3 人没船坐；如果每条船坐 5 人，则空出 2 个座位。求船的数量和人数。

**解析：** 设船 x 条，人数 y 人。
4x+3=y, 5x-2=y
4x+3=5x-2 → x=5
y=4×5+3=23

答案：5条船，23人
