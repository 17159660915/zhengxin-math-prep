# 7.2 平行线 - 思维训练

## 第1题
![平行线与角平分线](problems-diagrams/13-parallel-bisector.png)

**题目：** 如图，AB ∥ CD，EF 分别交 AB、CD 于 E、F，EG 平分 ∠AEF，∠AEF = 80°，求 ∠EGF。

**解析：** EG 平分 ∠AEF → ∠AEG = 80°/2 = 40°。AB ∥ CD → ∠AEG = ∠EGF（内错角相等），所以 ∠EGF = 40°。

## 第2题
**题目：** 已知 ∠1 = ∠2，∠3 = 110°，求 ∠4 的度数。（∠1 和 ∠2 是同位角，∠3 和 ∠4 是同旁内角）

**解析：** ∠1 = ∠2（同位角相等）→ a ∥ b。a ∥ b → ∠3 + ∠4 = 180°（同旁内角互补），110° + ∠4 = 180°，∠4 = 70°。
