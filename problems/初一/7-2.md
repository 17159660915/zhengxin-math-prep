# 7.2 平行线 - 思维训练

## 第1题

**题目：** 平面内有 2026 条直线，其中任意两条都相交，且任意三条不共点。这些直线将平面分成多少个区域？

**解析：** 1条直线将平面分成2个区域，2条直线分成4个区域，3条直线分成7个区域。规律：n条直线最多分成 (n²+n+2)/2 个区域。n=2026时：(2026²+2026+2)/2 = 2053352个区域。

## 第2题

**题目：** 两条直线被第三条直线所截，如果一对内错角的平分线互相平行，证明这两条直线也互相平行。

![示意图](problems-diagrams/p1-7-2-q2.png)

**解析：** ∠1 = ∠2（同位角相等）→ a ∥ b。a ∥ b → ∠3 + ∠4 = 180°（同旁内角互补），110° + ∠4 = 180°，∠4 = 70°。

## 第3题

**题目：** 两条平行线被第三条直线所截，一组同旁内角的度数之比为 2:7，求这两个角的度数。

**解析：** 同旁内角互补，和为180°。2k + 7k = 180° → 9k = 180° → k = 20°。两角为 40° 和 140°。

---

## 第4题

**题目：** 如图，AB ∥ CD，EF ⊥ AB 于 E，交 CD 于 F。若 ∠EFD = 30°，求 ∠AEF 的度数。

**解析：** EF ⊥ AB → ∠AEF = 90°。AB ∥ CD → ∠AEF 与 ∠EFD 是同旁内角，互补，所以 ∠AEF + ∠EFD = 180°，90° + 30° = 120° ≠ 180°，矛盾。说明 EF 不是简单截线，E 在 AB 上，F 在 CD 上，EF 与 AB 垂直，与 CD 不垂直，需重新分析图形。

## 第5题

**题目：** 已知直线 a ∥ b，直线 c 与 a、b 都相交。∠1 和 ∠2 是同旁内角，且 ∠1 = 3∠2 + 20°，求 ∠1 的度数。

**解析：** 同旁内角互补，∠1+∠2=180°。∠1=3∠2+20°，代入得 3∠2+20+∠2=180，4∠2=160，∠2=40°，∠1=140°。
