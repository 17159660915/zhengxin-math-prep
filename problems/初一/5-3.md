# 5.3 实际问题与一元一次方程 - 思维训练

## 第1题
**题目：** 一个两位数，十位数字与个位数字之和为 12。若将十位数字与个位数字交换，得到的新数比原数大 18。求原数。

**解析：** 设十位数字为 x，则个位数字为 12 - x。原数 = 10x + (12 - x) = 9x + 12。新数 = 10(12 - x) + x = 120 - 9x。新数 - 原数 = 18，即 (120 - 9x) - (9x + 12) = 18，108 - 18x = 18，x = 5。原数 = 57。

## 第2题
**题目：** 甲、乙两人分别从 A、B 两地同时出发相向而行，甲的速度是乙的 1.5 倍。相遇后甲继续走了 20 分钟到达 B 地，求乙从相遇点走到 A 地需要多少分钟。

**解析：** 设乙的速度为 v，则甲的速度为 1.5v。相遇时，甲走的距离 = 1.5v × t，乙走的距离 = v × t。相遇后甲走乙的路程 v × t，用时 20 分钟，即 v × t = 1.5v × 20，所以 t = 30 分钟。乙从相遇点走到 A 地需要走甲的路程 1.5v × 30 = 45v，用时 45v ÷ v = 45 分钟。


## 第3题

**题目：** 一个两位数，十位数字与个位数字之和为 7。若将十位与个位数字交换，得到的新数比原数大 27，求原数。

**解析：** 设十位为 x，个位为 7-x。原数 = 10x + (7-x) = 9x+7，新数 = 10(7-x) + x = 70-9x。新数-原数 = 27：70-9x-9x-7 = 27 → 63-18x=27 → 18x=36 → x=2。原数=25。

## 第4题

**题目：** 一列火车匀速行驶，经过一座长 300m 的桥需要 20s，完全在桥上的时间为 10s。求火车的长度和速度。

**解析：** 设车长 L(m)，速度 v(m/s)。经过桥（车头到桥头→车尾离开桥）：L+300 = 20v。完全在桥上（车尾上桥→车头离桥）：300-L = 10v。两式相加：600=30v，v=20m/s，L=100m。

## 第5题

**题目：** 商场将一种商品按标价 9 折出售，仍可获利 20%。若进价为 200 元，求标价。

**解析：** 设标价 x 元。0.9x - 200 = 200×20% = 40。0.9x = 240，x = 266.67 元。


## 第6题

**题目：** 某商品进价100元，标价150元。商店打x折销售后仍有20%的利润，求x的值。

**解析：** 打x折后售价=150*x/10=15x元。利润=15x-100，利润率=(15x-100)/100=0.2。15x-100=20，15x=120，x=8。打8折。

## 第7题

**题目：** 一项工程，甲单独做需10天完成，乙单独做需15天完成。甲先做3天，乙加入合作，还需几天？

**解析：** 甲效率1/10，乙效率1/15。甲做3天完成3/10。剩余7/10。合作效率=1/10+1/15=1/6。还需(7/10)/(1/6)=4.2天。

## 第8题

**题目：** 甲乙两人在环形跑道跑步，甲6米/秒，乙4米/秒，跑道周长400米。同向出发，多久第一次相遇？

**解析：** 速度差=6-4=2米/秒。追及距离=400米。时间=400/2=200秒。
