# 10.2 消元——解二元一次方程组 - 思维训练

## 第1题
**题目：** 解方程组 { 2x + 3y = 7，4x - 3y = 5 }，用加减消元法。

**解析：** ① + ② 消去 y：6x = 12 → x = 2。代入①：4 + 3y = 7 → 3y = 3 → y = 1。解为 { x = 2，y = 1 }。

## 第2题
**题目：** 解方程组 { 3x + 4y = 10，5x - 6y = 33 }，选择最简便的解法。

**解析：** ①×3：9x + 12y = 30，②×2：10x - 12y = 66。两式相加：19x = 96，x = 96/19。代入①：3×96/19 + 4y = 10，288/19 + 4y = 190/19，4y = -98/19，y = -49/38。


## 第3题

**题目：** 解方程组：{ 2x + 3y = 12, 3x - 2y = 5 }（用加减消元法）

**解析：** ①×2：4x+6y=24，②×3：9x-6y=15。相加：13x=39，x=3。代入①：6+3y=12，y=2。解为 {x=3, y=2}。

## 第4题

**题目：** 已知关于 x、y 的方程组 { ax + by = 7, bx + ay = 8 } 的解为 {x=2, y=1}，求 a、b 的值。

**解析：** 代入：2a + b = 7，2b + a = 8。解得 a=2，b=3。

## 第5题

**题目：** 解方程组：{ x/2 + y/3 = 5, x/3 - y/2 = 1 }。

**解析：** ①×6：3x+2y=30，②×6：2x-3y=6。①×3：9x+6y=90，②×2：4x-6y=12。相加：13x=102，x=102/13。代入：3×102/13+2y=30，306/13+2y=390/13，2y=84/13，y=42/13。
