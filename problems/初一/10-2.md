# 10.2 消元——解二元一次方程组 - 思维训练

## 第1题
**题目：** 解方程组 { 2x + 3y = 7，4x - 3y = 5 }，用加减消元法。

**解析：** ① + ② 消去 y：6x = 12 → x = 2。代入①：4 + 3y = 7 → 3y = 3 → y = 1。解为 { x = 2，y = 1 }。

## 第2题
**题目：** 解方程组 { 3x + 4y = 10，5x - 6y = 33 }，选择最简便的解法。

**解析：** ①×3：9x + 12y = 30，②×2：10x - 12y = 66。两式相加：19x = 96，x = 96/19。代入①：3×96/19 + 4y = 10，288/19 + 4y = 190/19，4y = -98/19，y = -49/38。
