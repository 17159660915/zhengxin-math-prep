# 11.3 一元一次不等式组 - 思维训练

## 第1题
**题目：** 若不等式组 { x > a, x ≤ 3 } 有 4 个整数解，求 a 的取值范围。

**解析：** 解①：2x > 4 → x > 2。解②：x ≤ 6。解集：2 < x ≤ 6。整数解：x = 3, 4, 5, 6。

## 第2题
**题目：** 若不等式组 { x > a，x < 2 } 有解，且所有整数解的和为 0，求 a 的取值范围。

**解析：** 有解 → a < 2。解集为 a < x < 2。整数解的和为 0 → 可能的整数有 -1、0、1 或 -1、0 或 0、1 等。若整数解为 -1、0、1，则 -2 ≤ a < -1。若整数解为 0、1，则 -1 ≤ a < 0。若整数解为 1，则 0 ≤ a < 1。多种情况，需要具体看 a 的范围。


## 第3题

**题目：** 解不等式组：{ 2x + 1 > 3, 3x - 4 ≤ 8 }，并在数轴上表示解集。

**解析：** ①：2x>2，x>1。②：3x≤12，x≤4。解集：1 < x ≤ 4。

## 第4题

**题目：** 已知关于 x 的不等式组 { x > a, x ≤ 2 } 有 3 个整数解，求 a 的取值范围。

**解析：** 解集为 a < x ≤ 2。3个整数解为 2, 1, 0。所以 -1 ≤ a < 0。

## 第5题

**题目：** 某校分配宿舍，每间住 4 人则 19 人没床位，每间住 6 人则有一间不满也不空。求宿舍间数和学生人数。

**解析：** 设宿舍 x 间，学生 4x+19 人。0 < 6x - (4x+19) < 6 → 0 < 2x-19 < 6 → 19 < 2x < 25 → 9.5 < x < 12.5。x=10,11,12。x=10时59人，x=11时63人，x=12时67人。


## 第6题

**题目：** 解不等式组：{2x+1>3，3x-4<=8}，并在数轴上表示解集。

**解析：** 2x+1>3 -> 2x>2 -> x>1。3x-4<=8 -> 3x<=12 -> x<=4。解集：1<x<=4。

**题目：** 已知关于x的不等式组{x>a，x<=2}有3个整数解，求a的取值范围。

**解析：** 整数解为0,1,2 -> -1<=a<0。

## 第8题

**题目：** 若不等式组{x>a，x<2}有解，且所有整数解的和为0，求a的取值范围。

**解析：** 有解 -> a<2。整数解：若a<=-2，整数解为-1,0,1，和为0。若-2<a<=-1，整数解为0,1，和为1。若-1<a<2，整数解为0,1或1，和不为0。所以a<=-2。
