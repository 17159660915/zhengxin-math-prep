# 3.2 代数式的值 - 思维训练

## 第1题
**题目：** 当 x = -2 时，代数式 ax³ + bx + 1 的值为 6。求当 x = 2 时，这个代数式的值。

**解析：** 代入 x = -2：a(-8) + b(-2) + 1 = 6，即 -8a - 2b = 5。当 x = 2 时：8a + 2b + 1 = -( -8a - 2b ) + 1 = -5 + 1 = -4。所以值为 -4。

## 第2题
**题目：** 已知 a + b = 3，ab = 1，求 a² + b² 的值。

**解析：** (a + b)² = a² + 2ab + b²，所以 a² + b² = (a + b)² - 2ab = 9 - 2 = 7。


## 第3题

**题目：** 已知 a² + a = 1，求 a³ + 2a² + 2026 的值。

**解析：** a³ + 2a² = a(a² + a) + a² = a×1 + a² = a + a² = 1。所以原式 = 1 + 2026 = 2027。

## 第4题

**题目：** 当 x = 1 时，代数式 ax³ + bx + 1 的值为 5。求当 x = -1 时，ax³ + bx + 1 的值。

**解析：** x=1：a + b + 1 = 5，a + b = 4。x=-1：-a - b + 1 = -(a+b) + 1 = -4 + 1 = -3。

## 第5题

**题目：** 已知 x² - 2x = 5，求 2x² - 4x + 3 的值。

**解析：** 2x² - 4x + 3 = 2(x² - 2x) + 3 = 2×5 + 3 = 13。
