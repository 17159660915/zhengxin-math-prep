## 第1题

**题目：** 在 △ABC 中，DE ∥ BC，AD:DB = 2:3，DE = 4，求 BC 的长。

**解析：** DE ∥ BC → △ADE ∽ △ABC
AD:DB=2:3 → AD:AB=2:5
DE:BC = AD:AB = 2:5
4:BC = 2:5, BC = 10

答案：BC=10

---

## 第2题

**题目：** 在 △ABC 中，D、E 分别在 AB、AC 上，且 DE ∥ BC，若 AD = 2，DB = 3，AE = 3，求 EC 的长。

**解析：** DE ∥ BC → AD/AB = AE/AC
2/5 = 3/(3+EC)
2(3+EC) = 15, 6+2EC=15, EC=4.5

答案：EC=4.5

## 第3题

**题目：** 在 Rt△ABC 中，∠C = 90°，CD ⊥ AB 于 D。若 AD = 4，BD = 9，求 CD 的长。

**解析：** △ACD ∽ △CBD（母子相似）
CD² = AD×BD = 4×9 = 36, CD = 6

答案：6

## 第4题

**题目：** 在 △ABC 中，∠C = 90°，CD ⊥ AB 于 D。若 AD = 4，BD = 9，求 AC 和 BC 的长。

**解析：** AC² = AD×AB = 4×13 = 52, AC = 2√13
BC² = BD×AB = 9×13 = 117, BC = 3√13

答案：AC=2√13, BC=3√13

## 第5题

**题目：** 在 △ABC 中，∠BAC = 90°，AD ⊥ BC 于 D，DE ⊥ AB 于 E，DF ⊥ AC 于 F。求证：AE×AB = AF×AC。

**解析：** △AED ∽ △ADB → AE/AD = AD/AB → AE×AB = AD²
△AFD ∽ △ADC → AF/AD = AD/AC → AF×AC = AD²
∴ AE×AB = AF×AC = AD²

答案：AE×AB = AF×AC

## 第6题

**题目：** 在△ABC中DE∥BC，AD:DB=2:3，DE=4，求BC。

**解析：** AD/AB=DE/BC，2/5=4/BC，BC=10。

## 第7题

**题目：** 在Rt△ABC中∠C=90度，CD⊥AB于D。AD=4，BD=9，求CD。

**解析：** 射影定理：CD^2=AD*BD=4*9=36，CD=6。

## 第8题

**题目：** 在△ABC中∠BAC=90度，AD⊥BC于D，DE⊥AB于E，DF⊥AC于F。求证：AE*AB=AF*AC。

**解析：** 射影定理：AD^2=AE*AB，AD^2=AF*AC。所以AE*AB=AF*AC。
