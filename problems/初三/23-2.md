# 23.2 中心对称 - 思维训练

## 第1题

**题目：** 下列图形中哪些是中心对称图形？等边三角形、平行四边形、线段、正五边形。

**解析：** 平行四边形是（旋转180度与自身重合），线段是（绕中点旋转180度重合）。等边三角形和正五边形不是中心对称图形。

## 第2题
**题目：** 点A(2,-5)关于原点对称的点B的坐标是多少？

**解析：** 关于原点对称，横纵坐标都取相反数。B(-2,5)。


## 第3题

**题目：** 点 A(3, -2) 关于原点对称的点 B 的坐标是什么？B 关于 y 轴对称的点 C 的坐标是什么？

**解析：** B(-3, 2)，C(3, 2)。

## 第4题

**题目：** 判断：① 平行四边形是中心对称图形。② 正五边形是中心对称图形。③ 圆是中心对称图形。

**解析：** ①√，平行四边形绕对角线交点旋转180°与自身重合。②×，正五边形不是中心对称图形。③√，圆绕圆心旋转任意角度都与自身重合。

## 第5题

**题目：** 如图，△ABC 与 △A'B'C' 关于点 O 中心对称，AB = 5，AC = 6，∠BAC = 60°，求 A'B' 的长和 ∠B'A'C' 的度数。

**解析：** 中心对称图形全等，A'B'=AB=5，∠B'A'C'=∠BAC=60°。
