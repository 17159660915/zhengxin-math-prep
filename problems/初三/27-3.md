# 27.3 位似 - 思维训练

## 第1题

**题目：** 以原点为位似中心，将点P(3,2)缩小1/2倍，求对应点坐标。

**解析：** P'(3*1/2,2*1/2)=(1.5,1)或P'(-3*1/2,-2*1/2)=(-1.5,-1)。

## 第2题

**题目：** 以原点为位似中心，将图形放大2倍，点A(1,2)的对应点坐标是什么？

**解析：** A'(2,4)或A'(-2,-4)。


## 第3题

**题目：** 以原点为位似中心，将点 A(2, 3) 放大 2 倍，求对应点 A' 的坐标。

**解析：** A'(2×2, 3×2) = (4, 6) 或 A'(-4, -6)（放大2倍并反向）。

## 第4题

**题目：** 以原点为位似中心，将点 B(-3, 4) 缩小到原来的 1/2，求对应点 B' 的坐标。

**解析：** B'(-3/2, 4/2) = (-1.5, 2) 或 B'(1.5, -2)。

## 第5题

**题目：** 两个位似图形的面积比为 4:9，求它们的相似比。

**解析：** 面积比 = 相似比的平方。k² = 4/9，k = 2/3 或 3/2。


## 第6题

**题目：** 以原点为位似中心，将点P(3,2)缩小1/2倍，求对应点坐标。

**解析：** P'(3*1/2,2*1/2)=(1.5,1)。

## 第7题

**题目：** 以原点为位似中心，将点A(2,3)放大2倍，求对应点A'坐标。

**解析：** A'(2*2,3*2)=(4,6)。

---

## 第8题

**题目：** 以原点为位似中心，将点B(-3,4)缩小到1/2，求对应点B'坐标。

**解析：** B'(-3*1/2,4*1/2)=(-1.5,2)。
