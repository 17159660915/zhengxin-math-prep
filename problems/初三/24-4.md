# 24.4 弧长和扇形面积 - 思维训练

## 第1题
**题目：** 半径为6，圆心角120度的弧长和扇形面积。


**解析：** l=120*pi*6/180=4pi。S=120*pi*36/360=12pi。

## 第2题
**题目：** **题目：** 扇形的圆心角为 150，弧长为 10，求扇形的半径和面积。

**解析：** l = nR/180，10 = 150 x R/180，R = 12。S = nR/360 = 150 x 144 x /360 = 60。
## 第3题

**题目：** 一个扇形的圆心角为 120°，半径为 9。用它围成一个圆锥的侧面，求圆锥的底面半径和高。

**解析：** S侧 = πrl = π×3×5 = 15π。S底 = πr² = 9π。S全 = 15π+9π = 24π。

## 第4题

**题目：** 一个扇形的半径为 6，弧长为 4π，求圆心角度数和扇形面积。

**解析：** l = nπr/180，4π = nπ×6/180，n = 120°。S = 1/2×l×r = 1/2×4π×6 = 12π。

## 第5题

**题目：** 圆的半径为 10，一条弦所对的圆心角为 60°，求这条弦的长度。

**解析：** 弦与圆心构成等边三角形，弦长 = 半径 = 10。



## 第6题

**题目：** 半径为 9，圆心角 80 的弧长和扇形面积。

**解析：** l = nR/180 = 80 x 9 x /180 = 4。S = nR/360 = 80 x 81 x /360 = 18。

## 第7题

**题目：** 圆锥的底面周长为 6，母线长为 4，求侧面积和底面半径。

**解析：** 底面周长 = 2r = 6，r = 3。S侧 = rl = x 3 x 4 = 12。

## 第7题

**题目：** 圆锥底面半径3，母线长5，求侧面积和全面积。

**解析：** S侧=πrl=15π，S底=9π，S全=24π。
