## 第1题

**题目：** 在 Rt△ABC 中，∠C=90°，a、b、c 分别为∠A、∠B、∠C的对边。若 sinA + sinB = 7/5，且 a+b=7，求 c 的值。

**解析：** sin²A+cos²A=1, cos²A = 1-9/25 = 16/25, cosA=4/5
tanA = sinA/cosA = 3/4

答案：cosA=4/5, tanA=3/4

## 第2题

**题目：** 在 Rt△ABC 中，∠C = 90°，AB = 10，∠A = 30°，求 BC 和 AC 的长。

**解析：** BC = AB×sin30° = 10×0.5 = 5
AC = AB×cos30° = 10×√3/2 = 5√3

答案：BC=5, AC=5√3

## 第3题

**题目：** 在 △ABC 中，∠A = 30°，∠B = 45°，AC = 2√2，求 BC 的长。

**解析：** ∠C = 180°-30°-45° = 105°
正弦定理：BC/sin30° = AC/sin45°
BC/(1/2) = 2√2/(√2/2) = 4
BC = 2

答案：BC=2

## 第4题

**题目：** 在 △ABC 中，∠C = 90°，CD ⊥ AB 于 D，AD = 3，BD = 2，求 tan∠A 的值。

**解析：** CD² = AD×BD = 3×2 = 6, CD = √6
在 Rt△ACD 中，tan∠A = CD/AD = √6/3

答案：tan∠A = √6/3

## 第5题

**题目：** 在 △ABC 中，∠C = 90°，∠A = 15°，AB = 2，求 BC 的长（用根号表示）。

**解析：** sin15° = sin(45°-30°) = sin45°cos30°-cos45°sin30°
= (√2/2)(√3/2) - (√2/2)(1/2)
= (√6-√2)/4
BC = AB×sin15° = 2×(√6-√2)/4 = (√6-√2)/2

答案：(√6-√2)/2
