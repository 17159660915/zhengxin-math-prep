# 27.2 相似三角形 - 思维训练

## 第1题
**题目：** 三角形ABC中，DE平行于BC，AD=2，DB=3，DE=4，求BC。


**解析：** DE平行于BC，三角形ADE相似于三角形ABC。AD/AB=DE/BC，2/5=4/BC，BC=10。

## 第2题
**题目：** 三角形ABC相似于三角形DEF，相似比为3:2，AB=6，求DE。


**解析：** AB/DE=3/2，6/DE=3/2，DE=4。


## 第3题

**题目：** 如图，DE ∥ BC，AD = 2，DB = 3，AE = 3，求 EC 的长。

**解析：** DE ∥ BC → △ADE ∽ △ABC。AD/AB = AE/AC，2/5 = 3/(3+EC)，2(3+EC)=15，6+2EC=15，EC=4.5。

## 第4题

**题目：** 两个相似三角形的相似比为 2:3，周长差为 10，求大三角形的周长。

**解析：** 周长比 = 相似比 = 2:3。设小周长为 2k，大周长为 3k。3k-2k=10，k=10。大周长=30。

## 第5题

**题目：** 如图，∠A = ∠D，∠B = ∠E，AB = 6，DE = 4，BC = 9，求 EF 的长。

**解析：** ∠A=∠D，∠B=∠E，△ABC ∽ △DEF。AB/DE = BC/EF，6/4 = 9/EF，EF=6。


## 第6题

**题目：** 三角形ABC中DE∥BC，AD=2，DB=3，DE=4，求BC。

**解析：** AD/AB=DE/BC，2/5=4/BC，BC=10。

---

## 第7题

**题目：** 两个相似三角形相似比3:2，AB=6，求DE。

**解析：** AB/DE=3/2，6/DE=3/2，DE=4。

---

## 第8题

**题目：** 两个相似三角形相似比2:3，周长差10，求大三角形周长。

**解析：** 设小周长2k，大周长3k。3k-2k=10，k=10。大周长=30。
