## 第1题

**题目：** 在同一时刻，一根 1.6m 的竹竿的影长为 0.8m，一棵树的影长为 3.2m，求树高。


**解析：** 平行投影，物高与影长成正比
1.6/0.8 = h/3.2, h = 1.6×3.2/0.8 = 6.4m

答案：6.4m

## 第2题

**题目：** 一个几何体的主视图和左视图都是三角形，俯视图是圆（含圆心），这个几何体是什么？

**解析：** 主视图是三角形 → 从正面看是三角形
左视图是三角形 → 从左面看是三角形
俯视图是圆（含圆心）→ 从上面看是圆
这是圆锥。

答案：圆锥

## 第3题

**题目：** 由若干个相同的小正方体搭成的几何体，主视图有 3 列，每列最高分别为 2、1、2 层；左视图有 2 列，最高分别为 2、1 层。求最少需要几个小正方体？

**解析：** 从俯视图入手，结合主视图和左视图。
最少需要 5 个（主视图的 2,1,2 与左视图的 2,1 结合）。

答案：5 个

## 第4题

**题目：** 一个几何体的三视图都是圆，这个几何体是什么？

**解析：** 三视图都是圆 → 球体。

答案：球体

## 第5题


**题目：** 如图，一个圆柱的底面半径为 2，高为 5，求它的主视图的面积。

**解析：** 主视图是长方形，宽 = 2r = 4，高 = 5
面积 = 4×5 = 20

答案：20
