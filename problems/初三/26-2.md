# 26.2 实际问题与反比例函数 - 思维训练

## 第1题
**题目：** 路程为120km，速度v与时间t的关系是什么？

**解析：** vt=120，v=120/t（t>0）。

## 第2题
**题目：** 某蓄水池有水1000m^3，放出速度为v m^3/h，放完需要t h，写出v与t的函数关系式。

**解析：** vt=1000，v=1000/t（t>0）。


## 第3题

**题目：** 某水池蓄水 100m³，放水速度 v(m³/h) 与放水时间 t(h) 成反比例。写出 v 与 t 的函数关系式，并求 t=5 时的 v。

**解析：** vt = 100，v = 100/t。t=5时 v=20m³/h。

## 第4题

**题目：** 面积为 12 的矩形，长 y 与宽 x 成反比例。求 y 关于 x 的函数解析式，并求 x=3 时的 y。

**解析：** xy = 12，y = 12/x。x=3时 y=4。

## 第5题

**题目：** 反比例函数 y = k/x 的图象经过点 (2, 3)，求 k 的值，并判断点 (3, -2) 是否在图象上。

**解析：** k = 2×3 = 6。点 (3, -2) 代入：3×(-2) = -6 ≠ 6，不在图象上。
