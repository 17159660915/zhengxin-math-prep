# 28.2 解直角三角形 - 思维训练

## 第1题
**题目：** Rt三角形ABC中，角C=90度，角A=30度，c=10，求a、b。


**解析：** sin30度=a/10，a=10*1/2=5。cos30度=b/10，b=10*根号3/2=5根号3。

## 第2题
**题目：** 某建筑物高30m，从楼顶看地面点的俯角为45度，求该点与楼底的距离。


**解析：** tan45度=30/x，x=30/tan45度=30m。


## 第3题

**题目：** 在 Rt△ABC 中，∠C = 90°，∠A = 30°，AB = 10，求 BC 和 AC 的长。

**解析：** 30°所对直角边是斜边的一半：BC = AB/2 = 5。AC = √(10²-5²) = √75 = 5√3。

## 第4题

**题目：** 在 Rt△ABC 中，∠C = 90°，AC = 6，BC = 8，求 sinA 和 cosA 的值。

**解析：** AB = √(36+64) = 10。sinA = BC/AB = 8/10 = 4/5，cosA = AC/AB = 6/10 = 3/5。

## 第5题

**题目：** 如图，从地面 A 点看山顶 C 的仰角为 30°，向山前进 100m 到 B 点，仰角变为 45°。求山高 CD。

**解析：** 设 CD = h。在 Rt△BCD 中，BD = h（45°等腰直角三角形）。在 Rt△ACD 中，AD = h/√3 = h√3/3。AD-BD = 100，h√3/3 - h = 100，h(√3/3-1)=100，h = 100/(√3/3-1) = 100/((√3-3)/3) = 300/(√3-3) = 300(√3+3)/(3-9) = 300(√3+3)/(-6) = 50(√3+3) ≈ 236.6m。


## 第6题

**题目：** Rt三角形ABC中，角C=90度，角A=30度，c=10，求a、b。

**解析：** a=c*sin30=10*1/2=5。b=c*cos30=10*√3/2=5√3。

## 第7题

**题目：** 某建筑物高30m，从楼顶看地面点的俯角45度，求该点与楼底距离。

**解析：** tan45=30/d，d=30/tan45=30m。

## 第8题

**题目：** Rt三角形ABC中，角C=90度，AC=6，BC=8，求sinA。

**解析：** AB=sqrt(36+64)=10。sinA=BC/AB=8/10=4/5。
