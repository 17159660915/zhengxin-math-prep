# 29.3 课题学习 制作立体模型 - 思维训练

## 第1题
**题目：** 用橡皮泥制作一个几何体模型，使其三视图分别为：主视图是长方形，左视图是长方形，俯视图是三角形。这个几何体是什么形状？如果三视图都是长方形，又是什么？

**解析：** 球体。

## 第2题
**题目：** 由小正方体搭成的几何体，主视图有3列，每列最高分别为2、1、2层，左视图有2列，最高分别为2、1层，最少需要几个小正方体？

**解析：** 从俯视图落位，满足主视图和左视图的条件，最少需要5个。


## 第3题

**题目：** 一个几何体的三视图是三个全等的正方形，这是什么几何体？它的表面积和体积有什么关系？

**解析：** 正方体。设棱长为 a，表面积=6a²，体积=a³。表面积=6×体积的2/3次方。

## 第4题

**题目：** 用橡皮泥制作一个三棱柱的模型，它的三视图分别是什么？

**解析：** 三棱柱的主视图是矩形（或三角形，取决于摆放方向），左视图是矩形，俯视图是三角形。

## 第5题

**题目：** 一个几何体的三视图分别是：主视图是等腰三角形，左视图是等腰三角形，俯视图是圆（含圆心）。求这个几何体可能是什么，并计算当底面半径为 3、高为 4 时它的体积。

**解析：** 圆锥。体积=1/3π×3²×4=12π。


## 第6题

**题目：** 用橡皮泥制作一个几何体模型，三视图分别为：主视图长方形，左视图长方形，俯视图圆。这是什么几何体？

**解析：** 圆柱体。

---

## 第7题

**题目：** 一个几何体的三视图是三个全等的正方形，这是什么几何体？表面积和体积有什么关系？

**解析：** 正方体。表面积=6a^2，体积=a^3。

## 第8题

**题目：** 一个几何体的三视图：主视图等腰三角形，左视图等腰三角形，俯视图圆（含圆心），这是什么几何体？

**解析：** 圆锥。
