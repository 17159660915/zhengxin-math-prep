# 22.3 实际问题与二次函数 - 思维训练

## 第1题
**题目：** 某商品进价50元，售价80元时可卖200件。每降价1元多卖10件，求最大利润时的售价和最大利润。

**解析：** 设降价x元，利润y元。y=(30-x)(200+10x)=-10x^2+100x+6000。x=-100/(-20)=5，y=-10*25+100*5+6000=6250。售价=80-5=75元，最大利润6250元。

## 第2题
**题目：** 用40m的篱笆靠墙围一个矩形菜地，求最大面积和此时的长宽。

**解析：** 设垂直于墙的边长为x m，平行于墙的边长为(40-2x)m。面积S=x(40-2x)=-2x^2+40x。x=-40/(-4)=10，S=200。宽10m，长20m，最大面积200m^2。


## 第3题

**题目：** 某商品进价 50 元，售价 80 元时可卖 200 件。每降价 1 元多卖 10 件，求最大利润时的售价和最大利润。

**解析：** 设降价 x 元，利润 y = (30-x)(200+10x) = -10x²+100x+6000。x = -100/(-20)=5，y=6250。售价75元，最大利润6250元。

## 第4题

**题目：** 用 40m 的篱笆靠墙围一个矩形菜地，求最大面积和此时的长宽。

**解析：** 设垂直于墙的边长为 x m，则平行于墙的边长为 40-2x。S = x(40-2x) = -2x²+40x。x = -40/(-4)=10，S=200。宽10m，长20m，最大面积200m²。

## 第5题

**题目：** 一座抛物线形拱桥，水面宽 8m 时拱顶离水面 4m。水面下降 1m 时，水面宽度增加多少？

**解析：** 以拱顶为原点建坐标系，抛物线过 (4,-4)。设 y=ax²，代入得 a=-1/4。水面下降1m后 y=-5，-5=-1/4 x²，x²=20，x=±2√5。宽度=4√5≈8.94m，增加 8.94-8=0.94m。


## 第6题

**题目：** 某商品进价50元，售价80元时可卖200件。每降价1元多卖10件，求最大利润。

**解析：** 设降价x元，利润y=(30-x)(200+10x)=-10x^2+100x+6000。x=-100/(-20)=5。y=6250。售价75元，最大利润6250元。

**题目：** 抛物线y=ax^2过点(2,8)，求a的值及对称轴。

**解析：** 8=a*4，a=2。y=2x^2，对称轴x=0。
