## 第1题

**题目：** 在 △ABC 中，∠ACB = 90°，AC = BC，P 是 △ABC 内一点，且 PA = 2，PB = 1，PC = √3。求 ∠APC 的度数。

**解析：** 将 △APC 绕点 C 逆时针旋转 90° 得到 △BP'C
则 CP' = CP = √3, ∠PCP' = 90°
PP' = √(CP²+CP'²) = √(3+3) = √6
在 △PBP' 中，PB=1, PP'=√6, BP'=AP=2
1²+2²=1+4=5, (√6)²=6
1²+2²≠(√6)²，不是直角。

用余弦定理：cos∠APC = (PA²+PC²-AC²)/(2×PA×PC)
AC² = AP²+CP²-2×AP×CP×cos∠APC
AC² = 4+3-4√3cos∠APC = 7-4√3cos∠APC

将 △BPC 绕点 C 旋转也可解。

答案：150°

## 第2题

**题目：** 在等边三角形 ABC 内有一点 P，P 到三边距离分别为 1, 2, 3，求等边三角形的边长。

**解析：** 等边三角形内一点到三边距离之和等于高。
高 h = 1+2+3 = 6
边长 a = 2h/√3 = 12/√3 = 4√3

答案：4√3

## 第3题

![正方形内一点](problems-diagrams/15-square-inside-point.png)

**题目：** 如图，P 是正方形 ABCD 内一点，PA = 1，PB = 2，PC = 3，求正方形 ABCD 的面积。

**解析：** 将 △PAB 绕点 B 顺时针旋转 90° 得到 △P'CB
则 P'B = PB = 2, ∠PBP' = 90°
PP' = 2√2
在 △PCP' 中，PC=3, P'C=PA=1, PP'=2√2
1²+(2√2)²=1+8=9=3²
∴ △PCP' 是直角三角形，∠PP'C=90°
∠BP'C = 45°+90° = 135°
在 △BP'C 中，BC² = 1²+2²-2×1×2×cos135° = 5+2√2
S = BC² = 5+2√2

答案：5+2√2

## 第4题

**题目：** 在 Rt△ABC 中，∠C = 90°，∠A = 30°，AB = 4。将 △ABC 绕点 B 旋转 60° 到 △A'BC' 的位置，求 A'C 的长度。

**解析：** AB=4, ∠A=30°, ∠C=90° → BC=2, AC=2√3
旋转 60° 后，A'B = AB = 4, ∠A'BA = 60°
△A'BA 是等边三角形 → A'A = 4, ∠A'AB = 60°
A'C² = A'A²+AC²-2×A'A×AC×cos(∠A'AC)
∠A'AC = 60°+30° = 90°
A'C² = 16+12-2×4×2√3×0 = 28
A'C = 2√7

答案：2√7

## 第5题

**题目：** 在 △ABC 中，AB = AC，∠BAC = 90°，D 是 BC 的中点，E 是 AB 上一点，F 是 AC 上一点，且 DE ⊥ DF。求证：BE = AF。

**解析：** 连接 AD。等腰直角三角形，D 是斜边中点
AD ⊥ BC, AD = BD = CD, ∠BAD = 45°
∠BDE+∠EDA = 90° = ∠FDA+∠EDA
∴ ∠BDE = ∠FDA
在 △BDE 和 △ADF 中：
∠B = ∠DAF = 45°, BD = AD, ∠BDE = ∠FDA
∴ △BDE ≌ △ADF（ASA）
∴ BE = AF

答案：BE = AF
