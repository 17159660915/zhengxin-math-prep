## 第1题

**题目：**

 在 ⊙O 中，弦 AB = 8，圆心 O 到弦 AB 的距离为 3，求 ⊙O 的半径。

**解析：** 过 O 作 OC ⊥ AB 于 C，则 AC = BC = 4
在 Rt△OAC 中，OC = 3, AC = 4
OA² = 3²+4² = 25, OA = 5

答案：5

---

## 第2题

**题目：** 在 ⊙O 中，直径 AB 和弦 CD 互相平分，且 AB = 10，CD = 8，求 AB 和 CD 之间的距离。


**解析：** 直径 AB 和弦 CD 互相平分 → 交点 O 是圆心
过 O 作 OE ⊥ CD 于 E
CE = 4, OC = 5
OE = √(5²-4²) = 3
AB 和 CD 的距离就是 OE = 3

答案：3

---

## 第3题

**题目：** 在 ⊙O 中，半径为 5，弦 AB ∥ CD，AB = 6，CD = 8，求 AB 和 CD 之间的距离。

**解析：** 分两种情况：
① AB 和 CD 在圆心同侧：
O 到 AB 距离 d₁ = √(5²-3²) = 4
O 到 CD 距离 d₂ = √(5²-4²) = 3
距离 = 4-3 = 1
② AB 和 CD 在圆心异侧：
距离 = 4+3 = 7

答案：1 或 7

## 第4题

**题目：** 在 △ABC 中，AB = AC = 5，BC = 6，求 △ABC 外接圆的半径。

**解析：** 等腰三角形，作 AD ⊥ BC 于 D
BD = CD = 3, AD = √(5²-3²) = 4
S△ABC = 1/2×6×4 = 12
外接圆半径 R = abc/(4S) = 5×5×6/(4×12) = 150/48 = 25/8

答案：25/8

## 第5题

**题目：** 在 ⊙O 中，弦 AB、CD 相交于 E，且 AE = 4，EB = 9，CE = 3，求 ED 的长。

**解析：** 相交弦定理：AE×EB = CE×ED
4×9 = 3×ED, 36 = 3ED, ED = 12

答案：12
