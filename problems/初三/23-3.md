# 23.3 课题学习 图案设计 - 思维训练

## 第1题
**题目：** 将正方形 ABCD 绕其中心 O 逆时针旋转 45°，正方形四个顶点会落在什么位置？画出旋转后的正方形与原正方形重叠部分的形状。

**解析：** 将等边三角形绕其中心旋转60度、120度、180度、240度、300度，可以得到正六边形图案。

## 第2题

**题目：** 请你设计一个"基本图形"，通过平移、旋转、轴对称三种变换的组合，生成一个无限延伸的墙纸图案，并说明每一步的变换方式。

**解析：** 任意选择一个基本图形（如一个L形），先沿水平方向平移复制，再沿垂直方向平移复制，或通过旋转90°后平移。关键：每种变换都要说明变换中心和方向。


## 第3题

**题目：** 利用平移、旋转、轴对称设计一个班徽图案，要求包含几何元素。

**解析：** 可以用一个三角形为基本图形，旋转一周得到星形，再对称得到完整图案。注意颜色搭配和对称性。

## 第4题

**题目：** 一个正方形图案，绕中心旋转 90° 后与自身重合，它还有什么对称性？

**解析：** 旋转90°与自身重合，则旋转180°、270°、360°都与自身重合。同时它关于两条对角线和两条中线都对称。

## 第5题

**题目：** 用平移变换设计一个花边图案，要求基本图形是平行四边形，沿水平方向平移。

**解析：** 画一个平行四边形，沿水平方向复制平移，每个平移距离为平行四边形的底边长，得到连续的花边图案。


## 第6题

**题目：** 利用平移、旋转、轴对称设计一个班徽图案，要求包含几何元素。

**解析：** 以圆形为外框，内部用对称的三角形和矩形组合，通过旋转90度形成花形图案。

---

## 第7题

**题目：** 用平移变换设计一个花边图案，要求基本图形是平行四边形，沿水平方向平移。

**解析：** 画一个平行四边形，沿水平方向每次平移相同距离，重复排列形成花边。

---

## 第8题

**题目：** 一个基本图形经过哪些变换可以得到一个中心对称图形？

**解析：** 将基本图形绕某点旋转180度，再与原图形组合，即可得到中心对称图形。
