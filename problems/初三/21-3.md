# 21.3 实际问题与一元二次方程 - 思维训练

## 第1题
**题目：** 某工厂两年内产值从100万增长到121万，求平均年增长率。

**解析：** 设平均年增长率为x。100(1+x)^2=121，(1+x)^2=1.21，1+x=+-1.1，x1=0.1=10%，x2=-2.1（舍去）。平均年增长率为10%。

## 第2题
**题目：** 两个连续正整数的积为56，求这两个数。

**解析：** 设较小的数为x，则较大的数为x+1。x(x+1)=56，x^2+x-56=0，(x+8)(x-7)=0，x1=7，x2=-8（舍去）。这两个数为7和8。


## 第3题

**题目：** 某商品原价 100 元，连续两次降价后为 81 元，求平均每次降价百分率。

**解析：** 设每次降价 x%。100(1-x%)² = 81，(1-x%)² = 0.81，1-x% = 0.9，x% = 0.1 = 10%。每次降价 10%。

## 第4题

**题目：** 一个直角三角形的两条直角边之和为 14，斜边为 10，求两条直角边的长。

**解析：** 设一直角边为 x，则另一直角边为 14-x。x²+(14-x)²=10²，x²+196-28x+x²=100，2x²-28x+96=0，x²-14x+48=0。(x-6)(x-8)=0，x=6或8。直角边为6和8。

## 第5题

**题目：** 某班开联欢会，每两人之间握手一次，共握手 45 次。求全班有多少人。

**解析：** 设全班 n 人。C(n,2) = 45，n(n-1)/2 = 45，n²-n-90=0，(n-10)(n+9)=0，n=10。


## 第6题

**题目：** 某商品原价200元，两次降价后为128元，求平均每次降价率。

**解析：** 设降价率为x。200(1-x)^2=128，(1-x)^2=0.64，1-x=0.8，x=0.2。降价率20%。

## 第7题

**题目：** 一个两位数，个位比十位大3，两数字之积等于这个两位数的1/2，求这个两位数。

**解析：** 设十位x，个位x+3。x(x+3)=(10x+x+3)/2，x^2+3x=(11x+3)/2，2x^2+6x=11x+3，2x^2-5x-3=0。x=3或x=-0.5（舍）。两位数为36。

## 第8题

**题目：** 参加一次聚会的每两人都握了一次手，共握手28次，求参加人数。

**解析：** 设n人。C(n,2)=28，n(n-1)/2=28，n^2-n-56=0，(n-8)(n+7)=0，n=8。8人。
