# 21.3 实际问题与一元二次方程 - 思维训练

## 第1题
**题目：** 某工厂两年内产值从100万增长到121万，求平均年增长率。

**解析：** 设平均年增长率为x。100(1+x)^2=121，(1+x)^2=1.21，1+x=+-1.1，x1=0.1=10%，x2=-2.1（舍去）。平均年增长率为10%。

## 第2题
**题目：** 两个连续正整数的积为56，求这两个数。

**解析：** 设较小的数为x，则较大的数为x+1。x(x+1)=56，x^2+x-56=0，(x+8)(x-7)=0，x1=7，x2=-8（舍去）。这两个数为7和8。
