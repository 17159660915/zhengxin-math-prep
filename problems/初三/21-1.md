## 第1题

**题目：** 已知关于 x 的方程 x² - (k+2)x + 2k = 0。求证：无论 k 取何值，方程总有实数根。

**解析：** Δ = (k+2)² - 4×1×2k = k²+4k+4-8k = k²-4k+4 = (k-2)² ≥ 0
Δ ≥ 0 恒成立，所以方程总有实数根。

答案：证明成立

## 第2题

**题目：** 已知关于 x 的方程 x² + 2(m-1)x + m² - 3 = 0 有两个不相等的实数根，求 m 的取值范围。

**解析：** Δ = 4(m-1)² - 4(m²-3) > 0
4(m²-2m+1) - 4m² + 12 > 0
4m² - 8m + 4 - 4m² + 12 > 0
-8m + 16 > 0, m < 2

答案：m < 2

## 第3题

**题目：** 已知 x₁, x₂ 是方程 x² - 3x - 2 = 0 的两个根，求 x₁² + x₂² 的值。

**解析：** 韦达定理：x₁+x₂=3, x₁x₂=-2
x₁²+x₂² = (x₁+x₂)² - 2x₁x₂ = 9 - 2(-2) = 9+4 = 13

答案：13

## 第4题

**题目：** 已知方程 x² + 2x - 3 = 0 的两个根为 x₁, x₂，求以 1/x₁, 1/x₂ 为根的一元二次方程。

**解析：** x₁+x₂=-2, x₁x₂=-3
1/x₁+1/x₂ = (x₁+x₂)/(x₁x₂) = -2/(-3) = 2/3
(1/x₁)(1/x₂) = 1/(x₁x₂) = -1/3
所求方程：x² - (2/3)x - 1/3 = 0
即 3x² - 2x - 1 = 0

答案：3x² - 2x - 1 = 0

## 第5题

**题目：** 已知 m、n 是方程 x² - x - 1 = 0 的两个根，且 m < n，求 m²⁰²⁶ + n²⁰²⁶ 的值。

**解析：** m、n 是 x²-x-1=0 的根，m=(1-√5)/2, n=(1+√5)/2
m²=m+1, n²=n+1
m²⁰²⁶ + n²⁰²⁶ 是斐波那契数列中与黄金分割相关的数。
实际上，由递推关系 aₖ₊₂ = aₖ₊₁ + aₖ, a₀=2, a₁=1
可得 m²⁰²⁶+n²⁰²⁶ = F₂₀₂₇（斐波那契数）

答案：F₂₀₂₇（斐波那契数）
