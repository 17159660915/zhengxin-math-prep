# 24.3 正多边形和圆 - 思维训练

## 第1题
**题目：** 正六边形的中心角是多少度？

**解析：** 中心角=360度/6=60度。

## 第2题
**题目：** **题目：** 正十边形的每个内角是多少度？每个外角是多少度？

**解析：** 内角和 = (10-2)x180 = 1440，每个内角 = 1440/10 = 144。外角 = 180 - 144 = 36。
## 第3题

**题目：** 正六边形的边长为 2，求它的外接圆半径和内切圆半径。

**解析：** 正六边形外接圆半径 = 边长 = 2。内切圆半径 = 正六边形中心到边的距离 = √3。

## 第4题

**题目：** 正 n 边形的每个外角为 30°，求 n 的值。

**解析：** 正 n 边形外角和为 360°，每个外角 360°/n。360°/n = 30°，n = 12。

## 第5题

**题目：** 正三角形的边长为 a，求它的外接圆半径 R 和内切圆半径 r。

**解析：** R = a/√3，r = a/(2√3)。



## 第6题

**题目：** 正六边形的中心角是多少度？每个内角是多少度？

**解析：** 中心角 = 360/6 = 60。内角和 = (6-2)x180 = 720，每个内角 = 720/6 = 120。

## 第7题

**题目：** 正五边形的每个内角是多少度？每个外角是多少度？

**解析：** 内角和 = (5-2)x180 = 540，每个内角 = 540/5 = 108。外角 = 180 - 108 = 72。

## 第7题

**题目：** 正五边形的每个内角是多少度？

**解析：** 内角和=(5-2)*180=540度。每个内角=540/5=108度。
