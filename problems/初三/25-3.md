# 25.3 用频率估计概率 - 思维训练

## 第1题
**题目：** 某射手射击100次，命中89次，频率=0.89。若射击1000次，频率如何变化？

**解析：** 频率会在0.89附近波动，但波动幅度会随着试验次数增加而减小。

## 第2题
**题目：** 某工厂生产1000个产品中抽检100个，有3个次品，估计次品率。

**解析：** 次品频率=3/100=0.03，估计次品率约为3%。


## 第3题

**题目：** 某实验重复 1000 次，事件 A 发生 352 次，用频率估计 P(A) 的值。

**解析：** P(A) ≈ 352/1000 = 0.352。

## 第4题

**题目：** 抛一枚硬币 100 次，正面朝上 48 次。抛第 101 次时，正面朝上的概率是多少？

**解析：** 每次抛硬币是独立事件，概率不变。P(正面)=1/2。

## 第5题

**题目：** 种子发芽实验：发芽 952 颗，未发芽 48 颗。求种子发芽概率的估计值。

**解析：** P(发芽) ≈ 952/(952+48) = 952/1000 = 0.952。
