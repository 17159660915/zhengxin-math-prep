# 21.2 解一元二次方程 - 思维训练

## 第1题
**题目：** 解方程x^2-3x-4=0（公式法）。

**解析：** a=1，b=-3，c=-4。判别式=(-3)^2-4*1*(-4)=9+16=25。x=[3+-5]/2，x1=4，x2=-1。

## 第2题
**题目：** 解方程x^2+4x-5=0（配方法）。

**解析：** x^2+4x=5，x^2+4x+4=9，(x+2)^2=9，x+2=+-3，x1=1，x2=-5。


## 第3题

**题目：** 解方程：(x-1)(x-2)(x-3)(x-4) = 0。

**解析：** 四个因式相乘为0，每个因式可能为0。x-1=0或x-2=0或x-3=0或x-4=0。x=1,2,3,4。

## 第4题

**题目：** 已知关于 x 的方程 x² - 2mx + m² - 4 = 0 有两个不相等的实数根，求 m 的取值范围。

**解析：** Δ = (-2m)² - 4(m²-4) = 4m² - 4m² + 16 = 16 > 0，对任意 m 都有两个不相等的实数根。

## 第5题

**题目：** 已知 x₁、x₂ 是方程 x² - 5x + 6 = 0 的两根，求 x₁² + x₂² 的值。

**解析：** 韦达定理：x₁+x₂=5，x₁x₂=6。x₁²+x₂² = (x₁+x₂)² - 2x₁x₂ = 25-12 = 13。
