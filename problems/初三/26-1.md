## 第1题

**题目：**

![反比例函数](problems-diagrams/09-inverse-proportion.png)
 已知反比例函数 y = k/x 的图象经过点 (2, 3)。若点 (a, b) 也在该图象上，且 a + b = 5，求 a 的值。

**解析：** k = 2×3 = 6, y = 6/x
b = 6/a, a + 6/a = 5
a² + 6 = 5a, a²-5a+6=0, (a-2)(a-3)=0
a=2 或 a=3

答案：a=2 或 a=3

## 第2题

**题目：** 已知反比例函数 y = (3m-1)/x 的图象在第一、三象限，求 m 的取值范围。

![反比例函数](problems-diagrams/p3-26-1-q2.png)

**解析：** 一、三象限 → k>0 → 3m-1 > 0 → m > 1/3

答案：m > 1/3

## 第3题

**题目：** 已知点 A(x₁, y₁)、B(x₂, y₂) 在反比例函数 y = 6/x 的图象上，且 x₁ < x₂ < 0，比较 y₁ 和 y₂ 的大小。

![反比例函数](problems-diagrams/p3-26-1-q2.png)

**解析：** k=6>0，在每个象限内 y 随 x 增大而减小
x₁ < x₂ < 0（同在三象限）
∴ y₁ > y₂

答案：y₁ > y₂

## 第4题

**题目：** 已知反比例函数 y = k/x 与一次函数 y = 2x + 1 的图象交于点 A(1, 3)，求 k 的值及另一个交点的坐标。

**解析：** 代入 A：3 = k/1, k=3
联立：3/x = 2x+1 → 3 = 2x²+x → 2x²+x-3=0 → (2x+3)(x-1)=0
x=1 或 x=-1.5
x=-1.5时 y = -2
另一个交点：(-1.5, -2)

答案：k=3, 另一个交点(-1.5, -2)

## 第5题

**题目：** 已知反比例函数 y = 2/x 的图象上两点 P(x₁, y₁)、Q(x₂, y₂)，且 y₁ = y₂ + 3，求 x₁ - x₂ 的值。

**解析：** y₁ = 2/x₁, y₂ = 2/x₂
2/x₁ = 2/x₂ + 3, 两边乘 x₁x₂：2x₂ = 2x₁ + 3x₁x₂
2x₂-2x₁ = 3x₁x₂, 2(x₂-x₁) = 3x₁x₂
x₁-x₂ = -3x₁x₂/2

答案：x₁ - x₂ = -3x₁x₂/2（无法确定具体值）
