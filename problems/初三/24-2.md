# 24.2 点和圆、直线和圆的位置关系 - 思维训练

## 第1题
**题目：** 圆O半径为5，点P到圆心距离为3，点P在圆的什么位置？

**解析：** d=3<r=5，点P在圆内。

## 第2题
**题目：** 圆O半径为4，圆心到直线l的距离为3，直线与圆的位置关系？

**解析：** d=3<r=4，直线与圆相交，有2个交点。


## 第3题

**题目：** 圆的半径为 5，点 P 到圆心的距离为 3，点 P 在圆内还是圆外？

**解析：** d=3 < r=5，点 P 在圆内。

## 第4题

**题目：** 圆的半径为 5，圆心到直线 l 的距离为 4，直线 l 与圆有几个交点？

**解析：** d=4 < r=5，直线与圆相交，有2个交点。

## 第5题

**题目：** 从圆外一点 P 引圆的两条切线 PA、PB，切点分别为 A、B。若 PA = 6，求 PB 的长。

**解析：** 从圆外一点引圆的两条切线长相等，PB = PA = 6。


## 第6题

**题目：** 圆O半径5，点P到圆心距离3，点P在圆的什么位置？

**解析：** d=3<r=5，点P在圆内。
