# 22.2 二次函数与一元二次方程 - 思维训练

## 第1题
**题目：** 二次函数y=x^2-2x-3与x轴有几个交点？求交点坐标。


**解析：** 判别式=(-2)^2-4*1*(-3)=4+12=16>0，有2个交点。x^2-2x-3=0，(x-3)(x+1)=0，x1=3，x2=-1。交点(3,0)和(-1,0)。

## 第2题
**题目：** 利用二次函数解不等式x^2-x-2>0。


**解析：** y=x^2-x-2，与x轴交于(-1,0)和(2,0)，开口向上。图象在x轴上方的部分：x<-1或x>2。


## 第3题

**题目：** 二次函数 y = x² - 4x + 3 与 x 轴有几个交点？求交点坐标。

**解析：** Δ = 16-12=4 > 0，有2个交点。x²-4x+3=0，(x-1)(x-3)=0，x=1或3。交点(1,0)和(3,0)。

## 第4题

**题目：** 二次函数 y = x² - 2x + m 与 x 轴只有一个交点，求 m 的值。

**解析：** Δ = 4-4m=0，m=1。

## 第5题

**题目：** 利用二次函数 y = x² - x - 2 的图象，解不等式 x² - x - 2 < 0。

**解析：** 与 x 轴交于 (-1,0) 和 (2,0)，开口向上。图象在 x 轴下方的部分：-1 < x < 2。
