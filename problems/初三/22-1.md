## 第1题

**题目：**

![二次函数](problems-diagrams/08-quadratic-functions.png)
 已知二次函数 y = x² - 2mx + m² - 1 的图象顶点在 x 轴上，求 m 的值。

**解析：** 顶点在 x 轴上 → Δ = 0
Δ = (-2m)² - 4(m²-1) = 4m² - 4m² + 4 = 4 ≠ 0
函数与 x 轴始终有 2 个交点，顶点不可能在 x 轴上。

等等，顶点在 x 轴上意味着顶点纵坐标 = 0
顶点纵坐标 = (4ac-b²)/(4a) = (4(m²-1)-4m²)/4 = (4m²-4-4m²)/4 = -1
顶点纵坐标恒为 -1，不可能在 x 轴上。

答案：无解，顶点纵坐标恒为 -1

## 第2题

**题目：** 已知抛物线 y = x² + bx + c 经过点 A(1, 0) 和 B(-3, 0)，求该抛物线的顶点坐标。

![二次函数](problems-diagrams/p3-22-1-q2.png)

**解析：** A、B 是抛物线与 x 轴的交点。
抛物线对称轴为 x = (1+(-3))/2 = -1
代入 A：1+b+c=0
代入 B：9-3b+c=0
相减：-8+4b=0, b=2, c=-3
顶点 x=-1, y=(-1)²+2(-1)-3 = 1-2-3 = -4
顶点坐标：(-1, -4)

答案：(-1, -4)

## 第3题

**题目：** 已知二次函数 y = x² + (m+1)x + m 的图象与 x 轴有两个交点，且这两个交点的距离为 2，求 m 的值。

![二次函数](problems-diagrams/p3-22-1-q2.png)

**解析：** 设两根为 x₁, x₂，则 |x₁-x₂| = 2
x₁+x₂ = -(m+1), x₁x₂ = m
(x₁-x₂)² = (x₁+x₂)² - 4x₁x₂
4 = (m+1)² - 4m = m²+2m+1-4m = m²-2m+1 = (m-1)²
m-1=±2, m=3 或 m=-1

答案：m=3 或 m=-1

## 第4题

**题目：** 已知二次函数 y = ax² + bx + c 的图象经过点 (0, 2)，当 x=1 时 y 有最大值 4，求该二次函数解析式。

**解析：** 过 (0,2) → c=2
顶点 (1,4) → 对称轴 x=-b/(2a)=1 → b=-2a
代入顶点：4 = a+b+2 = a-2a+2 = -a+2, a=-2, b=4
y = -2x² + 4x + 2

答案：y = -2x² + 4x + 2

## 第5题

**题目：** 已知抛物线 y = x² - 2x - 3 与直线 y = x + 1 相交于 A、B 两点，求线段 AB 的长。

**解析：** 联立：x²-2x-3 = x+1 → x²-3x-4=0 → (x-4)(x+1)=0
x₁=4, x₂=-1
A(4,5), B(-1,0)
AB = √((4+1)²+(5-0)²) = √(25+25) = √50 = 5√2

答案：5√2
