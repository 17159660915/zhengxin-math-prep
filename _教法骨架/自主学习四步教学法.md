# 自主学习四步教学法（落地版）

> 来源：2026-07-25 家长接待录音转写
> 核心理念：不是老师讲学生听，是老师教方法，学生自己学。

## 核心流程

```
预习 → 自测（第一本教材） → 讲题（上台当老师） → 巩固（第二本教材）
```

## 一、预习（建立知识框架）

**学生任务：**
1. 读课本内容（该读的要读出来）
2. 在 A4/A3 纸上**画单元知识框架图**（思维导图/导向图）
   - 每个单元画一张
   - 按自己的理解画出知识点结构
   - 标出重点
3. 把自己不懂的地方用红线标记

**关键原则：**
- **第一次让学生按自己的思路画**，不管画得好不好
- 目的是让学生先独立思考，而不是等老师讲
- 画法不限，学生能画出来就代表他在思考

**老师的作用（此时不教）：**
- 只监督学生是否在做
- 不做讲解、不代替思考

## 二、自测（暴露真实问题）

**操作：**
- **买两本教材**，这是整套方法的关键
- 第一本教材：学生自己做完，老师不提前讲解，学生直接做题

**为什么买两本：**
- 第一本用于**暴露问题**，不抄错题（省时间）
- 老师评讲时，勾出错题
- 第二本用于**重做错题**、订正

**核心态度：**
- **错没关系，不怕错**
- 第一本全对反而不正常，错题才是教学起点
- 第一本书的错题极其真实地暴露出学生的薄弱点
- "如果是老师讲过的题型，弱点暴露不出来"

> "他首先是能够做，只要他能做，错没关系，我有办法。"

## 三、讲题（费曼学习法落地）

**这是整套方法的核心环节。**

### 学生讲题流程

1. **学生当老师，老师当学生**
   - 学生上台，对着黑板讲
   - 老师坐在下面听
2. **讲题要求**
   - 讲清楚题目怎么做
   - 配合肢体语言
   - 写黑板、排布知识点位置
   - 讲完整、讲透彻
3. **老师此时不打断**
   - 从前到后，学生讲完再点评
   - 不中途指出错误

### 第一次讲题的标准

| 次数 | 做法 | 预期效果 |
|------|------|---------|
| 第1次 | 学生自己讲，老师只听不教 | 可能只达到30分水平 |
| 第2次 | 老师点评+示范后，学生再讲 | 提升到60-70分 |
| 第3-5次 | 反复打磨，纠正细节 | 达到90-95分 |
| 达成 | 肢体语言、黑板布局、讲解逻辑都到位 | 完成一个单元 |

> "第一个单元可能要讲一遍两遍三遍四遍五遍，讲几遍我不知道，反正要达到这个标准。"

### 老师点评技巧

**① 先肯定，后建议**
- "你是怎么能把内容讲得这么好的？" —— 先来一个大大的肯定
- 再说："内容讲得好，我们如果把黑板上的知识点先写在这里、再写在这里……整个都能呈现出来，是不是整个版面也很好呢？"
- 让孩子自己去想改进空间

**② "装傻"引导法（核心技巧）**
- 学生讲错时，**不直接指出来**
- 装作自己也没听明白："诶，这个是怎么讲的呀？我再听听……"
- 引导他自己发现错误："那个圆打开以后打平，这一面的长是整个周长还是一半呢？"
- 当他发现正确结论时，说："哇，你都知道？老师刚才都没听到！"

**③ 每次只讲一个改进点**
- 不要一次性指出所有问题
- 这次重点关注肢体语言，下次关注板书布局
- 一次只推一个点，孩子容易接受

**④ "眼里只有你"的专注**
- 老师全程认真看着学生
- 让他感觉"整个世界、整个眼里只有你"
- 这种专注本身就是最大的鼓励

### 讲题评分标准（满分100分）

- 内容逻辑是否清晰
- 讲解是否有条理
- 肢体语言是否自然
- 板书布局是否合理
- 声音是否洪亮、自信

### 讲题训练的意义

- 掌握知识点达到90%-95%（远超普通做题）
- 培养表达能力、自信心
- **"看到眼睛有光，上台很自信，对着镜头放松"** 比考满分更重要
- 学到的是"终身受用的技能"

## 四、巩固（第二本教材）

1. 讲完并掌握一个单元后，做第二本教材对应单元
2. 第二本只做老师勾出的重点题/易错题
3. 目标：正确率 90%+
4. 如果正确率不高 → 再买一份重做
5. 如果正确率高 → 跳过，继续下一个单元

**专项训练：** 全部单元完成后，做教材后面的专项训练，针对每个单元薄弱点进行强化。

## 五、完整周期的教学节奏

| 时间 | 内容 | 目标 |
|------|------|------|
| 第1周 | 预习+自己画框架+第一本自测 | 暴露问题 |
| 第2周 | 讲题训练+第二本错题订正 | 掌握90% |
| 第3周 | 综合题+易错题+期末模拟卷 | 巩固提升 |
| 第4周 | 北京/杭州等地区模拟卷 | 降维测试 |

## 核心金句

> "我不是以讲题为主，我是以他养成这种习惯、掌握这种技能为主的。"

> "考80分表示他自学能掌握八成，哪怕只考80分，比传统90分的含金量高得多。"

> "只要你能讲出来，能上台、敢表达、眼里有光，这个比考满分都重要。"
