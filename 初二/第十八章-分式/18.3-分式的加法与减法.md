# 18.3 分式的加法与减法

## 📖 知识点

### 一、同分母分式相加减

**分母不变**，分子相加减。

> a/b + c/b = (a + c)/b
> a/b - c/b = (a - c)/b

> 例：2/x + 3/x = 5/x；3/(x+1) - 1/(x+1) = 2/(x+1)

### 二、异分母分式相加减

先**通分**，化为同分母的分式，再加减。

> a/b + c/d = (ad + bc)/(bd)

> 例：1/x + 1/y = (y + x)/(xy)

### 三、分式加减的一般步骤

1. 找最简公分母
2. 通分
3. 分子相加减
4. 约分（化为最简分式）

---

## ⭐ 重点

1. 同分母分母不变，分子相加减——**分子要加括号**（特别是减法时）。
2. 异分母→通分→同分母→加减→约分。
3. 最简公分母：各分母系数的最小公倍数 × 各字母的最高次幂。

---

## ⚠️ 易错点

> ❌ **错误**：1/(x-1) - 1/(x+1) = 0（直接把分子相减）
> ✅ **正确**：先通分再计算
> 1/(x-1) - 1/(x+1) = (x+1)/[(x-1)(x+1)] - (x-1)/[(x-1)(x+1)] = (x+1-x+1)/[(x-1)(x+1)] = 2/(x²-1)

> ❌ **错误**：a/(x+y) + b/(x+y) = (a+b)/(x+y) 是对的，但 (a+b) 不加括号
> ✅ **正确**：结果可以写作 (a+b)/(x+y)，但分子是多项式时要加括号

> ❌ **错误**：通分时只把分母乘了，分子没乘
> ✅ **正确**：通分是分式变形，分子分母要同乘同一个整式

---

## 📝 典型例题

**例 1**：计算 3/(x+1) - 2/(x+1)

> 解：同分母，分母不变，分子相减
> 原式 = (3 - 2)/(x + 1) = 1/(x + 1)

**例 2**：计算 1/(x-1) + 1/(x+1)

> 解：通分，最简公分母为 (x-1)(x+1)
> 原式 = (x+1)/[(x-1)(x+1)] + (x-1)/[(x-1)(x+1)]
> = (x+1+x-1)/[(x-1)(x+1)] = 2x/(x²-1)

**例 3**：计算 1/(x²-1) - 1/(x²+2x+1)

> 解：x²-1 = (x+1)(x-1)，x²+2x+1 = (x+1)²
> 最简公分母 = (x+1)²(x-1)
> 原式 = (x+1)/[(x+1)²(x-1)] - (x-1)/[(x+1)²(x-1)]
> = (x+1-x+1)/[(x+1)²(x-1)] = 2/[(x+1)²(x-1)]
