# 18.2 分式的乘法与除法

## 📖 知识点

### 一、分式的乘法

分式乘分式，用**分子的积作为积的分子**，**分母的积作为积的分母**。

> a/b · c/d = (a · c) / (b · d)

> 例：(x/y) · (y²/x²) = x · y² / (y · x²) = y/x

### 二、分式的除法

分式除以分式，把除式的分子、分母**颠倒位置**后，与被除式相乘。

> a/b ÷ c/d = a/b · d/c = (a · d) / (b · c)（c ≠ 0，d ≠ 0）

> 例：(x/y) ÷ (x²/y²) = (x/y) · (y²/x²) = x · y² / (y · x²) = y/x

### 三、分式的乘方

分式乘方，把分子、分母分别乘方。

> (a/b)^n = a^n / b^n（n 为正整数）

> 例：(2x/y)² = 4x² / y²

---

## ⭐ 重点

1. 分式乘法：**分子乘分子，分母乘分母**，能约分的先约分。
2. 分式除法：**除以一个分式等于乘以它的倒数**。
3. 分式运算的结果要化为**最简分式**。

---

## ⚠️ 易错点

> ❌ **错误**：(x²/y) ÷ (x/y²) = (x²/y) · (y²/x) = x²y²/(xy) = xy（颠倒时只倒了分母，没倒分子）
> ✅ **正确**：(x²/y) ÷ (x/y²) = (x²/y) · (y²/x) = x²y²/(xy) = xy（实际上这个结果是对的，因为 y²/x = x/y² 的倒数。检查：x/y² 的倒数是 y²/x，正确）

> ❌ **错误**：分式乘法先约分再乘，容易约错
> ✅ **正确**：先分解因式再约分，最后乘。如 (x²-1)/(x+2) · (x+2)/(x-1) = (x+1)(x-1)/(x+2) · (x+2)/(x-1) = x+1

> ❌ **错误**：(a/b)² = a²/b
> ✅ **正确**：(a/b)² = a²/b²（分子分母分别乘方）

## 📝 典型例题

**例 1**：计算 (x² - y²)/(x²) · x/(x + y)

> 解：分子 = (x + y)(x - y)
> 原式 = (x + y)(x - y)/x² · x/(x + y) = (x - y)/x

**例 2**：计算 (x² - 4)/(x² - 1) ÷ (x + 2)/(x + 1)

> 解：原式 = (x² - 4)/(x² - 1) · (x + 1)/(x + 2)
> = (x + 2)(x - 2)/[(x + 1)(x - 1)] · (x + 1)/(x + 2)
> = (x - 2)/(x - 1)

**例 3**：计算 (2ab²/c)²

> 解：(2ab²/c)² = 4a²b⁴/c²
