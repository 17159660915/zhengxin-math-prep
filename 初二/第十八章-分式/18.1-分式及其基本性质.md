# 18.1 分式及其基本性质

## 📖 知识点

### 一、分式的概念

一般地，如果 A、B 表示两个整式，且 B 中含有**字母**，那么式子 A/B 叫做**分式**。

> 其中 A 叫做**分子**，B 叫做**分母**。

### 二、分式有意义的条件

分式 A/B 有意义的条件是：**分母 B ≠ 0**。

> 例：分式 1/(x-2) 中，x - 2 ≠ 0，即 x ≠ 2 时才有意义。

### 三、分式值为 0 的条件

分式 A/B = 0 的条件是：**分子 A = 0 且分母 B ≠ 0**。

> 例：当 x = 2 时，分式 (x-2)/(x+1) = 0（分子为 0，分母不为 0）

### 四、分式的基本性质

分式的分子与分母同乘（或除以）同一个**不等于 0 的整式**，分式的值不变。

> A/B = (A × C) / (B × C)（C ≠ 0）
> A/B = (A ÷ C) / (B ÷ C)（C ≠ 0）

### 五、约分

把一个分式的分子和分母的**公因式**约去，叫做**约分**。

> 约分后的分式，分子和分母没有公因式，叫做**最简分式**。

### 六、通分

把几个异分母的分式分别化成与原来分式相等的**同分母**分式，叫做**通分**。

> 通分的关键是确定**最简公分母**。

---

## ⭐ 重点

1. 分式与分数的区别：**分母中含有字母**才是分式。
2. 分式值为 0 必须同时满足两个条件——分子为 0，分母不为 0。
3. 分式的基本性质中，乘（或除以）的整式不能为 0。

---

## ⚠️ 易错点

> ❌ **错误**：分式 (x-2)/(x+1) 中，当 x = 2 时，分式值为 0，因为分子为 0
> ✅ **正确**：x = 2 时，分子为 0，分母 = 3 ≠ 0，所以分式值为 0。但必须同时检查分母不为 0

> ❌ **错误**：分式 1/(x-2) 中，x = 2 时分式值为 0
> ✅ **正确**：x = 2 时分母为 0，分式无意义，没有值

> ❌ **错误**：约分时把分子分母的项分别约掉
> ✅ **正确**：约分是约去分子分母的**公因式**，不是约去项。如 (x+y)/(x²+xy) = (x+y)/[x(x+y)] = 1/x

---

## 📝 典型例题

**例 1**：x 取何值时，分式 (x-1)/(x+2) 有意义？值为 0？

> 解：有意义：x + 2 ≠ 0 → x ≠ -2
> 值为 0：x - 1 = 0 且 x + 2 ≠ 0 → x = 1

**例 2**：约分：(x² - 4)/(x² + 2x)

> 解：分子 = (x + 2)(x - 2)，分母 = x(x + 2)
> 原式 = (x + 2)(x - 2) / [x(x + 2)] = (x - 2)/x

**例 3**：通分：1/(x-1) 和 1/(x+1)

> 解：最简公分母为 (x-1)(x+1)
> 1/(x-1) = (x+1)/[(x-1)(x+1)]
> 1/(x+1) = (x-1)/[(x-1)(x+1)]
