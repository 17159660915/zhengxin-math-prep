# 17.1 用提公因式法分解因式

## 📖 知识点

### 一、因式分解的概念

把一个**多项式**化成几个**整式的积**的形式，叫做**因式分解**（也叫分解因式）。

> 因式分解与整式乘法是**互逆变形**。
> 例：x² - 1 = (x + 1)(x - 1) 是因式分解（乘法是 (x+1)(x-1) = x² - 1）

### 二、公因式

多项式各项都含有的**相同因式**，叫做公因式。

> 找公因式的方法：
> 1. 系数取最大公约数
> 2. 字母取相同字母的最低次幂

### 三、提公因式法

如果多项式的各项有公因式，可以把这个公因式提到括号外面，将多项式写成因式乘积的形式。

> ma + mb + mc = m(a + b + c)

> 例：6x³y - 3x²y² + 9x²y = 3x²y(2x - y + 3)

---

## ⭐ 重点

1. 因式分解是**整式乘法的逆变形**——可以反过来验证是否正确。
2. 提公因式时，公因式要**提尽**（系数取最大公约数，字母取最低次幂）。
3. 公因式可以是单项式，也可以是**多项式**，如 (a+b) 可以作为公因式。

---

## ⚠️ 易错点

> ❌ **错误**：x² + 2x + 1 = x(x + 2) + 1（没有写成积的形式，不是因式分解）
> ✅ **正确**：x² + 2x + 1 = (x + 1)²（写成整式的积的形式）

> ❌ **错误**：6x²y - 3xy² = 3xy(2x - y)（公因式提取不完整）
> ✅ **正确**：6x²y - 3xy² = 3xy(2x - y)，系数取最大公约数 3，字母取最低次幂

> ❌ **错误**：提公因式后，括号内最后一项为 1 时漏写
> ✅ **正确**：2x + 1 = 1(2x + 1) 不能提公因式；但 2x² + x = x(2x + 1)

---

## 📝 典型例题

**例 1**：分解因式 8a³b² - 12a²b³ + 4a²b²

> 解：公因式为 4a²b²
> 原式 = 4a²b²(2a - 3b + 1)

**例 2**：分解因式 2(x + y)² - 4(x + y)

> 解：公因式为 2(x + y)
> 原式 = 2(x + y)[(x + y) - 2] = 2(x + y)(x + y - 2)

**例 3**：分解因式 -4x² + 6x - 2

> 解：首项系数为负，先提负号
> 原式 = -2(2x² - 3x + 1) = -2(2x - 1)(x - 1)
