# 14.2 三角形全等的判定



## 📖 知识点



### 一、五种判定方法



| 判定 | 条件 | 简写 |

|------|------|------|

| 边边边 | 三边分别相等 | SSS |

| 边角边 | 两边及其夹角分别相等 | SAS |

| 角边角 | 两角及其夹边分别相等 | ASA |

| 角角边 | 两角及其中一角的对边分别相等 | AAS |

| 斜边、直角边 | 斜边和一条直角边分别相等（直角三角形专用） | HL |



### 二、判定方法详解



**SSS（边边边）**：三边对应相等的两个三角形全等。

> AB = DE，BC = EF，AC = DF → △ABC ≌ △DEF



**SAS（边角边）**：两边和它们的夹角对应相等的两个三角形全等。

> AB = DE，∠B = ∠E，BC = EF → △ABC ≌ △DEF（角必须是两边之间的夹角）



**ASA（角边角）**：两角和它们的夹边对应相等的两个三角形全等。

> ∠B = ∠E，BC = EF，∠C = ∠F → △ABC ≌ △DEF



**AAS（角角边）**：两角和其中一角的对边对应相等的两个三角形全等。

> ∠B = ∠E，∠C = ∠F，AB = DE → △ABC ≌ △DEF



**HL（斜边、直角边）**：斜边和一条直角边对应相等的两个直角三角形全等。

> 在 Rt△ABC 和 Rt△DEF 中，∠B = ∠E = 90°，AC = DF，AB = DE → △ABC ≌ △DEF



### 三、判定方法对比
![全等三角形SSS](diagrams/17-congruent-triangles.png)



| 简写 | 已知条件 | 是否必须夹角/夹边 |

|------|---------|----------------|

| SSS | 三条边 | 不涉及角 |

| SAS | 两条边 + 一个角 | 角必须是**夹角** |

| ASA | 两个角 + 一条边 | 边必须是**夹边** |

| AAS | 两个角 + 一条边 | 边可以是非夹边 |

| HL | 斜边 + 直角边 | 仅直角三角形 |



---



## ⭐ 重点



1. **SAS 中的角必须是夹角**——两边和其中一边的对角对应相等不能判定全等。

2. **SSA 不能判定全等**——两边和其中一边的对角对应相等，不能判定全等，但 HL 是 SSA 的特例（直角三角形）。

3. 判定全等至少需要**三个条件**，且至少要有一条边。



---



## ⚠️ 易错点



> ❌ **错误**：AB = DE，AC = DF，∠B = ∠E → △ABC ≌ △DEF（SSA 不能判定）

> ✅ **正确**：这是 SSA，不能判定全等。需要 SAS（夹角）



> ❌ **错误**：SSA 一定不能判定全等

> ✅ **正确**：一般在非直角三角形中不能，但**直角三角形 HL 是 SSA 的特殊情况，可以判定**



> ❌ **错误**：只要三个条件就够

> ✅ **正确**：AAA（三个角相等）不能判定全等，只能判定相似

## 📝 典型例题



**例 1**：AB = DE，BC = EF，∠B = ∠E，△ABC 和 △DEF 全等吗？用的是哪种判定？



> 解：AB = DE，∠B = ∠E，BC = EF → 两边及其夹角对应相等

> △ABC ≌ △DEF（SAS）



**例 2**：∠A = ∠D，∠B = ∠E，AC = DF，△ABC 和 △DEF 全等吗？



> 解：∠A = ∠D，∠B = ∠E，AC = DF → 两角及其中一角的对边对应相等

> △ABC ≌ △DEF（AAS）



**例 3**：Rt△ABC 中，∠B = 90°，AB = 3，AC = 5；Rt△DEF 中，∠E = 90°，DE = 3，DF = 5。△ABC ≌ △DEF 吗？



> 解：斜边 AC = DF = 5，直角边 AB = DE = 3

> Rt△ABC ≌ Rt△DEF（HL）
