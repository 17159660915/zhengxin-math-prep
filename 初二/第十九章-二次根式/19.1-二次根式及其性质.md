# 19.1 二次根式及其性质

## 📖 知识点

### 一、二次根式的概念

一般地，形如 √a（a ≥ 0）的式子叫做**二次根式**。

> "√" 叫做二次根号，"a" 叫做被开方数。
> a ≥ 0（被开方数为非负数）是二次根式有意义的条件。

### 二、二次根式的性质

1. **双重非负性**：√a ≥ 0 且 a ≥ 0（a ≥ 0）
2. (√a)² = a（a ≥ 0）
3. √(a²) = |a|

> 性质 3 的详细说明：
> 当 a ≥ 0 时，√(a²) = a
> 当 a < 0 时，√(a²) = -a

### 三、最简二次根式

满足以下条件的二次根式叫做**最简二次根式**：
1. 被开方数不含分母
2. 被开方数中不含能开得尽方的因数或因式

> 例：√8 = 2√2（化简后）；√(1/2) = √2/2（化简后）

---

## ⭐ 重点

1. **双重非负性**：√a ≥ 0，a ≥ 0——这是二次根式的核心性质。
2. √(a²) = |a|，不是等于 a——要分 a 的正负讨论。
3. 化简二次根式：把被开方数中的完全平方因子开到根号外。

---

## ⚠️ 易错点

> ❌ **错误**：√(a²) = a（没有考虑 a 的正负）
> ✅ **正确**：√(a²) = |a|。a ≥ 0 时等于 a，a < 0 时等于 -a

> ❌ **错误**：√(-4) = -2（负数没有平方根）
> ✅ **正确**：√(-4) 无意义，因为被开方数 -4 < 0

> ❌ **错误**：√(a) + √(b) = √(a + b)（不能合并）
> ✅ **正确**：√(a) + √(b) 不能合并，不是同类二次根式

---

## 📝 典型例题

**例 1**：x 为何值时，√(x - 3) 有意义？

> 解：x - 3 ≥ 0 → x ≥ 3

**例 2**：化简 √(x² - 4x + 4)（x < 2）

> 解：√(x² - 4x + 4) = √((x - 2)²) = |x - 2|
> x < 2 → x - 2 < 0 → |x - 2| = -(x - 2) = 2 - x

**例 3**：化简 √(12)

> 解：√(12) = √(4 × 3) = 2√3
