# 19.3 二次根式的加法与减法

## 📖 知识点

### 一、同类二次根式

几个二次根式化成**最简二次根式**后，如果**被开方数相同**，这几个二次根式叫做**同类二次根式**。

> 例：√8 和 √18 化简后分别为 2√2 和 3√2，被开方数都是 2，是同类二次根式。

### 二、二次根式的加减

**法则**：先把每个二次根式化为**最简二次根式**，再合并**同类二次根式**。

> 合并同类二次根式：系数相加减，根号部分不变。

> 例：√8 + √18 = 2√2 + 3√2 = 5√2

### 三、加减混合运算步骤

1. 化简（化到最简二次根式）
2. 判断（找出同类二次根式）
3. 合并（合并同类二次根式，不是同类的不能合并）

---

## ⭐ 重点

1. 同类二次根式：**化简后**被开方数相同，与系数无关。
2. 合并同类二次根式：**系数相加减，根号不变**。
3. 不是同类二次根式不能合并（如 √2 + √3 不能合并）。

---

## ⚠️ 易错点

> ❌ **错误**：√2 + √3 = √5（根号不能直接相加）
> ✅ **正确**：√2 + √3 不是同类二次根式，不能合并

> ❌ **错误**：√8 + √2 = √8 + √2（没有化简，没发现是同类）
> ✅ **正确**：√8 + √2 = 2√2 + √2 = 3√2（先化简，再合并）

> ❌ **错误**：2√2 + 3√2 = 5√4（合并了根号）
> ✅ **正确**：2√2 + 3√2 = 5√2（系数相加，根号不变）

## 📝 典型例题

**例 1**：计算 √12 + √27 - √48

> 解：√12 = 2√3，√27 = 3√3，√48 = 4√3
> 原式 = 2√3 + 3√3 - 4√3 = √3

**例 2**：计算 √50 - √18 + √8

> 解：√50 = 5√2，√18 = 3√2，√8 = 2√2
> 原式 = 5√2 - 3√2 + 2√2 = 4√2

**例 3**：计算 (√8 + √3) - (√12 - √2)

> 解：= √8 + √3 - √12 + √2
> = 2√2 + √3 - 2√3 + √2
> = (2√2 + √2) + (√3 - 2√3) = 3√2 - √3
