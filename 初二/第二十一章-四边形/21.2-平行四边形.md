# 21.2 平行四边形



## 📖 知识点



### 一、平行四边形的定义



两组对边分别**平行**的四边形叫做**平行四边形**。



> 记作：ABCD，读作"平行四边形 ABCD"。



### 二、平行四边形的性质



| 性质 | 内容 |

|------|------|

| 边 | 对边**平行且相等** |

| 角 | 对角**相等**，邻角**互补** |

| 对角线 | 对角线**互相平分** |

| 对称性 | 中心对称图形，对称中心是对角线交点 |



### 三、平行四边形的判定



| 判定 | 条件 |

|------|------|

| 定义法 | 两组对边分别平行 |

| 边 | 两组对边分别相等 |

| 边 | 一组对边平行且相等 |

| 角 | 两组对角分别相等 |

| 对角线 | 对角线互相平分 |




---



## ⭐ 重点



1. 平行四边形的性质：**对边平行且相等、对角相等、邻角互补、对角线互相平分**。

2. 判定平行四边形有两种思路：从边（平行或相等）、从角、从对角线。

3. 一组对边平行且相等是最常用的判定方法。



---



## ⚠️ 易错点



> ❌ **错误**：一组对边平行，另一组对边相等的四边形是平行四边形

> ✅ **正确**：一组对边平行且**相等**才是平行四边形。一组对边平行、另一组对边相等可能是等腰梯形



> ❌ **错误**：对角线相等的四边形是平行四边形

> ✅ **正确**：对角线**互相平分**才是平行四边形，对角线相等不能判定



> ❌ **错误**：平行四边形是轴对称图形

> ✅ **正确**：平行四边形是**中心对称**图形，不是轴对称图形（一般情况）



---



## 📝 典型例题



**例 1**：ABCD 中，AB = 8，BC = 5，求周长。



> 解：平行四边形对边相等

> 周长 = 2(AB + BC) = 2(8 + 5) = 26



**例 2**：ABCD 中，对角线 AC、BD 交于点 O，AO = 5，求 OC。



> 解：平行四边形对角线互相平分

> OC = AO = 5



**例 3**：四边形 ABCD 中，AB = CD，AB ∥ CD，求证 ABCD 是平行四边形。



> 证明：一组对边平行且相等 → 平行四边形
