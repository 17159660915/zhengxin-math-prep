# 16.2 整式的乘法

## 📖 知识点

### 一、单项式与单项式相乘

**法则**：系数相乘，相同字母分别相乘，只在一个单项式中出现的字母连同指数一起作为积的因式。

> 例：2x²y · 3xy³ = (2 × 3) · (x² · x) · (y · y³) = 6x³y⁴

### 二、单项式与多项式相乘

**法则**：用单项式去乘多项式的**每一项**，再把所得的积相加。

> 例：2x(3x² - 4x + 1) = 2x · 3x² - 2x · 4x + 2x · 1 = 6x³ - 8x² + 2x

### 三、多项式与多项式相乘

**法则**：先用一个多项式的**每一项**乘另一个多项式的**每一项**，再把所得的积相加。

> 例：(x + 2)(x + 3) = x · x + x · 3 + 2 · x + 2 · 3 = x² + 3x + 2x + 6 = x² + 5x + 6

### 四、一般步骤

1. 系数相乘
2. 相同字母相乘（指数相加）
3. 不同字母照写
4. 合并同类项

---

## ⭐ 重点

1. 单项式乘多项式——**逐项相乘**，不能漏项。
2. 多项式乘多项式——**逐项相乘**，有多少项就乘多少次，最后合并同类项。
3. 注意符号：负号乘进去时要变号。

---

## ⚠️ 易错点

> ❌ **错误**：2x(3x² - 4x + 1) = 6x³ - 8x² + 2x²（最后一项符号错了）
> ✅ **正确**：2x(3x² - 4x + 1) = 6x³ - 8x² + 2x（注意 -4x 乘 2x 得 -8x²，不是 -4x）

> ❌ **错误**：(x + 2)(x + 3) = x² + 6（漏了中间项）
> ✅ **正确**：(x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6

> ❌ **错误**：-2x(x - 3) = -2x² + 6x 不需要注意符号（已经正确，但写"不需要"是错误的）
> ✅ **正确**：-2x(x - 3) = -2x² + 6x，注意 -2x 乘 -3 得 +6x

## 📝 典型例题

**例 1**：计算 (-2ab) · (3a²b - 2ab² + 1)

> 解：(-2ab) · 3a²b = -6a³b²
> (-2ab) · (-2ab²) = 4a²b³
> (-2ab) · 1 = -2ab
> 结果 = -6a³b² + 4a²b³ - 2ab

**例 2**：计算 (x - 3)(2x + 1)

> 解：(x - 3)(2x + 1) = x · 2x + x · 1 - 3 · 2x - 3 · 1
> = 2x² + x - 6x - 3 = 2x² - 5x - 3

**例 3**：计算 (2x + 1)(x² - 3x + 2)

> 解：= 2x · x² + 2x · (-3x) + 2x · 2 + 1 · x² + 1 · (-3x) + 1 · 2
> = 2x³ - 6x² + 4x + x² - 3x + 2
> = 2x³ - 5x² + x + 2
