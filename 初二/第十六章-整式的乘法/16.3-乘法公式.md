# 16.3 乘法公式

## 📖 知识点

### 一、平方差公式

两个数的**和**与这两个数的**差**的积，等于这两个数的**平方差**。

> (a + b)(a - b) = a² - b²

> 例：(x + 2)(x - 2) = x² - 4；(3x + y)(3x - y) = 9x² - y²

### 二、完全平方公式

两个数的**和（或差）的平方**，等于它们的平方和加上（或减去）它们的积的 **2 倍**。

> (a + b)² = a² + 2ab + b²
> (a - b)² = a² - 2ab + b²

> 例：(x + 3)² = x² + 6x + 9；(2x - 1)² = 4x² - 4x + 1

### 三、公式的对比

| 公式 | 形式 | 结果 |
|------|------|------|
| 平方差 | (a+b)(a-b) | a² - b²（两项） |
| 完全平方和 | (a+b)² | a² + 2ab + b²（三项） |
| 完全平方差 | (a-b)² | a² - 2ab + b²（三项） |

---

## ⭐ 重点

1. 平方差公式的关键：**一项相同，一项相反**，结果等于相同项的平方减相反项的平方。
2. 完全平方公式中间项是 **2ab**，口诀：**首平方，尾平方，积的 2 倍放中央**。
3. (-a - b)² = (a + b)² = a² + 2ab + b²——两个负号抵消。

---

## ⚠️ 易错点

> ❌ **错误**：(a + b)² = a² + b²（漏了 2ab 项）
> ✅ **正确**：(a + b)² = a² + 2ab + b²

> ❌ **错误**：(a - b)² = a² - b²（漏了 2ab 且符号错误）
> ✅ **正确**：(a - b)² = a² - 2ab + b²

> ❌ **错误**：(x - 3)(x + 3) = x² - 3（平方差公式结果也错了）
> ✅ **正确**：(x - 3)(x + 3) = x² - 9 = x² - 3²

> ❌ **错误**：(-x - y)² = x² + 2xy - y²（符号混淆）
> ✅ **正确**：(-x - y)² = [-(x + y)]² = (x + y)² = x² + 2xy + y²

---

## 📝 典型例题

**例 1**：计算 (2x + 1)(2x - 1)

> 解：平方差公式，a = 2x，b = 1
> (2x + 1)(2x - 1) = (2x)² - 1² = 4x² - 1

**例 2**：计算 (3x - 2y)²

> 解：完全平方公式
> (3x - 2y)² = (3x)² - 2 · (3x) · (2y) + (2y)² = 9x² - 12xy + 4y²

**例 3**：计算 (x + 2)² - (x - 2)²

> 解：分别展开再相减
> (x + 2)² = x² + 4x + 4
> (x - 2)² = x² - 4x + 4
> 相减：(x² + 4x + 4) - (x² - 4x + 4) = 8x
