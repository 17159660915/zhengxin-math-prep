# 23.1 一次函数的概念



## 📖 知识点



### 一、一次函数



一般地，形如 y = kx + b（k、b 是常数，k ≠ 0）的函数，叫做**一次函数**。



> 例：y = 2x + 1、y = -x + 3、y = 5x 都是一次函数。



### 二、正比例函数



当 b = 0 时，y = kx（k 是常数，k ≠ 0）叫做**正比例函数**。



> 正比例函数是一次函数的**特殊形式**。

> 例：y = 2x、y = -3x 是正比例函数。



### 三、一次函数与正比例函数的关系



一次函数 y = kx + b 中：

- 当 b = 0 时，是正比例函数（经过原点）

- 当 b ≠ 0 时，是普通一次函数（不经过原点）



> 正比例函数是特殊的一次函数。



---



## ⭐ 重点



1. 一次函数 y = kx + b 中，**k ≠ 0** 是必要条件——k = 0 时是常数函数。

2. 正比例函数是一次函数的特例（b = 0）。

3. 判断一个函数是否为一次函数，要化为最简形式后看是否满足 y = kx + b 的形式。



---



## ⚠️ 易错点



> ❌ **错误**：y = 2 是一次函数

> ✅ **正确**：y = 2 中 k = 0，不是一次函数，是常数函数



> ❌ **错误**：y = 1/x 是一次函数

> ✅ **正确**：y = 1/x 不是整式，不是一次函数，是反比例函数



> ❌ **错误**：y = kx + b 中 b 不能为 0

> ✅ **正确**：b 可以为 0（此时是正比例函数），但 k 不能为 0



---



## 📝 典型例题



**例 1**：下列函数中，哪些是一次函数？哪些是正比例函数？

① y = 3x + 2　② y = -x　③ y = 5　④ y = 2/x



> 解：① 一次函数（b = 2）　② 正比例函数（b = 0）　③ 常数函数（k = 0）　④ 不是整式，不是一次函数




**例 3**：已知 y = (m - 3)x^(m²-8) + 2 是一次函数，求 m 的值。

> 解：一次函数要求 x 次数为 1，且系数不为 0
> m² - 8 = 1，m² = 9，m = 3 或 m = -3
> 当 m = 3 时，系数 m - 3 = 0，舍去
> m = -3

**例 4**：下列函数中，哪些是正比例函数？哪些是一次函数但不是正比例函数？
① y = -3x  ② y = 2x + 1  ③ y = x²  ④ y = 5/x  ⑤ y = 0

> 解：① 正比例函数（b = 0）② 一次函数（b ≠ 0）
> ③ 二次函数 ④ 反比例函数 ⑤ 常数函数（k = 0）

**例 2**：当 m 为何值时，y = (m - 2)x + 3 是一次函数？



> 解：一次函数要求 k ≠ 0 → m - 2 ≠ 0 → m ≠ 2
