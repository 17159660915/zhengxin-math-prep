# 23.4 实际问题与一次函数



## 📖 知识点



### 一、建立一次函数模型



解决实际问题的步骤：

1. 分析问题，确定**变量**和**常量**

2. 找出变量之间的**等量关系**

3. 设出变量，写出**函数解析式**

4. 确定自变量的**取值范围**

5. 利用函数性质解决问题



### 二、常见类型



| 类型 | 等量关系 |

|------|---------|

| 行程问题 | 路程 = 速度 × 时间 |

| 费用问题 | 总费用 = 基础费 + 单位费用 × 数量 |

| 方案选择 | 比较两个方案的费用函数 |



### 三、方案选择问题



当两个方案的费用与某个变量有关时，可以分别写出方案一和方案二的函数解析式，然后比较：

- 当 x 取何值时方案一更优

- 当 x 取何值时方案二更优

- 当 x 取何值时两方案相同



---



## ⭐ 重点



1. 实际问题中，自变量的取值范围要**符合实际意义**（如时间不能为负）。

2. 方案选择问题通过比较两个函数的**交点**来决策。

3. 一次函数模型在解决实际问题时非常实用，关键是找到变量间的等量关系。



---



## ⚠️ 易错点



> ❌ **错误**：实际问题中不写自变量的取值范围

> ✅ **正确**：实际问题必须写出自变量的取值范围，且要符合实际意义



> ❌ **错误**：方案选择只看函数值大小，不考虑实际可行性

> ✅ **正确**：方案选择要在自变量的实际取值范围内比较



---



## 📝 典型例题



**例 1**（费用问题）：某出租车起步价 8 元（含 3km），超过 3km 后每公里 2 元。写出费用 y（元）与路程 x（km）的函数关系式。



> 解：当 0 < x ≤ 3 时，y = 8

> 当 x > 3 时，y = 8 + 2(x - 3) = 2x + 2




**例 3**（行程问题）：A、B 两地相距 300km，甲车从 A 地出发，乙车从 B 地出发，相向而行。甲车速度 60km/h，乙车速度 40km/h。写出两车距离 y（km）与时间 x（h）的函数关系式。

> 解：x 小时后，甲走了 60x km，乙走了 40x km
> 两车距离 y = 300 - 60x - 40x = 300 - 100x
> 相遇时 y = 0，300 - 100x = 0，x = 3
> 自变量取值范围：0 ≤ x ≤ 3

**例 4**（方案选择）：某快递公司寄件收费标准：方案 A 首重 10 元（含 1kg），续重 2 元/kg；方案 B 首重 8 元（含 1kg），续重 3 元/kg。寄 x kg 包裹（x > 1），哪种方案更划算？

> 解：方案 A：y₁ = 10 + 2(x - 1) = 2x + 8
> 方案 B：y₂ = 8 + 3(x - 1) = 3x + 5
> 令 y₁ = y₂：2x + 8 = 3x + 5，x = 3
> 当 x < 3 时，y₂ < y₁，方案 B 更划算
> 当 x = 3 时，两者相同
> 当 x > 3 时，y₁ < y₂，方案 A 更划算

**例 2**（方案选择）：A 方案：月租 20 元，每分钟 0.1 元。B 方案：无月租，每分钟 0.3 元。每月通话 x 分钟，哪种方案更划算？



> 解：A：y₁ = 20 + 0.1x，B：y₂ = 0.3x

> 令 y₁ = y₂ → 20 + 0.1x = 0.3x → 20 = 0.2x → x = 100

> 当 x < 100 时，B 更划算；当 x = 100 时，两者相同；当 x > 100 时，A 更划算
