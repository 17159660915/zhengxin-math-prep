# 23.2 一次函数的图象和性质



## 📖 知识点



### 一、一次函数的图象



一次函数 y = kx + b 的图象是一条**直线**，经过点 (0, b) 和 (-b/k, 0)。



> 其中 (0, b) 是图象与 y 轴的交点，(-b/k, 0) 是图象与 x 轴的交点。



### 二、k 与 b 的意义



- **k（斜率）**：决定直线的**倾斜方向**和**倾斜程度**

- **b（截距）**：决定直线与 y 轴的交点位置



| k 的符号 | 图象方向 | 函数性质 |

|---------|---------|---------|

| k > 0 | 从左向右上升 | y 随 x 增大而增大 |

| k < 0 | 从左向右下降 | y 随 x 增大而减小 |



| b 的符号 | 与 y 轴交点 |

|---------|------------|

| b > 0 | 在 y 轴正半轴 |

| b = 0 | 经过原点（正比例函数） |

| b < 0 | 在 y 轴负半轴 |



### 三、画一次函数图象



两点确定一条直线，所以画一次函数图象只需**找两个点**：

1. 取 x = 0，得 (0, b)

2. 取 y = 0，得 (-b/k, 0)




---



## ⭐ 重点



1. k > 0 → 直线上升（y 随 x 增大而增大）；k < 0 → 直线下降（y 随 x 增大而减小）。

2. b 是直线与 y 轴交点的纵坐标——b > 0 交于正半轴，b = 0 过原点，b < 0 交于负半轴。

3. 画一次函数图象：**两点法**——找与 x 轴、y 轴的交点。



---



## ⚠️ 易错点



> ❌ **错误**：k 越大，图象越靠近 y 轴，越陡

> ✅ **正确**：|k| 越大，图象越陡；k > 0 时，k 越大越陡；k < 0 时，|k| 越大越陡



> ❌ **错误**：b 越大，图象越陡

> ✅ **正确**：b 决定图象上下平移，不影响倾斜程度（陡峭程度）



---



## 📝 典型例题



**例 1**：一次函数 y = 2x - 3 中，k 和 b 各是多少？图象经过哪些象限？



> 解：k = 2 > 0，b = -3 < 0

> 直线上升，交 y 轴负半轴

> 经过第一、三、四象限



**例 2**：一次函数 y = -x + 2 的图象经过哪些象限？



> 解：k = -1 < 0，b = 2 > 0

> 直线下降，交 y 轴正半轴

> 经过第一、二、四象限




**例 4**：一次函数 y = (2k - 1)x + 3 的图象经过第一、二、四象限，求 k 的取值范围。

> 解：经过二、四象限，说明图象从左向右下降，k < 0
> 2k - 1 < 0，k < 1/2
> 经过第二象限，b = 3 > 0，交 y 轴正半轴
> 经过第一象限，说明图象在 x 轴正半轴也有部分
> k < 1/2

**例 5**：直线 y = kx + b 过点 (1, 3) 和 (-1, -1)，求 k 和 b。

> 解：代入两点：
> 3 = k + b……①
> -1 = -k + b……②
> ① + ②：2 = 2b，b = 1
> 代入①：3 = k + 1，k = 2
> 解析式为 y = 2x + 1

**例 3**：画出一次函数 y = 2x + 1 的图象。



> 解：取两个点：

> x = 0 → y = 1，得 (0, 1)

> y = 0 → 0 = 2x + 1 → x = -1/2，得 (-1/2, 0)

> 过这两点画一条直线
