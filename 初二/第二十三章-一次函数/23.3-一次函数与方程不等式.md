# 23.3 一次函数与方程(组)不等式



## 📖 知识点



### 一、一次函数与一元一次方程



一次函数 y = kx + b 的图象与 x 轴交点的**横坐标**，就是方程 kx + b = 0 的解。



> 例：y = 2x - 4 与 x 轴交于 (2, 0)，则方程 2x - 4 = 0 的解为 x = 2。



### 二、一次函数与二元一次方程组



两个一次函数图象的交点坐标，就是对应的二元一次方程组的解。



> 例：y = x + 1 与 y = -x + 3 的交点为 (1, 2)，则方程组 { y = x + 1，y = -x + 3 } 的解为 { x = 1，y = 2 }。



### 三、一次函数与一元一次不等式



kx + b > 0 的解集 → 一次函数图象在 x 轴上方的部分对应的 x 取值范围。

kx + b < 0 的解集 → 一次函数图象在 x 轴下方的部分对应的 x 取值范围。



> 例：y = 2x - 4 中，2x - 4 > 0 的解集为 x > 2（图象在 x 轴上方的部分）。



---



## ⭐ 重点



1. 方程 kx + b = 0 的解 = 函数 y = kx + b 与 x 轴交点的横坐标。

2. 方程组 { y = k₁x + b₁，y = k₂x + b₂ } 的解 = 两直线交点的坐标。

3. 不等式 kx + b > 0 的解集 = 图象在 x 轴上方的 x 取值。



---



## ⚠️ 易错点



> ❌ **错误**：方程的解是函数图象与 x 轴的交点

> ✅ **正确**：方程的解是交点的**横坐标**（数值），不是交点本身（点）



> ❌ **错误**：两条直线平行时，方程组也有解

> ✅ **正确**：两条直线平行（k₁ = k₂ 且 b₁ ≠ b₂），没有交点，方程组无解



---



## 📝 典型例题



**例 1**：一次函数 y = 3x - 6 与 x 轴的交点坐标是多少？方程 3x - 6 = 0 的解是多少？



> 解：令 y = 0 → 3x - 6 = 0 → x = 2

> 交点坐标 (2, 0)，方程的解为 x = 2



**例 2**：求直线 y = x + 2 与 y = -x + 4 的交点坐标。



> 解：x + 2 = -x + 4 → 2x = 2 → x = 1

> y = 1 + 2 = 3

> 交点坐标 (1, 3)



**例 3**：解不等式 2x + 1 > 0 用图象法。



> 解：作 y = 2x + 1 的图象，与 x 轴交于 (-1/2, 0)

> 图象在 x 轴上方的部分：x > -1/2

> 解集为 x > -1/2
