# 22.1 函数的概念

## 📖 知识点

### 一、变量与常量

- **常量**：在变化过程中数值始终不变的量
- **变量**：在变化过程中数值发生变化的量

> 例：S = πr² 中，π 是常量，r 和 S 是变量。

### 二、函数的概念

在一个变化过程中，如果有两个变量 x 和 y，且对于 x 的**每一个确定的值**，y 都有**唯一确定的值**与之对应，那么 y 是 x 的**函数**。

> x 叫做**自变量**，y 叫做**因变量**（或函数值）。
> 记作：y = f(x)，读作"y 是 x 的函数"。

### 三、函数值

当自变量 x 取某一确定值 a 时，对应的因变量 y 的值叫做**函数值**。

> 例：y = 2x + 1，当 x = 3 时，函数值 y = 7。

### 四、自变量取值范围

| 函数形式 | 自变量取值范围 |
|---------|--------------|
| 整式（如 y = 2x + 1） | 全体实数 |
| 分式（如 y = 1/x） | 分母 ≠ 0 |
| 二次根式（如 y = √x） | 被开方数 ≥ 0 |
| 实际应用 | 还要符合实际意义 |

---

## ⭐ 重点

1. 函数的核心：**一对一的确定性**——每个 x 对应唯一一个 y。
2. 自变量取值范围要考虑：分母不为 0、被开方数非负、实际意义。
3. 函数的表示法将在下一节详细学习。

---

## ⚠️ 易错点

> ❌ **错误**：y = ±√x 中，y 是 x 的函数
> ✅ **正确**：每个 x 对应两个 y 值（±），不是函数

> ❌ **错误**：y = 1/x 中，x 可以取任何实数
> ✅ **正确**：x ≠ 0，因为分母不能为 0

> ❌ **错误**：y = √(x - 2) 中，x 可以取任何实数
> ✅ **正确**：x - 2 ≥ 0 → x ≥ 2

## 📝 典型例题

**例 1**：下列关系中，y 是 x 的函数吗？① y = 2x　② y² = x　③ y = 1/x（x ≠ 0）

> 解：① 是（每个 x 对应唯一一个 y）　② 否（每个 x 对应两个 y）　③ 是（每个 x 对应唯一一个 y）

**例 2**：求函数 y = √(x - 1) + 1/(x - 2) 的自变量取值范围。

> 解：√(x - 1) → x - 1 ≥ 0 → x ≥ 1
> 1/(x - 2) → x - 2 ≠ 0 → x ≠ 2
> 取值范围：x ≥ 1 且 x ≠ 2

**例 3**：y = 2x + 3，求当 x = -1 时的函数值。

> 解：y = 2 × (-1) + 3 = -2 + 3 = 1
