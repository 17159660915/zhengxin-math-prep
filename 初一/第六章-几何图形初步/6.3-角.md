# 6.3 角

## 📖 知识点

### 一、角的概念

- **静态定义**：有公共端点的两条射线组成的图形叫做**角**。公共端点叫做角的**顶点**，两条射线叫做角的**边**。
- **动态定义**：一条射线绕它的端点旋转形成的图形。

### 二、角的表示方法

| 方法 | 表示 | 适用 |
|------|------|------|
| 三个大写字母 | ∠AOB（顶点在中间） | 任意角 |
| 一个大写字母 | ∠O（顶点处只有一个角） | 顶点处无其他角时 |
| 数字 | ∠1、∠2 | 在角内部标注 |
| 希腊字母 | ∠α、∠β | 在角内部标注 |

### 三、角的度量

- 单位：**度**（°）、**分**（′）、**秒**（″）
- 1° = 60′，1′ = 60″（六十进制）
- 1° = 3600″

### 四、角的分类

| 角的范围 | 名称 |
|---------|------|
| θ = 0° | 零角 |
| 0° < θ < 90° | 锐角 |
| θ = 90° | 直角 |
| 90° < θ < 180° | 钝角 |
| θ = 180° | 平角 |
| θ = 360° | 周角 |

### 五、角平分线

从一个角的顶点出发，把这个角分成**两个相等角**的射线，叫做这个角的**平分线**。

∠AOC = ∠COB = 1/2 ∠AOB

### 六、余角和补角

| 关系 | 定义 | 公式 |
|------|------|------|
| 互余 | 两角之和为 90° | α + β = 90° |
| 互补 | 两角之和为 180° | α + β = 180° |

> **性质**：同角（或等角）的余角相等；同角（或等角）的补角相等。

---

## ⭐ 重点

1. 角的表示法中，顶点字母**必须写在中间**。
2. 度分秒是**六十进制**，不是十进制——18′ + 42′ = 60′ = 1°。
3. 余角和补角的性质：同角的余角相等、同角的补角相等。

---

## ⚠️ 易错点

> ❌ **错误**：∠ABC 的顶点是 A（或 C）
> ✅ **正确**：∠ABC 的顶点是 B（中间的字母是顶点）

> ❌ **错误**：30.5° = 30°5′（把 0.5° 当成 5′）
> ✅ **正确**：30.5° = 30° + 0.5 × 60′ = 30°30′

> ❌ **错误**：∠A 的补角是 90° - ∠A
> ✅ **正确**：∠A 的补角是 180° - ∠A（余角才是 90° - ∠A）

> ❌ **错误**：∠1 + ∠2 = 90°，∠1 + ∠3 = 90°，则 ∠2 + ∠3 = 90°
> ✅ **正确**：同角的余角相等，∠2 = ∠3

---

## 📝 典型例题

**例 1**：计算 32°18′ + 45°52′

> 解：32°18′ + 45°52′ = 77°70′ = 78°10′（70′ = 1°10′）

**例 2**：∠AOB = 80°，OC 是 ∠AOB 的平分线，OD 是 ∠BOC 的平分线，求 ∠AOD。

> 解：∠BOC = 1/2 × 80° = 40°
> ∠COD = 1/2 × 40° = 20°
> ∠AOD = ∠AOC + ∠COD = 40° + 20° = 60°

**例 3**：一个角的补角比它的余角的 3 倍少 10°，求这个角。

> 解：设这个角为 x°。
> 补角 = 180 - x，余角 = 90 - x
> 180 - x = 3(90 - x) - 10
> 180 - x = 270 - 3x - 10
> 180 - x = 260 - 3x
> 2x = 80，x = 40°
