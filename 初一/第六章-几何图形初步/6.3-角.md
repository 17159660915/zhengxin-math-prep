# 6.3 角

## 📖 知识点

### 一、角的概念

- **静态定义**：有公共端点的两条射线组成的图形叫做**角**。公共端点叫做角的**顶点**，两条射线叫做角的**边**。
- **动态定义**：一条射线绕它的端点旋转形成的图形。

### 二、角的表示方法

| 方法 | 表示 | 适用 |
|------|------|------|
| 三个大写字母 | $\angle AOB$（顶点在中间） | 任意角 |
| 一个大写字母 | $\angle O$（顶点处只有一个角） | 顶点处无其他角时 |
| 数字 | $\angle 1$、$\angle 2$ | 在角内部标注 |
| 希腊字母 | $\angle \alpha$、$\angle \beta$ | 在角内部标注 |

### 三、角的度量

- 单位：**度**（$^\circ$）、**分**（$'$）、**秒**（$''$）
- $1^\circ = 60'$，$1' = 60''$（六十进制）
- $1^\circ = 3600''$

### 四、角的分类

| 角的范围 | 名称 |
|---------|------|
| $\theta = 0^\circ$ | 零角 |
| $0^\circ < \theta < 90^\circ$ | 锐角 |
| $\theta = 90^\circ$ | 直角 |
| $90^\circ < \theta < 180^\circ$ | 钝角 |
| $\theta = 180^\circ$ | 平角 |
| $\theta = 360^\circ$ | 周角 |

### 五、角平分线

从一个角的顶点出发，把这个角分成**两个相等角**的射线，叫做这个角的**平分线**。

$$\angle AOC = \angle COB = \dfrac{1}{2}\angle AOB$$

### 六、余角和补角

| 关系 | 定义 | 公式 |
|------|------|------|
| 互余 | 两角之和为 $90^\circ$ | $\alpha + \beta = 90^\circ$ |
| 互补 | 两角之和为 $180^\circ$ | $\alpha + \beta = 180^\circ$ |

> **性质**：同角（或等角）的余角相等；同角（或等角）的补角相等。

---

## ⭐ 重点

1. 角的表示法中，顶点字母**必须写在中间**。
2. 度分秒是**六十进制**，不是十进制——$18' + 42' = 60' = 1^\circ$。
3. 余角和补角的性质：同角的余角相等、同角的补角相等。

---

## ⚠️ 易错点

> ❌ **错误**：$\angle ABC$ 的顶点是 $A$（或 $C$）
> ✅ **正确**：$\angle ABC$ 的顶点是 $B$（中间的字母是顶点）

> ❌ **错误**：$30.5^\circ = 30^\circ 5'$（把 $0.5^\circ$ 当成 $5'$）
> ✅ **正确**：$30.5^\circ = 30^\circ + 0.5 \times 60' = 30^\circ 30'$

> ❌ **错误**：$\angle A$ 的补角是 $90^\circ - \angle A$
> ✅ **正确**：$\angle A$ 的补角是 $180^\circ - \angle A$（余角才是 $90^\circ - \angle A$）

> ❌ **错误**：$\angle 1 + \angle 2 = 90^\circ$，$\angle 1 + \angle 3 = 90^\circ$，则 $\angle 2 + \angle 3 = 90^\circ$
> ✅ **正确**：同角的余角相等，$\angle 2 = \angle 3$

---

## 📝 典型例题

**例 1**：计算 $32^\circ 18' + 45^\circ 52'$

> 解：$32^\circ 18' + 45^\circ 52' = 77^\circ 70' = 78^\circ 10'$（$70' = 1^\circ 10'$）

**例 2**：$\angle AOB = 80^\circ$，$OC$ 是 $\angle AOB$ 的平分线，$OD$ 是 $\angle BOC$ 的平分线，求 $\angle AOD$。

> 解：$\angle BOC = \dfrac{1}{2} \times 80^\circ = 40^\circ$
> $\angle COD = \dfrac{1}{2} \times 40^\circ = 20^\circ$
> $\angle AOD = \angle AOC + \angle COD = 40^\circ + 20^\circ = 60^\circ$

**例 3**：一个角的补角比它的余角的 $3$ 倍少 $10^\circ$，求这个角。

> 解：设这个角为 $x^\circ$。
> 补角 $= 180 - x$，余角 $= 90 - x$
> $180 - x = 3(90 - x) - 10$
> $180 - x = 270 - 3x - 10$
> $180 - x = 260 - 3x$
> $2x = 80$，$x = 40^\circ$
