# 10.3 实际问题与二元一次方程组

## 📖 知识点

### 一、列二元一次方程组解应用题的步骤

1. **审**：审清题意，找出两个等量关系
2. **设**：设两个未知数（通常分别设为 x 和 y）
3. **列**：根据两个等量关系列出两个方程
4. **解**：解方程组
5. **验**：检验解的合理性
6. **答**：写出答案

> 核心：找出**两个**等量关系，因为有两个未知数需要两个方程。

### 二、常见问题类型

| 类型 | 等量关系 |
|------|---------|
| 和差倍分 | 和/差/倍/分关系 = 两个方程 |
| 行程问题 | 路程 = 速度 × 时间 |
| 工程问题 | 工作量 = 效率 × 时间 |
| 数字问题 | 两位数 = 10a + b |
| 配套问题 | 数量比 = 配套比 |
| 购物问题 | 总价 = 单价 × 数量 |

---

## ⭐ 重点

1. 找两个等量关系——每个等量关系对应一个方程。
2. 设未知数时，选择**与等量关系直接相关**的量。
3. 解出答案后要检验是否符合实际（如人数不能为负）。

---

## ⚠️ 易错点

> ❌ **错误**：只找到一个等量关系就列方程
> ✅ **正确**：两个未知数需要两个方程，至少要找到两个等量关系

> ❌ **错误**：设了 x 后不写 x 代表什么
> ✅ **正确**：设未知数时必须明确含义——"设大货车每辆运 x 吨"

> ❌ **错误**：单位不统一就列方程
> ✅ **正确**：先统一单位再列方程

## 📝 典型例题

**例 1**（和差）：两数之和为 25，两数之差为 7，求这两个数。

> 解：设两数为 x 和 y（x > y）
> { x + y = 25，x - y = 7 }
> 两式相加：2x = 32 → x = 16
> y = 25 - 16 = 9
> 答：两数为 16 和 9。

**例 2**（购物）：买 3 支钢笔和 2 本笔记本共 19 元，买 5 支钢笔和 3 本笔记本共 31 元，求钢笔和笔记本的单价。

> 解：设钢笔 x 元/支，笔记本 y 元/本
> { 3x + 2y = 19……①，5x + 3y = 31……② }
> ① × 3 - ② × 2：9x + 6y - 10x - 6y = 57 - 62 → -x = -5 → x = 5
> 代入①：15 + 2y = 19 → y = 2
> 答：钢笔 5 元/支，笔记本 2 元/本。

**例 3**（数字）：一个两位数，个位数字与十位数字之和为 11，交换十位与个位数字后新数比原数大 27，求原数。

> 解：设十位数字为 x，个位数字为 y
> { x + y = 11，10y + x - (10x + y) = 27 }
> 化简：{ x + y = 11，y - x = 3 }
> 两式相加：2y = 14 → y = 7，x = 4
> 原数 = 47
