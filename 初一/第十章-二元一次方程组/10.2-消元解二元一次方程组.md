# 10.2 消元——解二元一次方程组

## 📖 知识点

### 一、消元思想

将二元一次方程组中**两个未知数转化为一个未知数**，从而求解的方法，叫做**消元**。

### 二、代入消元法

**步骤**：
1. 从方程组中选一个系数较简单的方程，将一个未知数用另一个未知数表示
2. 代入另一个方程，消去一个未知数，得到一元一次方程
3. 解这个一元一次方程，求出一个未知数的值
4. 将求出的值代入第一步的表达式，求另一个未知数
5. 写出方程组的解

> 例：{ x + y = 5……①，2x - y = 1……② }
> 由①得：y = 5 - x……③
> 代入②：2x - (5 - x) = 1 → 3x = 6 → x = 2
> 代入③：y = 5 - 2 = 3
> 解为 { x = 2，y = 3 }

### 三、加减消元法

**步骤**：
1. 将两个方程中同一未知数的系数化为相等或互为相反数
2. 两式相加或相减，消去一个未知数
3. 解一元一次方程
4. 代入求另一个未知数

> 例：{ 3x + 2y = 8……①，x - 2y = -4……② }
> ① + ② 消去 y：4x = 4 → x = 1
> 代入①：3 + 2y = 8 → 2y = 5 → y = 2.5

### 四、选择消元法的原则

| 情况 | 推荐方法 |
|------|---------|
| 某个方程中未知数系数为 1 或 -1 | 代入消元法 |
| 两个方程中同一未知数系数相同或相反 | 加减消元法 |
| 系数无特殊关系 | 加减消元法（用最小公倍数化系数） |

---

## ⭐ 重点

1. 消元的核心目标：把二元变成一元，再解一元一次方程。
2. 代入消元法要注意代入时**加括号**——如代入 y = 5 - x 到 2x - y = 1 中应写为 2x - (5 - x)。
3. 加减消元法要注意**两式相加还是相减**——系数相同则相减，系数相反则相加。

---

## ⚠️ 易错点

> ❌ **错误**：代入时忘记加括号——2x - y = 1 代入 y = 5 - x 得 2x - 5 - x = 1
> ✅ **正确**：2x - (5 - x) = 1 → 2x - 5 + x = 1 → 3x = 6

> ❌ **错误**：加减消元时，系数互为相反数却相减
> ✅ **正确**：系数互为相反数时，应**相加**消元

> ❌ **错误**：解完只写出一个未知数就结束
> ✅ **正确**：必须求出两个未知数的值，并用 { x = a，y = b } 的格式写出

## 📝 典型例题

**例 1**（代入法）：{ x = 2y，3x - y = 10 }

> 解：将 x = 2y 代入 3x - y = 10
> 3(2y) - y = 10 → 6y - y = 10 → 5y = 10 → y = 2
> x = 2 × 2 = 4
> 解为 { x = 4，y = 2 }

**例 2**（加减法）：{ 2x + 3y = 7，4x - 3y = 5 }

> 解：① + ② → 6x = 12 → x = 2
> 代入①：4 + 3y = 7 → 3y = 3 → y = 1
> 解为 { x = 2，y = 1 }

**例 3**：{ 3x + 4y = 10，5x - 6y = 33 }

> 解：① × 3，② × 2 → { 9x + 12y = 30，10x - 12y = 66 }
> 两式相加：19x = 96 → x = 96/19
> 代入①求 y（略）
