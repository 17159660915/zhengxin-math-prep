# 2.1 有理数的加法与减法

## 📖 知识点

### 一、有理数的加法法则

| 类型 | 法则 | 示例 |
|------|------|------|
| 同号两数相加 | 取**相同的符号**，并把绝对值相加 | (-3)+(-5)=-(3+5)=-8 |
| 异号两数相加 | 绝对值**相等**时和为 0；绝对值**不等**时，取绝对值较大的数的符号，并用较大的绝对值减去较小的绝对值 | (-3)+5=+(5-3)=2；3+(-3)=0 |
| 一个数同 0 相加 | 仍得这个数 | (-4)+0=-4 |

### 二、有理数的加法运算律

- **交换律**：a + b = b + a
- **结合律**：(a + b) + c = a + (b + c)

> 运用运算律可以简化计算，特别是把同号的数结合在一起相加。

### 三、有理数的减法法则

**减去一个数，等于加上这个数的相反数。**

a - b = a + (-b)

> 例：3 - (-5) = 3 + 5 = 8；(-2) - 6 = (-2) + (-6) = -8

### 四、有理数的加减混合运算

加减混合运算可以统一为**加法运算**：

a - b + c - d = a + (-b) + c + (-d)

写成省略加号的形式：a - b + c - d（读作"a 负 b 正 c 负 d"）。

---

## ⭐ 重点

1. **减法变加法**是核心：减号变加号，减数变相反数，这两步必须同时做。
2. 同号相加——符号不变，绝对值相加；异号相加——符号看"大"的，绝对值相减。
3. 加减混合运算中，先把减法全部转化为加法，再利用运算律简便计算。
4. 灵活运用交换律和结合律，把同号的数、能凑整的数先结合。

---

## ⚠️ 易错点

> ❌ **错误**：(-3) + (-5) = +8（同号相加忘了取相同符号）
> ✅ **正确**：(-3) + (-5) = -(3+5) = -8

> ❌ **错误**：3 - (-5) = 3 - 5 = -2（只改了减号，没把减数变相反数）
> ✅ **正确**：3 - (-5) = 3 + (+5) = 8

> ❌ **错误**：(-7) + 2 = -9（异号相加时，把绝对值相加了）
> ✅ **正确**：(-7) + 2 = -(7-2) = -5（取绝对值大的符号，绝对值相减）

> ❌ **错误**：0 - (-3) = -3（误认为 0 减任何数都等于那个数的相反数，但符号搞反）
> ✅ **正确**：0 - (-3) = 0 + 3 = 3

## 📝 典型例题

**例 1**：计算 (-23) + (+58) + (-17) + (-8)

> 解：把同号结合
> = [(-23) + (-17)] + [(-8)] + (+58)
> = (-40) + (-8) + 58
> = (-48) + 58 = 10

**例 2**：计算 (-5) - (-8) - (+3) + (-2)

> 解：先全部转为加法
> = (-5) + 8 + (-3) + (-2)
> = [(-5) + (-3) + (-2)] + 8
> = (-10) + 8 = -2

**例 3**：某地一天早晨气温 -3° C，中午上升 8° C，半夜又下降 6° C，半夜气温是多少？

> 解：(-3) + 8 + (-6) = (-3) + (-6) + 8 = (-9) + 8 = -1° C
