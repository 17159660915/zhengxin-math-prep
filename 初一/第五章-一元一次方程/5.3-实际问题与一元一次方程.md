# 5.3 实际问题与一元一次方程

## 📖 知识点

### 一、列方程解应用题的一般步骤

1. **审**：审清题意，找出已知量和未知量
2. **设**：设未知数（通常设所求量为 x）
3. **找**：找出等量关系
4. **列**：根据等量关系列出方程
5. **解**：解方程
6. **验**：检验解的合理性（是否符合实际意义）
7. **答**：写出答案

### 二、常见问题类型

| 类型 | 基本等量关系 |
|------|------------|
| 行程问题 | 路程 = 速度 × 时间 |
| 工程问题 | 工作量 = 工作效率 × 时间（设总量为 1） |
| 购物问题 | 总价 = 单价 × 数量 |
| 年龄问题 | 年龄差不变 |
| 数字问题 | 两位数 = 10a + b |
| 利润问题 | 利润 = 售价 - 进价；利润率 = 利润 ÷ 进价 |

### 三、行程问题详解

**相遇问题**：s_A + s_B = 总路程

**追及问题**：s_{快} - s_{慢} = 初始距离

**顺逆水问题**：
- v_{顺} = v_{静} + v_{水}
- v_{逆} = v_{静} - v_{水}

---

## ⭐ 重点

1. 设未知数**设谁方便就设谁**，不一定直接设所求量。
2. 找等量关系是列方程的核心——常见关键词："一共""相差""倍数""比例"。
3. 解出方程后要**检验**，看是否符合实际情景（如人数不能为负、分数）。

---

## ⚠️ 易错点

> ❌ **错误**：设未知数写了"设 x"，但没写 x 代表什么
> ✅ **正确**：设 x 时必须明确——"设甲的速度为 x km/h"

> ❌ **错误**：解出 x = -3，但题目问人数，直接写 -3 人
> ✅ **正确**：检验后发现 x = -3 不符合实际，此题无解或需重新审题

> ❌ **错误**：单位不统一就列方程（如 v 用 km/h，t 用分钟）
> ✅ **正确**：先统一单位再列方程

## 📝 典型例题

**例 1**（行程）：甲、乙两人从相距 36km 的两地相向而行，甲的速度是 4km/h，乙的速度是 5km/h。甲先出发 1h，乙出发多少小时后两人相遇？

> 解：设乙出发 x 小时后相遇。
> 甲走了 (x+1) 小时，4(x+1) + 5x = 36
> 4x + 4 + 5x = 36，9x = 32，x = 32/9（小时）

**例 2**（利润）：某商品按标价的 8 折出售仍获利 20\%，已知进价为 100 元，求标价。

> 解：设标价为 x 元。
> 0.8x - 100 = 100 × 20\%，0.8x = 120，x = 150 元

**例 3**（数字）：一个两位数，十位数字与个位数字之和为 10，交换十位与个位数字后，新数比原数大 36，求原数。

> 解：设十位数字为 x，则个位数字为 10 - x。
> 原数 = 10x + (10-x) = 9x + 10
> 新数 = 10(10-x) + x = 100 - 9x
> 100 - 9x = 9x + 10 + 36，54 = 18x，x = 3
> 个位数字 = 7，原数为 37。
