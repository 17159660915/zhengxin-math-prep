# 5.1 方程

## 📖 知识点

### 一、方程的概念

含有**未知数**的**等式**叫做**方程**。

> 方程必须同时满足两个条件：① 是等式 ② 含有未知数。
> 例：2x + 1 = 5 是方程；2x + 1（不是等式）不是方程；1 + 2 = 3（不含未知数）不是方程。

### 二、一元一次方程

只含有一个未知数（**元**），未知数的次数都是 1（**一次**），等号两边都是整式的方程叫做**一元一次方程**。

> 标准形式：ax + b = 0（a ≠ 0）

| 方程 | 判断 | 理由 |
|------|------|------|
| 3x + 2 = 0 | ✅ | 一个未知数，次数 1 |
| x² + 1 = 0 | ❌ | 未知数次数是 2 |
| x + y = 5 | ❌ | 有两个未知数 |
| 1/x = 2 | ❌ | 不是整式（字母在分母） |

### 三、方程的解与解方程

- 使方程左右两边**相等**的未知数的值，叫做**方程的解**。
- 求方程的解的过程叫做**解方程**。

### 四、等式的性质

**性质 1**：等式两边加（或减）同一个数（或式子），结果仍相等。
a = b ⟹ a ± c = b ± c

**性质 2**：等式两边乘同一个数，或除以同一个不为 0 的数，结果仍相等。
a = b ⟹ ac = bc  (c ≠ 0)
a = b ⟹ a/c = b/c  (c ≠ 0)

---

## ⭐ 重点

1. **一元一次方程的三要素**：① 一个未知数 ② 次数为 1 ③ 整式方程。
2. 等式的性质是解方程的理论基础，**两边同除时 c ≠ 0** 是关键限定。
3. 方程的解是**数值**，不是过程。

---

## ⚠️ 易错点

> ❌ **错误**：x² = 4 是一元一次方程
> ✅ **正确**：x 的次数是 2，是一元二次方程

> ❌ **错误**：2/x-1 = 3 是一元一次方程
> ✅ **正确**：字母在分母，不是整式方程，不是一元一次方程

> ❌ **错误**：等式两边同时除以 x，得到新方程（没考虑 x = 0 的可能）
> ✅ **正确**：除以 x 前需确认 x ≠ 0，否则可能丢解

---

## 📝 典型例题

**例 1**：下列方程中，哪些是一元一次方程？
① 2x - 3 = 0　② x² + x = 0　③ 3x + 2y = 5　④ 1/x + 2 = 0

> 解：只有 ① 是一元一次方程。② 次数为 2，③ 有两个未知数，④ 不是整式。

**例 2**：已知 x = 2 是方程 2x + a = 7 的解，求 a 的值。

> 解：代入 x = 2：2 × 2 + a = 7，解得 a = 3
