# 8.1 平方根



## 📖 知识点



### 一、算术平方根



如果一个**正数** x 的平方等于 a，即 x² = a，那么这个正数 x 叫做 a 的**算术平方根**。



> 记作：√a（读作"根号 a"）



规定：**0 的算术平方根是 0**，即 √0 = 0。



> 例：因为 5² = 25，所以 25 的算术平方根是 5，即 √25 = 5。



**注意**：负数没有算术平方根（因为任何数的平方都是非负的）。



### 二、平方根



如果一个数的平方等于 a，那么这个数叫做 a 的**平方根**（或二次方根）。



> 即：若 x² = a，则 x 是 a 的平方根。



- 正数 a 的平方根有**两个**，互为相反数：√a 和 -√a

- 0 的平方根是 0

- 负数**没有**平方根



> 记法：正数 a 的平方根记作 ±√a



### 三、平方根与算术平方根的区别



| | 平方根 | 算术平方根 |

|---|--------|----------|

| 个数 | 正数有 2 个 | 正数有 1 个 |

| 符号 | ±√a | √a |

| 取值 | 一正一负（或 0） | 非负数 |



### 四、开平方



求一个数 a 的平方根的运算，叫做**开平方**。



> 开平方与平方互为逆运算。



| a 的值 | √a | ±√a |

|--------|-----|------|

| 0 | 0 | 0 |

| 1 | 1 | ±1 |

| 4 | 2 | ±2 |

| 9 | 3 | ±3 |

| 1/4 | 1/2 | ±1/2 |



---



## ⭐ 重点



1. **√a 表示算术平方根（非负数）**，±√a 表示平方根（两个值）——这是最核心的区别。

2. 只有**非负数**才有平方根和算术平方根。

3. √a ≥ 0 恒成立（算术平方根是非负的）。



---



## ⚠️ 易错点



> ❌ **错误**：√25 = ±5（把平方根和算术平方根搞混）

> ✅ **正确**：√25 = 5（算术平方根只有一个，是非负数）；25 的平方根是 ±5



> ❌ **错误**：√(-4) = -2（负数没有平方根）

> ✅ **正确**：-4 没有平方根，√(-4) 无意义



> ❌ **错误**：√(a²) = a（没有考虑 a 的正负）

> ✅ **正确**：√(a²) = |a|。当 a ≥ 0 时 √(a²) = a；当 a < 0 时 √(a²) = -a



> ❌ **错误**：√(4 + 9) = √4 + √9 = 2 + 3 = 5（根号不能拆开加）

> ✅ **正确**：√(4 + 9) = √13（根号内不能随意拆分）

## 📝 典型例题



**例 1**：求下列各数的平方根和算术平方根：36，49/64，0



> 解：

> 36 的平方根 = ±6，算术平方根 = 6

> 49/64 的平方根 = ±7/8，算术平方根 = 7/8

> 0 的平方根 = 0，算术平方根 = 0



**例 2**：求 √(x - 2) + √(y + 3) = 0 中的 x、y 值。



> 解：√(x-2) ≥ 0，√(y+3) ≥ 0，两个非负数之和为 0，则各自为 0

> x - 2 = 0 → x = 2

> y + 3 = 0 → y = -3




**例 4**：求 √(x - 2) + √(y + 3) = 0 中的 x、y 值。

> 解：√(x-2) ≥ 0，√(y+3) ≥ 0，两个非负数之和为 0，则各自为 0
> x - 2 = 0 → x = 2
> y + 3 = 0 → y = -3

**例 5**：一个正方形的面积为 50，求它的边长（精确到 0.01）。

> 解：边长 = √50 = √(25×2) = 5√2
> 5√2 ≈ 5 × 1.414 = 7.07

**例 3**：一个正方形的面积为 50，求它的边长。



> 解：边长 = √50 = √(25 × 2) = 5√2
