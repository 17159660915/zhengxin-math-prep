# 9.1 用坐标描述平面内点的位置



## 📖 知识点



### 一、平面直角坐标系的构成



在平面内画两条互相垂直、原点重合的数轴，组成**平面直角坐标系**。



- **x 轴**：水平的数轴（横轴），向右为正方向

- **y 轴**：竖直的数轴（纵轴），向上为正方向

- **原点**：两轴的交点，记作 O



### 二、坐标的表示



平面内任意一点 P 的位置用一对**有序数对** (a, b) 表示，称为 P 点的**坐标**。



- a 叫做**横坐标**（x 坐标）

- b 叫做**纵坐标**（y 坐标）

- 记作 P(a, b)



> 注意：**有序**——(3, 4) 和 (4, 3) 表示不同的点。



### 三、象限



坐标轴将平面分成四个部分，每个部分叫做一个**象限**。



| 象限 | 位置 | 横坐标 | 纵坐标 |

|------|------|--------|--------|

| 第一象限 | 右上 | 正 (+) | 正 (+) |

| 第二象限 | 左上 | 负 (-) | 正 (+) |

| 第三象限 | 左下 | 负 (-) | 负 (-) |

| 第四象限 | 右下 | 正 (+) | 负 (-) |



> 坐标轴上的点**不属于任何象限**。



### 四、特殊点的坐标



| 点的位置 | 特征 |

|---------|------|

| x 轴上 | 纵坐标 = 0，即 (a, 0) |

| y 轴上 | 横坐标 = 0，即 (0, b) |

| 原点 | (0, 0) |

| 一、三象限角平分线上 | x = y |

| 二、四象限角平分线上 | x = -y |



---



## ⭐ 重点



1. 坐标 (a, b) 是有序数对，顺序不能颠倒。

2. 点所在的象限只看横纵坐标的**符号**，不看数值大小。

3. x 轴上的点纵坐标为 0，y 轴上的点横坐标为 0。



---



## ⚠️ 易错点



> ❌ **错误**：(3, 0) 在第一象限

> ✅ **正确**：(3, 0) 在 x 轴上，不属于任何象限



> ❌ **错误**：点 (-2, 5) 到 x 轴的距离是 2

> ✅ **正确**：到 x 轴的距离是 |5| = 5（纵坐标的绝对值），不是横坐标



---



## 📝 典型例题



**例 1**：点 P(-3, 4) 在第几象限？到 x 轴和 y 轴的距离各是多少？



> 解：横坐标负，纵坐标正 → 第二象限

> 到 x 轴距离 = |4| = 4

> 到 y 轴距离 = |-3| = 3



**例 2**：已知点 M(a, b) 在第四象限，则 a、b 的符号是什么？



> 解：第四象限横坐标正、纵坐标负 → a > 0，b < 0



**例 3**：点 P(x, y) 满足 |x| = 3，|y| = 2，且 P 在第二象限，求 P 的坐标。



> 解：第二象限 x < 0，y > 0 → x = -3，y = 2 → P(-3, 2)
