# 11.2 一元一次不等式



## 📖 知识点



### 一、一元一次不等式的概念



含有一个未知数，未知数的次数是 1 的不等式，叫做**一元一次不等式**。



> 标准形式：ax + b > 0（或 < 0，≥ 0，≤ 0），a ≠ 0



### 二、解一元一次不等式的步骤



与解一元一次方程类似，但**乘除负数时不等号要变方向**：



| 步骤 | 内容 | 注意 |

|------|------|------|

| ① 去分母 | 两边同乘各分母最小公倍数 | 若乘负数要变号（通常乘正数） |

| ② 去括号 | 按去括号法则展开 | 括号前为负号全变号 |

| ③ 移项 | 含未知数移到一边，常数移另一边 | 移项要变号 |

| ④ 合并同类项 | 化为 ax > b 的形式 | |

| ⑤ 系数化为 1 | 两边同除以 a | **a < 0 时不等号变方向** |



### 三、解一元一次不等式与方程的对比



| | 一元一次方程 | 一元一次不等式 |

|---|-----------|-------------|

| 解的个数 | 通常 1 个 | 通常无数个（解集） |

| 去分母/去括号 | 相同 | 相同 |

| 系数化为 1 | 两边除以 a | a < 0 时**变号** |



---



## ⭐ 重点



1. 解不等式与解方程的唯一区别：**乘除负数时不等号变方向**。

2. 解集通常表示为 x > a 或 x < a 的形式。

3. 去分母时同乘的是正数（最小公倍数），此时不变号；只有系数化为 1 时除以负数才变号。



---



## ⚠️ 易错点



> ❌ **错误**：解 -2x + 3 < 7，得 -2x < 4，x < -2（忘记变号）

> ✅ **正确**：-2x < 4，两边除以 -2（负数，变号），x > -2



> ❌ **错误**：去分母时只乘含分母的项

> ✅ **正确**：不等式两边**每一项**都要乘



> ❌ **错误**：解集写为不等式本身，如 2x > 6

> ✅ **正确**：解集要化简到底，2x > 6 → x > 3



---



## 📝 典型例题



**例 1**：解不等式 3(x - 2) ≤ 5x + 2，并在数轴上表示解集。



> 解：去括号：3x - 6 ≤ 5x + 2

> 移项：3x - 5x ≤ 2 + 6

> 合并：-2x ≤ 8

> 系数化为 1（除以 -2，变号）：x ≥ -4

> 数轴：在 -4 处画实心圆点，向右画射线



**例 2**：解不等式 (x - 1)/2 - (2x + 1)/3 < 1



> 解：去分母（乘 6）：3(x - 1) - 2(2x + 1) < 6

> 去括号：3x - 3 - 4x - 2 < 6

> 合并：-x - 5 < 6

> 移项：-x < 11

> 系数化为 1（除以 -1，变号）：x > -11




**例 4**：求不等式 2(x - 3) ≤ 3(2x + 1) - 5 的非负整数解。

> 解：2x - 6 ≤ 6x + 3 - 5
> 2x - 6 ≤ 6x - 2
> -4x ≤ 4，x ≥ -1
> 非负整数解：x = 0, 1, 2, 3, …

**例 5**：关于 x 的方程 2x + 3k = 1 的解是正数，求 k 的取值范围。

> 解：2x = 1 - 3k，x = (1 - 3k)/2
> x > 0，(1 - 3k)/2 > 0，1 - 3k > 0
> -3k > -1，k < 1/3

**例 3**：求不等式 2x - 5 < 3x + 1 的正整数解。



> 解：2x - 5 < 3x + 1

> -x < 6 → x > -6

> 又 x 为正整数 → x = 1, 2, 3, 4, 5, …（所有正整数）
