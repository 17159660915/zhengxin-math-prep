# 11.3 一元一次不等式组

## 📖 知识点

### 一、一元一次不等式组的概念

把几个含有**同一个未知数**的一元一次不等式合在一起，就组成了一个**一元一次不等式组**。

### 二、不等式组的解集

不等式组中各个不等式解集的**公共部分**，叫做不等式组的解集。

> 如果没有公共部分，则不等式组**无解**。

### 三、解不等式组的步骤

1. 分别解每一个不等式
2. 在数轴上表示各个解集
3. 取**公共部分**
4. 写出不等式组的解集

### 四、四种基本情况（a < b）

| 类型 | 解集 | 口诀 |
|------|------|------|
| x > a 且 x > b | x > b | 同大取大 |
| x < a 且 x < b | x < a | 同小取小 |
| x > a 且 x < b | a < x < b | 大小小大取中间 |
| x < a 且 x > b | 无解 | 小小大大无解 |

> **口诀**：同大取大，同小取小，大小小大取中间，小小大大无解集。

---

## ⭐ 重点

1. 不等式组的解集是各个不等式解集的**公共部分**——在数轴上取重叠区域。
2. 四种口诀是快速判断解集的核心工具。
3. 无解的情况：两个解集没有重叠区域。

---

## ⚠️ 易错点

> ❌ **错误**：不等式组的解集取所有解集的**并集**（取全部范围）
> ✅ **正确**：取**交集**（公共部分），只取同时满足所有不等式的范围

> ❌ **错误**：只解一个不等式就写解集
> ✅ **正确**：必须解完所有不等式，再取公共部分

> ❌ **错误**：口诀"大小小大取中间"搞反
> ✅ **正确**：x 大于较小的数，x 小于较大的数，取中间

---

## 📝 典型例题

**例 1**：解不等式组 { 2x - 1 > 3，x + 2 ≤ 8 }

> 解：
> 解①：2x > 4 → x > 2
> 解②：x ≤ 6
> 公共部分：2 < x ≤ 6

**例 2**：解不等式组 { x - 3 < 0，2x + 1 > 7 } 并判断是否有解

> 解：
> 解①：x < 3
> 解②：2x > 6 → x > 3
> 公共部分：x > 3 且 x < 3，**无解**

**例 3**：求不等式组 { 2x + 1 > -3，3x - 5 ≤ 7 } 的整数解。

> 解：
> 解①：2x > -4 → x > -2
> 解②：3x ≤ 12 → x ≤ 4
> 解集：-2 < x ≤ 4
> 整数解：x = -1, 0, 1, 2, 3, 4
